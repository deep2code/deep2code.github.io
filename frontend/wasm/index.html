WebAssembly

🏷️ 前端

WebAssembly：让浏览器跑 C/C++ 的黑魔法

我第一次真正用 Wasm，是要在网页里跑一个复杂的 PDF 解析——JS 跑纯文字处理卡死了，后来把那个 C 库编译成 Wasm，速度直接快了十倍。这就是 Wasm 的价值：把已经成熟的 C/C++/Rust 库搬到浏览器，性能逼近原生。Figma、Google Earth、AutoCAD 的网页版，全靠 Wasm 撑着。

一句话理解

Wasm 是一种二进制指令格式，浏览器内置了它的虚拟机，能以接近原生的速度跑。它不是「另一个 JS」，是一种和 JS 并行的、为性能计算设计的低级字节码。

它是怎么跑起来的

flowchart LR A[C C++ Rust 源码] --> B[编译 clang rustc] B --> C[.wasm 字节码] C --> D[浏览器 Wasm 虚拟机] D --> E[接近原生速度执行] F[JS] <--> D

关键点：Wasm 和 JS 是两个独立线程/堆，但它们能互相调用（通过 WebAssembly 的 import/export）。JS 负责 DOM 和 UI，Wasm 负责重计算，各干各的。这就是 Figma 的架构。

2024-2026：Wasm 走到哪了

方向进展
Wasm 3.0标准化 SIMD、异常处理、GC 等特性
WASIWebAssembly System Interface，让 Wasm 脱离浏览器跑在服务端/边缘
组件模型Component Model，跨语言互操作
边缘计算Fastly/Cloudflare Workers 跑 Wasm
Rust 生态wasm-bindgen / wasm-pack 成熟

我觉得最重要的是 WASI。它让 Wasm 不再只活在浏览器里，变成一种「可移植的、安全的、跨平台的运行时」。边缘计算、Serverless 都在押注它——同一份 Wasm，浏览器和服务端都能跑。

性能：到底快多少

别信「快十倍」的宣传。真实情况取决于做什么：

任务JS 基线Wasm（参考值）
纯数值计算1x3-10x
JSON 解析1x1.5-3x
DOM 操作1x0.5x（Wasm 反而慢）
启动时间快加载字节码 + 编译，略慢
别什么都上 Wasm

Wasm 的强项是计算密集、已有 C 库可复用。如果你在做 DOM 操作、界面交互，JS 反而更快——因为 Wasm 调 DOM 要绕一圈，比直接 JS 慢。我见过有人把表单校验这种小事编译成 Wasm，纯属脱裤子放屁。

工具链：Rust 是最佳拍档

现在写 Wasm 最舒服的组合是 Rust + wasm-pack：

# 装工具
cargo install wasm-pack

# 新建项目
cargo new --lib my-wasm
cd my-wasm
wasm-pack build --target web

它会帮你编译、生成 .wasm、生成 JS 胶水代码。前端直接 import 那个 JS 文件就能调 Rust 函数。比从 C 用 Emscripten 简单太多。

分发网页即开即用网页要安装

适合复杂计算、文件处理3D、游戏高性能完整应用

我的实战建议

  • 先确认 JS 真的慢，再上 Wasm——别过早优化；
  • DOM 操作交给 JS，Wasm 只做纯计算；
  • Wasm 二进制大，做代码分割和流式编译（Streaming Compilation）；
  • 选 Rust 写新 Wasm，C 老库用 Emscripten。

FAQ

Q：Wasm 会取代 JavaScript 吗？
短期内不会。Wasm 和 JS 是互补，不是替代。JS 负责 DOM、UI、胶水代码，Wasm 负责重计算。Figma 这种重计算的产品 Wasm 占比高，但普通 CRUD 网页 JS 就够。

Q：Wasm 安全吗？
它跑在沙箱里，没有系统权限，比原生 C 安全。这也是边缘计算押注它的原因——租户的 Wasm 不能越界。但别把密钥硬编码在 Wasm 里，反编译能读出来。

Q：学习曲线陡吗？
用 Rust + wasm-pack 已经不算陡了，半小时能跑通 Hello。但要真正写出好的 Wasm 应用，得懂内存布局、和 JS 的边界处理，这是进阶坎。

Q：2026 年 Wasm 最火的场景是什么？
边缘计算（Cloudflare Workers 跑 Wasm）和 AI 推理（把小型模型编译成 Wasm 在浏览器本地跑）。浏览器端跑 LLM 是新方向，隐私场景很有戏。

小结

Wasm 不是银弹，是「把成熟高性能库搬到浏览器」的工具。你的应用真有计算瓶颈、且已有 C/Rust 实现，它值；否则老老实实写 JS。下一篇 Flutter，看跨端 UI 怎么做。
