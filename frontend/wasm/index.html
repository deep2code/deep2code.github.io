WASM 入门：从你遇到的问题出发

🏷️ WASM

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及WASM怎么帮你解决。

flowchart TB A[C/C++/Rust] --> B[编译成 WASM] B --> C[浏览器运行] C --> D[接近原生性能]

1. JS 跑太慢

你遇到的问题

浏览器里跑图像处理、视频解码，JS 太慢。

怎么解决？用 WASM，把 C/C++/Rust 编译成 WASM，浏览器跑，接近原生性能。

2. WASM 是什么

你遇到的问题

WebAssembly 是什么？

怎么解决？浏览器里运行的二进制指令格式，接近原生性能的低级语言。

3. 什么场景用

你遇到的问题

什么场景适合用 WASM？

怎么解决？图像处理、视频编解码、游戏、科学计算。普通业务不用。

使用场景

场景说明
游戏高性能 3D 游戏
多媒体视频/图像处理
工具大型工具（PS 网页版）
新手最容易踩的坑
  • 普通业务不用普通业务用 JS 就够，不要用 WASM。
  • Rust 是首选现在写 WASM 首选 Rust，C/C++ 容易出问题。
