Firefox 浏览器：从你遇到的问题出发

🏷️ Firefox

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Firefox怎么帮你解决。

flowchart TB A[Firefox] --> B[开发者工具] B --> C[调试] C --> D[兼容性测试]

1. 兼容性测试用什么

你遇到的问题

做完网站，怎么测不同浏览器兼容性？

怎么解决？Chrome 日常用，Firefox 测兼容，Safari 测 Mac/iOS。

2. Firefox DevTools

你遇到的问题

Firefox 开发者工具有什么特点？

怎么解决？CSS Grid 检查器、网络监视器、JavaScript 调试器很好用。

3. 什么时候用 Firefox

你遇到的问题

什么时候需要用 Firefox？

怎么解决？测 CSS Grid 兼容、测浏览器扩展、隐私相关测试。
