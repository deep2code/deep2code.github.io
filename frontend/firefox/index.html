Firefox：被低估的技术极客浏览器

Chrome 一家独大，Firefox 常年排老二。但作为前端开发者，我桌面主力一直留着 Firefox——不是情怀，是它的开发者工具在很多地方比 Chrome 还顺手。这篇聊的不是怎么用 Firefox 上网，是它作为一套浏览器引擎，2026 年走到哪了。

一句话主线

Firefox = Gecko 渲染引擎（Rust 重写的 Stylo/Servo）+ SpiderMonkey JS 引擎。它和 Chrome（Blink + V8）是两条独立的技术路线，保留它就是保留一个「另一种浏览器」的存在。

内核：Gecko 和 Servo 的关系

很多人搞不清 Servo、Gecko、Firefox 的关系。简单说：Servo 是 Mozilla 用 Rust 写的下一代实验性渲染引擎，它的成果正在逐步搬进 Gecko。比如样式引擎 Stylo 就是从 Servo 搬过来的。下图是这套关系：

flowchart TD A[Servo 实验引擎 Rust] -->|逐步移植| B[Gecko 主线引擎] B --> C[Firefox 浏览器] D[SpiderMonkey JS 引擎] --> C E[Quantum CSS Stylo] --> B

这也是为什么 Firefox 是少数用 Rust 写核心组件的主流浏览器——Mozilla 在 Rust 上的押注比 Chrome 早得多。

我实际体感：2024 年后 Firefox 的内存占用比早期 Quantum 时代降了不少，开几十个标签页不再像以前那样疯涨。但和 Chrome 比还是略高，这是 Gecko 的架构取舍。

about:config：高手的控制面板

Firefox 最独特的地方是 about:config——一个几乎所有内部开关都能改的页面。Chrome 没有这种开放程度。几个我调过的：

# 地址栏输入 about:config
# 关闭 Pocket 推荐
browser.newtabpage.pocket.enabled = false
# 启用硬件加速
media.hardware-video-decoding.enabled = true
# 调整缓存大小
browser.cache.disk.capacity = 1048576
必坑

about:config 改坏了浏览器会出怪问题。我建议每次只改一个，改坏了就把这个键右键重置。别一上来照着网上的「优化清单」全改一遍，那些清单很多是过时的。

Firefox DevTools：比 Chrome 好用的地方

作为前端，我两个浏览器的 DevTools 都用。Firefox 有几个独门优势：

功能FirefoxChrome
CSS Grid 可视化原生高亮，最好用有，但弱一些
Rules 面板显示继承链清晰一般
响应式设计模式好用也好用
性能面板够用更强
扩展生态中最丰富

我调 CSS Grid 的时候会专门切到 Firefox——它的 Grid 布局可视化（画出行线列线）比 Chrome 直观。别的时候还是 Chrome。

为什么我建议前端多留一个 Firefox

  • 兼容性兜底：你在 Chrome 调好的样式，未必在 Gecko 上一样，留个 Firefox 测一下；
  • 独立引擎：万一 Gecko 解析有独特 bug，只有 Firefox 能复现；
  • 隐私测试：Firefox 默认强隐私，帮你测试第三方脚本在严格策略下还能不能跑；
  • 别让 Chrome 一家独大：作为前端，保持一个非 Chromium 浏览器的存在很重要。

FAQ

Q：Firefox 还有人用吗？
全球桌面市场份额在 5%-10% 左右，虽然比 Chrome 小很多，但绝对用户量不小。它的意义不只是份额——是保留一个独立于 Chromium 的引擎，不让 Web 被一家垄断。

Q：为什么 Firefox 手机版这么弱？
苹果政策要求 iOS 上所有浏览器必须用 WebKit 内核，Android 上 Firefox 早期换了 GeckoView 引擎。手机上 Firefox 份额小、投入有限，体验确实不如 Chrome。手机上我也用 Chrome。

Q：Firefox 的 AI 功能怎么用？
新版有内置的页面总结、翻译，调用的是远端大模型。和浏览器本体是分开的功能，不想用可以在设置里关。本地翻译是 Mozilla 的翻译模型，不经过服务器。

Q：2026 了，Firefox 会消失吗？
短期不会。Mozilla 有基金、有独立引擎、有忠实用户群。但它的份额确实在缓慢下降。我觉得它会一直作为「第二引擎」存在下去，就像 IE 当年也活了很多年。

小结

Firefox 对普通用户是个「还行的浏览器」，对前端开发者是「必须保留的兼容性参照」。留一个它在桌面，调 Grid、测 Gecko、看隐私策略，比什么都值。下一篇前端知识体系总览，把前面这些串起来。
