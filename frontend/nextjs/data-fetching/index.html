数据获取与缓存

数据获取策略

Next.js 15 的数据获取是基于 fetch 扩展的。同一个 fetch 请求默认会被缓存，多个组件调用同一个 URL 只会发一次请求。

策略代码适用场景
静态生成fetch(url, { cache: 'force-cache' })不常变的内容
动态渲染fetch(url, { cache: 'no-store' })用户个性化内容
增量静态再生fetch(url, { next: { revalidate: 60 } })半静态内容，每 60 秒更新
