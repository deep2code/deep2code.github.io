Next.js 入门：从你遇到的问题出发

🏷️ Next.js

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Next.js怎么帮你解决。

flowchart LR A[用户访问] --> B[服务端渲染 HTML] B --> C[直接给浏览器完整页面] C --> D[加载快 + SEO 友好]

1. SPA 页面打开白屏

你遇到的问题

React SPA 要下载完 JS 才显示内容，用户看到白屏 2 秒。

怎么解决？Next.js 服务端渲染，直接给完整 HTML，打开就显示。

2. SEO 不好做

你遇到的问题

SPA 搜索引擎爬不到内容，百度收录不了。

怎么解决？服务端渲染，搜索引擎能直接爬到完整内容。

3. 做个网站不知道怎么开始

你遇到的问题

你想做个博客或官网，从零搭 React 太麻烦。

怎么解决？Next.js 自带路由、渲染、部署，开箱即用。

Next.js 渲染方式

SSR服务端实时渲染内容实时更新
SSG构建时生成静态页博客、文档站
ISR增量静态再生博客 + 偶尔更新
新手最容易踩的坑
  • 小项目用 SSG 就够了博客、文档站用静态生成，快又省钱。
  • 不要上来就 SSRSSR 会增加服务器压力，能用静态就用静态。
