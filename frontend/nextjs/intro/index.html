Next.js 入门：从你遇到的问题出发

🏷️ Next.js 入门

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Next.js 入门怎么帮你解决。

flowchart TB A[Next.js] --> B[App Router] B --> C[SSR/SSG] C --> D[API Routes]

1. React 做网站 SEO 差

你遇到的问题

纯 React SPA 网站，搜索引擎搜不到。

怎么解决？用 Next.js，支持 SSR/SSG，SEO 好，加载快。

2. Next.js 核心概念

你遇到的问题

Next.js 核心概念有哪些？

怎么解决？App Router、Server Components、SSR/SSG、API Routes。

3. 什么时候用 Next.js

你遇到的问题

什么时候该用 Next.js？

怎么解决？要 SEO、要服务端渲染、要全栈 React 项目。
