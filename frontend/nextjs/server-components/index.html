Next.js Server Components：从你遇到的问题出发

🏷️ RSC

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及RSC怎么帮你解决。

flowchart TB A[Server Component] --> B[服务端渲染] B --> C[直接查数据库] B --> D[0 JS 发给客户端]

1. 客户端组件太多 JS

你遇到的问题

你用客户端组件，所有代码都发给浏览器，太大了。

怎么解决？Server Component 在服务端跑，不发给客户端，减小 JS 体积。

2. 直接在组件里查数据库

你遇到的问题

以前要写 API 接口，前端再调。

怎么解决？Server Component 直接在组件里查数据库，不用写 API。

3. 怎么用 RSC

你遇到的问题

知道有 RSC，不知道怎么用。

怎么解决？组件默认就是 Server Component，要客户端交互的加 "use client"。

新手最容易踩的坑
  • 默认用 Server Component大部分组件用 Server，要交互的才用 Client。
  • 不要在 Server Component 用 HooksServer 端没有浏览器，不能用 useState、useEffect。
