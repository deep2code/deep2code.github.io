Server Components 深度

Server Components 是什么

Server Components 是 Next.js 13 引入的最大变革。组件默认在服务端渲染，不打包到客户端 bundle，减少 JS 体积。

特性Server ComponentClient Component
运行位置服务端浏览器
能访问后端✅ 直接查数据库❌ 只能调 API
能用 hooks❌ 不能用 useState/useEffect✅ 全部 hooks
能写事件处理❌ 不能 onClick✅ 可以
Bundle 大小0 KB（不打包）计入 bundle

什么时候用 Client Component

只有需要交互的时候才用 Client Component。加 "use client" 指令：

"use client"

import { useState } from 'react'

数据流最佳实践

  • 数据获取放 Server Component：直接查数据库，不要经过 API
  • 交互组件用 Client Component：按钮、表单、滑块等
  • Server Component 可以传 props 给 Client Component：但不能传函数
  • 不要在 Client Component 里 import Server Component：反过来是允许的
常见误区：不要把整个页面都标成 "use client"。那就是传统 SPA 了，失去了 Next.js 的意义。只有需要交互的小组件才标。
