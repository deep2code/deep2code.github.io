Next.js Server Components：从你遇到的问题出发

🏷️ Server Components

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Server Components怎么帮你解决。

flowchart TB A[Server Component] --> B[服务端渲染] B --> C[少发 JS] C --> D[页面更快]

1. 客户端 JS 太多

你遇到的问题

Next.js 客户端 JS 太多，页面加载慢。

怎么解决？用 Server Components，组件在服务端渲染，不发到浏览器，减少 JS 体积。

2. Server Components 是什么

你遇到的问题

Server Components 是什么？

怎么解决？Next.js 13+ 新特性，组件在服务端运行，不增加客户端 JS 体积。

3. 和 Client Components 区别

你遇到的问题

Server 和 Client Components 区别？

怎么解决？Server 组件在服务端跑，不能用 useState/useEffect；Client 组件在浏览器跑。
