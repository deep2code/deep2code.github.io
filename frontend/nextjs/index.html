Next.js 入门：从你遇到的问题出发

🏷️ Next.js 入门

你用 React 做网站，SEO 很差，因为内容都是 JS 渲染的，搜索引擎爬不到。或者你要做个全栈应用，前端是 React，后端还要单独写个接口服务，太麻烦了。

这篇不讲理论，就讲你真的会遇到的问题，以及 Next.js 怎么帮你解决。

场景一：用 React 做的网站，搜索引擎搜不到

你遇到的问题

你用 React 做了个公司官网，上线了半个月，百度、谷歌搜你的公司名字都搜不到。你去看，原来 React 是客户端渲染，内容都是 JS 生成的，HTML 里是空的，搜索引擎爬虫爬不到内容，SEO 特别差。

Next.js 怎么解决？Next.js 默认是服务端渲染，把 HTML 在服务器上就渲染好了，直接发给浏览器，内容都在 HTML 里，搜索引擎爬虫直接就能爬到，SEO 很好。

// Next.js 页面，直接写，服务端自动渲染成 HTML
export default function Home() {
  return (
    <div>
      <h1>欢迎来到我公司官网</h1>
      <p>我们是做技术服务的公司...</p>
    </div>
  )
}

现在 HTML 里直接就有内容，搜索引擎能爬到，SEO 好了。

场景二：前端是 React，后端还要单独写个接口，太麻烦

你遇到的问题

你做个全栈应用，前端用 React，后端要单独写个 Node 接口服务，还要部署两个服务，跨域、接口联调，麻烦死了。小项目也要搞这么一套，太浪费时间。

Next.js 怎么解决？Next.js 自带后端能力，你可以在同一个项目里写 API 接口，前端页面和后端接口在同一个项目里，不用单独部署后端服务。

// app/api/hello/route.js，直接写接口
export async function GET() {
  return Response.json({ message: "Hello World" })
}

现在前端和后端在同一个项目里，不用单独写后端服务，部署一个项目就搞定了。

场景三：React 单页应用，首屏加载太慢

你遇到的问题

你的 React 单页应用，打开页面要加载几百 K 的 JS，首屏白屏 2 秒，手机上更慢。用户打开就走了。

Next.js 怎么解决？Next.js 自动做代码分割，每个页面只加载自己需要的 JS，首屏加载快很多，还支持静态生成，页面直接是 HTML，打开更快。

对比纯 React SPANext.js
SEO差（JS 渲染）好（服务端渲染）
首屏速度慢快很多
后端要单独写自带 API 能力
适合场景后台管理系统官网、博客、电商这种 SEO 要求高的
新手最容易踩的坑
  • 客户端组件要加 "use client"：要用 useState、useEffect 这些 React Hooks，文件顶部要加 "use client"，不然会报错。
  • 不要什么都用服务端渲染：复杂交互的部分用客户端组件，简单的内容部分用服务端渲染，平衡性能和交互。
  • 图片要优化：用 Next.js 自带的 Image 组件，自动压缩、自动生成响应式图片，加载更快。
  • 路由是文件系统：Next.js 的路由就是文件目录结构，不用自己配路由，文件放在 app 目录下就自动生成路由了。
