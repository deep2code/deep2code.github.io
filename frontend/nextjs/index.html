Next.js 实战：从你遇到的问题出发

🏷️ Next.js

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Next.js怎么帮你解决。

flowchart TB A[Next.js] --> B[App Router] B --> C[Server Components] C --> D[API Routes]

1. React 做网站 SEO 差

你遇到的问题

纯 React SPA 网站，搜索引擎搜不到。

怎么解决？用 Next.js，支持 SSR/SSG，SEO 好，加载快。

2. App Router 是什么

你遇到的问题

Next.js App Router 是什么？

怎么解决？Next.js 13+ 新的路由方式，基于目录，支持 Server Components。

3. 什么时候用 Next.js

你遇到的问题

什么时候该用 Next.js？

怎么解决？要 SEO、要服务端渲染、要全栈 React 项目。

渲染方式

方式说明
SSR服务端渲染每次请求
SSG构建时静态生成
ISR增量静态再生
新手最容易踩的坑
  • 用 App Router新项目用 App Router，不要用旧的 Pages Router。
  • Server Components能用 Server Components 就用，减少客户端 JS。
