Docker 自托管

# 构建
npm run build

# Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .
RUN npm ci && npm run build
EXPOSE 3000
CMD ["npm", "start"]

性能优化清单

  • 图片优化：用 next/image 自动压缩、格式转换、懒加载
  • 字体优化：用 next/font 自托管字体，避免布局偏移
  • 代码分割：动态 import 重型组件
  • 缓存策略：合理使用 revalidate 和 cache
  • 分析工具：next build --analyze 看 bundle 组成
// next.config.ts
const nextConfig = {
  images: {
    remotePatterns: [
      { protocol: 'https', hostname: 'cdn.example.com' }
    ]
  },
  experimental: {
    optimizePackageImports: ['lucide-react']
  }
}

export default nextConfig
