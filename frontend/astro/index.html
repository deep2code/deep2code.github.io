Astro：从你遇到的问题出发

🏷️ Astro

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Astro怎么帮你解决。

flowchart LR A[写组件] --> B[构建成静态 HTML] B --> C[0 JS 默认] C --> D[加载极快]

1. 博客加载慢

你遇到的问题

用 React 写博客，每个页面加载几百 KB JS。

怎么解决？Astro 默认输出 0 JS 静态 HTML，加载快。

2. 想混用框架组件

你遇到的问题

我想用 React 写评论，Vue 写导航。

怎么解决？Astro 支持 React/Vue/Svelte 混用。

3. SEO 不好做

你遇到的问题

SPA 博客搜索引擎收录不好。

怎么解决？构建时生成静态 HTML，SEO 天生友好。

Astro vs Next.js

对比AstroNext.js
默认 JS0 KB几百 KB
适合内容站复杂应用
新手最容易踩的坑
  • 内容站选 Astro博客、文档站用 Astro 又快又简单。
  • 复杂应用选 Next.js大量交互的应用还是 Next.js。
