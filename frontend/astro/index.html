Astro 入门：从你遇到的问题出发

🏷️ Astro 入门

你做个博客或者内容网站，用 React/Vue 做出来页面很大，加载很慢，大部分内容都是静态的，根本不需要交互。你想做个快一点的网站。

这篇不讲理论，就讲你真的会遇到的问题，以及 Astro 怎么帮你解决。

场景一：做个博客，用 React 做出来加载太慢了

你遇到的问题

你做个技术博客，大部分都是文章内容，只有评论、点赞这种小交互。你用 React 做，打包出来有几百 K 的 JS，首屏加载要 3 秒，手机上更慢。大部分用户打开就走了。

Astro 怎么解决？Astro 默认给你生成纯静态 HTML，不带 JS。只有你加了交互的地方，才加载一点点 JS。你的博客网站，默认加载只有几十 K，比 React 快 10 倍。

---
// Astro 组件，直接写 HTML，默认不带 JS
const posts = await getPosts();
---

<html>
  <body>
    <h1>我的博客</h1>
    {posts.map(post => (
      <a href={post.url}>{post.title}</a>
    ))}
  </body>
</html>

这个组件打包完就是纯 HTML，几乎没有 JS，加载飞快。

场景二：这个页面用 React，那个页面用 Vue，能不能混着用

你遇到的问题

你有的组件是 React 写的，有的是 Vue 写的，用一个框架做网站，另一个框架的组件用不了，很麻烦。

Astro 怎么解决？Astro 支持混用：你可以在一个 Astro 页面里，同时用 React 组件和 Vue 组件，不用全换成同一个框架。

---
import ReactCounter from './ReactCounter.jsx';
import VueButton from './VueButton.vue';
---

<h1>混用组件</h1>
<ReactCounter />
<VueButton />

场景三：做内容网站，要 SEO 好，搜索引擎能爬到内容

你遇到的问题

你用 React 做的单页应用，内容都是 JS 动态渲染的，搜索引擎爬虫爬不到内容，搜不到你的网站，SEO 很差。

Astro 怎么解决？Astro 生成的是纯静态 HTML，所有内容都在 HTML 里，搜索引擎爬虫直接就能爬到，SEO 特别好，很适合做博客、文档、营销网站。

对比React SPAAstro
默认 JS 大小几百 K几 K 甚至 0
加载速度慢快很多
SEO差（JS 渲染）好（纯 HTML）
交互能力很强可以加，也很强
适合场景复杂交互应用内容类网站（博客、文档）
新手最容易踩的坑
  • Astro 默认不加载 JS：你加了 React/Vue 组件，默认是静态渲染的，要加 client:load 才会 hydration 成可交互的。
  • 不要拿 Astro 做复杂后台：Astro 适合内容类网站，做复杂的后台管理系统还是用 React/Vue 更合适。
  • 图片要优化：Astro 自带图片优化，把大图自动压缩成小格式，加载更快，记得用。
  • MD 写文章很方便：博客文章直接写 Markdown，Astro 自动生成页面，不用写 HTML。
