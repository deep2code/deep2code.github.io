岛屿架构与组件

部分水合指令

Astro 最核心的概念：什么时候 hydrate 组件。

指令什么时候水合适用场景
client:load页面加载后立即水合导航栏、搜索框
client:visible组件进入视口才水合页脚评论、侧边栏
client:idle浏览器空闲时水合非关键交互组件
client:only完全客户端渲染地图、图表
 
---
// 不水合：纯静态，0KB JS
import Clock from '../components/ReactClock.jsx'
---

<Clock />  

<Clock client:load />  
<Clock client:visible />  
<Clock client:idle />

多框架支持

Astro 可以混用 React、Vue、Svelte 组件：

---
import ReactCounter from './ReactCounter.jsx'
import VueButton from './VueButton.vue'
import SvelteChart from './SvelteChart.svelte'
---

<ReactCounter client:load />
<VueButton client:visible />
<SvelteChart client:only />
