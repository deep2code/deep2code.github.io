App 上架：开发完只是开始，上架才是真正的考验

我第一次提交 App Store 审核，被打回三次，理由一个比一个玄学：「你的应用没有足够价值」「请提供隐私政策链接」。开发一个月，上架花了三周。这篇把我踩过的坑整理出来，让你少走弯路。

先认清现实

海外：App Store + Google Play 两家；国内：华为、小米、OPPO、vivo、应用宝、魅族……七八家商店一家一家传。国内上架要软著、要备案、要各种资质，别以为做完一个安装包就完事。

上架前的准备清单

事项说明
开发者账号App Store $99/年，Google Play $25 一次性
隐私政策必备链接，不提供必被拒
软著/备案国内商店要求，提前 1 个月办
应用截图各家尺寸要求不同，按规格切
签名Android 用 keystore，iOS 用证书
权限说明为什么要相机/定位，写清楚
必坑：隐私政策

我第一次被打回就是因为没放隐私政策链接。现在各家商店对隐私合规查得极严，收集任何个人信息都要有政策说明。提前准备好，别等被打回才补。

App Store：审核最严的一关

App Store 审核是玄学。我整理了一个典型流程：

flowchart TD A[Xcode 上传归档] --> B[App Store Connect 创建应用] B --> C[填元信息 截图 描述] C --> D[提交审核] D --> E{审核通过?} E -->|拒绝| F[看拒绝理由 修改 重新提交] F --> D E -->|通过| G[正式发布 灰度或全量]

审核时长参考：快的一天，慢的一周。我最长等过 9 天，急得不行。小技巧：新应用尽量在周四前提交，周五提交经常拖到下周一。

常见被拒原因

  • 崩溃或 bug：审核员真的会点，有崩溃直接拒；
  • 隐私政策缺失：上面说过了；
  • 权限用途不明：要了定位但没解释干嘛用；
  • 占位符内容：审核时别放假数据/未完成页面；
  • 引导行为：不能弹窗让用户好评、评分。

国内安卓商店：最累的一关

国内安卓没有 Google Play，要一家一家传。最麻烦的是资质审核：

商店要求审核时长
华为应用市场软著 + 隐私政策1-3 天
小米应用商店软著 + ICP 备案1-3 天
OPPO/vivo类似1-3 天
应用宝腾讯系1-3 天

我的经验：软著和 ICP 备案提前一个月办，这两个是硬门槛，办不下来其他都免谈。国内商店审核比 App Store 宽松，但材料多，一家一家传很耗时间。

签名和更新策略

Android 签名配置别写在 build.gradle 里硬编码密码，我一般放 root 的 keystore.properties（不提交 git）：

// android/keystore.properties（加入 .gitignore）
storeFile=/Users/junjunyi/keystore/my-release.keystore
storePassword=MyStr0ng#Pass
keyAlias=release
keyPassword=MyStr0ng#Pass

// android/app/build.gradle
def keystoreProps = new Properties()
keystoreProps.load(new FileInputStream(rootProject.file("keystore.properties")))

android {
    signingConfigs {
        release {
            storeFile file(keystoreProps['storeFile'])
            storePassword keystoreProps['storePassword']
            keyAlias keystoreProps['keyAlias']
            keyPassword keystoreProps['keyPassword']
        }
    }
    buildTypes {
        release { signingConfig signingConfigs.release }
    }
}
Android 签名密钥别丢

Android 的 keystore 丢了，以后就发不了更新——应用商店认签名。我同事真丢过 keystore，只能重新发一个新应用，老用户没法升级。密钥备份到至少两个安全地方。

更新别一次性全量发布，用灰度发布：先放 10% 用户观察崩溃率，没问题再放量。App Store 和 Google Play 都支持分阶段发布，国内商店大多也支持。

2024-2026 的新变化

  • 隐私清单：App Store 要求声明每个 API 干嘛用，审核更严；
  • 数据收集披露：必须在 App Store 页面列出收集哪些数据；
  • AI 相关：集成 AI 功能要特别声明；
  • 支付：iOS 对外部抽成有新政策，小开发者有优惠。
flowchart TD A[开发完成] --> B[准备资质 软著 隐私政策] B --> C[各家商店提交] C --> D[审核] D --> E[灰度发布 10%] E --> F[观察崩溃率] F --> G{有问题?} G -->|有| H[热修复或回滚] G -->|无| I[全量发布]

FAQ

Q：个人开发者能上架吗？
能。App Store 个人账号 $99/年可以上，Google Play $25 一次性。国内安卓商店个人开发者部分支持，但企业主体过审更顺。

Q：被拒了怎么办？
仔细读拒绝邮件，按理由改，礼貌回复审核员。很多拒绝是沟通问题，不是代码问题。别反复硬提交，会被标记。

Q：一个 App 要传几个商店？
海外传 App Store + Google Play 就够。国内建议华为、小米、OPPO、vivo、应用宝这五家，覆盖 90% 安卓用户。魅族、三星等可选。

Q：上架后能改名字/图标吗？
能，但要重新审核。改名太频繁会被商店降权，起名要想好。

小结

上架不是技术活，是流程活。提前把软著、隐私政策、账号备齐，按各家要求传材料，比开发本身还磨人。做好心理准备：开发一个月，上架一两周是常态。
