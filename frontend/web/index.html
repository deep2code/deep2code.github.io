HTTP 入门：从你遇到的问题出发

🏷️ HTTP 入门

你打开一个网页，输入 URL，回车，页面就出来了。你有没有想过：浏览器和服务器之间到底说了什么？为什么有的网站是 https，有的是 http？

这篇不讲理论，就讲你真的会遇到的问题，以及 HTTP 是怎么回事。

场景一：为什么有的网站打不开，显示"连接被重置"

你遇到的问题

你输入一个网址，回车，浏览器转了半天，显示"连接被重置"。你不知道是哪里出问题了：是网断了？是服务器挂了？还是 URL 写错了？

HTTP 是怎么回事？HTTP 就是浏览器和服务器之间说话的规则。你输入 URL，浏览器按照这个规则，给服务器发消息："我要这个页面"，服务器收到消息，按照规则回消息："这是你要的页面"。如果中间任何一步出问题，就打不开了。

# 浏览器给服务器发的消息长这样
GET /index.html HTTP/1.1
Host: www.yourcompany.com

# 服务器回的消息长这样
HTTP/1.1 200 OK
Content-Type: text/html

...

场景二：为什么有的网站是 http，有的是 https？

你遇到的问题

你打开有的网站，地址栏是 http://，有的是 https://。你问：这两个有什么区别？为什么银行、支付宝都是 https？

HTTPS 就是加密的 HTTP。普通的 HTTP 是明文说话，你发的消息在路上谁都能看到。HTTPS 是加密的，你发的消息只有服务器能看懂，别人就算截到了也看不懂，安全。所以涉及密码、钱的网站都用 HTTPS。

对比HTTPHTTPS
加密不加密，明文加密，安全
端口80443
浏览器提示不安全安全（小锁）
费用免费要申请 SSL 证书（现在也免费了）

场景三：为什么有的页面打开很慢？

你遇到的问题

你打开一个网页，转了 5 秒才出来。你不知道是哪里慢：是网慢？是服务器慢？还是页面太大了？

HTTP 状态码告诉你是怎么回事。服务器回消息的时候，会带一个状态码，告诉你结果怎么样：

状态码什么意思
200成功了，一切正常
301 / 302重定向，跳转到别的地址了
404找不到，你要的页面不存在
500服务器内部错误，服务器出问题了
502 / 504网关错误，服务器没响应
新手最容易踩的坑
  • 不要用 http 传密码：明文传密码，路上谁都能截到，一定要用 https。
  • 404 不是你网断了：404 是页面不存在，不是网的问题，检查 URL 对不对。
  • 500 是服务器的问题：500 是服务器内部错误，不是你浏览器的问题，找后端排查。
  • 缓存能让页面快很多：第一次加载完，第二次从本地缓存拿，不用再去服务器要了。
