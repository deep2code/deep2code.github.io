HTTP：从你遇到的问题出发

🏷️ HTTP

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及HTTP怎么帮你解决。

flowchart LR A[浏览器] -->|HTTP 请求| B[服务器] B -->|HTTP 响应| A

1. 前端调接口跨域

你遇到的问题

你前端页面是 a.com，接口是 b.com，浏览器报错跨域。

怎么解决？服务器配 CORS，或者用代理转发。

2. HTTPS 怎么配

你遇到的问题

网站要上 HTTPS，不知道怎么弄。

怎么解决？用 Let's Encrypt 免费证书，Nginx 配置一下就行。

3. GET 和 POST 区别

你遇到的问题

什么时候用 GET，什么时候用 POST？

怎么解决？GET 查数据，POST 提交数据；GET 参数在 URL，POST 在 body。

常用状态码

状态码含义
200成功
301/302重定向
400参数错误
401未登录
403没权限
404找不到
500服务器错误
新手最容易踩的坑
  • 不要迷信 HTTP/3大部分场景 HTTP/1.1 足够，不用追求最新版本。
  • HTTPS 一定要上HTTP 现在浏览器都标不安全，一定要上 HTTPS。
