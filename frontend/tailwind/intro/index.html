Tailwind CSS v4 入门

Tailwind 是什么

Tailwind CSS 是一个实用优先的 CSS 框架。不是给你预写好的组件（比如 Bootstrap 的 .btn-primary），而是给你一堆小的工具类，直接在 HTML 里组合。

方式传统 CSSTailwind
命名自己想类名工具类，不用想
文件大小越写越大JIT 后很小
复用抽组件React/Vue 组件
开发速度慢快

传统 CSS vs Tailwind

v4 新特性

2026 年 Tailwind v4 已经发布，主要变化：

  • Oxide 引擎：Rust 编写，速度快 10 倍
  • CSS-first 配置：不用 tailwind.config.js 了，直接在 CSS 里配置
  • 原生 CSS 嵌套：直接用 CSS 嵌套语法
  • 零配置安装：npm 包体积小很多
# 安装
npm install tailwindcss @tailwindcss/cli

# 构建
npx @tailwindcss/cli -i input.css -o output.css --watch
