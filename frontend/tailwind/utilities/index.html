Tailwind 工具类速查：从你遇到的问题出发

🏷️ Tailwind 速查

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Tailwind 速查怎么帮你解决。

flowchart TB A[Tailwind] --> B[布局] B --> C[间距] C --> D[颜色] D --> E[字体]

1. 记不住类名

你遇到的问题

用 Tailwind 老是记不住类名，要查文档。

怎么解决？常用的就那几十个，记熟了写起来很快。

2. 常用布局类

你遇到的问题

常用布局类有哪些？

怎么解决？flex、grid、items-center、justify-between、w-full、h-screen。

3. 常用间距类

你遇到的问题

常用间距类有哪些？

怎么解决？p-*（内边距）、m-*（外边距）、gap-*（间距）。

常用类速查

类别常用类说明
布局flex / grid / block显示方式
对齐items-center / justify-betweenFlex 对齐
间距p-4 / m-2 / gap-3内/外边距、间距
宽度w-full / w-1/2宽度
颜色bg-blue-500 / text-gray-600背景/文字色
字体text-sm / font-bold字号/字重
新手最容易踩的坑
  • 不要每次都查常用的几十个性记熟，写起来比 CSS 快。
  • 响应式加前缀sm:、md:、lg:，不同断点不同样式。
