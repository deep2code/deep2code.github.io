Tailwind CSS：从你遇到的问题出发

🏷️ Tailwind

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Tailwind怎么帮你解决。

flowchart LR A[HTML 里写原子类] --> B[Tailwind] B --> C[生成用到的 CSS] C --> D[页面样式完成]

1. CSS 文件越来越大

你遇到的问题

项目大了 CSS 几万行，不知道哪些样式没用。

怎么解决？Tailwind 只生成你用到的样式，产物很小。

2. 起类名起疯了

你遇到的问题

你在为一个按钮叫 btn-primary-lg 还是 button-main 纠结。

怎么解决？不用起类名，直接在 HTML 里写样式类。

3. 改样式要切文件

你遇到的问题

改个颜色要切到 CSS 文件找半天。

怎么解决？直接在 HTML 里改 class，不用切文件。

常用原子类
