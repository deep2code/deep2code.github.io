Tailwind CSS 实战：从你遇到的问题出发

🏷️ Tailwind CSS

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Tailwind CSS怎么帮你解决。

flowchart TB A[Tailwind] --> B[原子化] B --> C[响应式] C --> D[暗色模式]

1. 响应式怎么写

你遇到的问题

要适配手机/平板/桌面，怎么写响应式？

怎么解决？Tailwind 用前缀，sm: md: lg: 不同屏幕用不同 class。

2. 暗色模式怎么做

你遇到的问题

要做暗色模式怎么弄？

怎么解决？Tailwind 内置暗色模式，dark: 前缀，配 class="dark" 切换。

3. 组件样式怎么复用

你遇到的问题

多个组件要用一样的样式，重复写 class 太麻烦。

怎么解决？用 @apply 抽成 CSS 类，或者直接做组件。

响应式前缀

前缀屏幕大小
sm:640px+
md:768px+
lg:1024px+
xl:1280px+
新手最容易踩的坑
  • 不要滥用 @apply@apply 不要用太多，不然又回到写 CSS 了。
  • 用 CDN 先试试新手可以先用 CDN 版试试，不用装构建工具。
