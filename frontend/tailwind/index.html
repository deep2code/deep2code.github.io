Tailwind CSS 实战：从你遇到的问题出发

🏷️ Tailwind CSS

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Tailwind CSS怎么帮你解决。

flowchart TB A[HTML 写 class] --> B[Tailwind 编译] B --> C[生成 CSS] C --> D[页面样式]

1. 写 CSS 太麻烦

你遇到的问题

写 CSS 要想类名、分文件、层级多了乱。

怎么解决？用 Tailwind，原子化 CSS，直接在 HTML 写 class，不用想类名。

2. Tailwind 是什么

你遇到的问题

Tailwind CSS 是什么？

怎么解决？原子化 CSS 框架，一堆小 class 组合出样式。

3. 怎么开始用

你遇到的问题

怎么开始用？

怎么解决？装 tailwindcss，配 config，HTML 里直接写 class。

常用 class

功能class
边距m-4 / p-4
颜色text-blue-500 / bg-gray-100
布局flex / grid
新手最容易踩的坑
  • 新项目都用新项目做样式直接用 Tailwind，快很多。
  • 不要自定义太多尽量用默认值，不要改太多配置。
