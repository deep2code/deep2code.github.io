Tailwind CSS 入门：从你遇到的问题出发

🏷️ Tailwind CSS 入门

你写 CSS，要想一堆类名：container、header、box、btn-primary……写了一堆 CSS 文件，改个样式要翻半天，还怕类名冲突。

这篇不讲理论，就讲你真的会遇到的问题，以及 Tailwind 怎么帮你解决。

场景一：写 CSS 要想一堆类名，还经常冲突

你遇到的问题

你写页面，先想类名：这个容器叫什么？box？container？wrapper？然后写 .box { ... }，过两天另一个页面也有个 box，样式不一样，冲突了，越改越乱。CSS 文件越写越大，几 K 变成几百 K，找个样式翻半天。

Tailwind 怎么解决？不用想类名，直接在 HTML 里写样式。一个按钮就是：<button class="bg-blue-500 px-4 py-2 rounded">，直接写在 class 里，不用写单独的 CSS 文件，也不用想类名。



场景二：改个样式，要翻 CSS 文件找半天





你遇到的问题


产品说按钮要大一点，颜色要深一点。你要先找到按钮的类名，再翻 CSS 文件找到对应的样式，改完还要刷新看效果，来来回回折腾半天。





Tailwind 怎么解决？样式直接写在 HTML 里，你直接在按钮那行改就行，不用翻 CSS 文件。比如要大一点，加个 px-6 py-3，要深一点，把 bg-blue-500 改成 bg-blue-600，直接改，10 秒搞定。




场景三：手机端和电脑端样式不一样，写一堆 media query





你遇到的问题


电脑端是三列布局，手机端是一列。你要写一堆 @media (max-width: 768px) 的代码，又长又乱，还容易错。





Tailwind 怎么解决？直接加前缀就行，手机端和电脑端的样式直接写在 class 里，不用写 media query。

Tailwind 类作用



px-4 py-2左右内边距 16px，上下 8px


bg-blue-500背景色蓝色


text-white文字白色


rounded圆角


flex items-center弹性布局，垂直居中








新手最容易踩的坑


    

  • 不要写一堆重复的类：按钮、卡片这些重复的组件，抽成 React/Vue 组件，不要每次都写一堆类。
    • 

  • 不要用 Tailwind 内联所有样式：复杂的自定义样式还是写单独的 CSS，不要全堆在 class 里。
    • 

  • 生产环境要压缩：默认会把没用到的类删掉，生成的 CSS 文件很小，不用怕文件太大。
    • 

  • 不要硬记所有类：常用的记一下，不常用的查文档就行，不用全背下来。
