最佳实践与组织

不要复制粘贴类名

很多人用 Tailwind 最大的误区：在每个 HTML 里复制粘贴一长串类名。正确做法是抽成组件。

// ❌ 不好：到处复制粘贴


// ✅ 好：抽成 React 组件
function Button({ variant = 'primary', children, ...props }) {
  const variants = {
    primary: 'bg-blue-500 hover:bg-blue-600',
    secondary: 'bg-gray-200 hover:bg-gray-300',
    danger: 'bg-red-500 hover:bg-red-600',
  }
  return (
    
  )
}

用 @apply 抽公共类

/* styles.css */
@layer components {
  .btn {
    @apply px-4 py-2 rounded-md font-medium transition-colors;
  }
  .btn-primary {
    @apply btn bg-blue-500 text-white hover:bg-blue-600;
  }
  .input {
    @apply w-full px-3 py-2 border border-gray-300 rounded-md;
  }
}

生产优化

  • JIT 模式：只生成用到的类，CSS 体积从 MB 降到 KB
  • PurgeCSS：自动删除未使用的样式
  • CSS 变量：主题色用 CSS 变量，方便换肤
  • 暗色模式：用 dark: 变体，不用写两套样式
shadcn/ui：2026 年最流行的用法是 Tailwind + shadcn/ui。不是组件库，而是给你复制粘贴组件代码，你完全拥有这些组件，可以随便改。
