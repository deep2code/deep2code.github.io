Flutter 入门：从你遇到的问题出发

🏷️ Flutter

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Flutter怎么帮你解决。

flowchart TB A[Flutter] --> B[一套代码] B --> C[Android] B --> D[iOS] B --> E[Web]

1. 跨端开发选什么

你遇到的问题

要做 App，Android 和 iOS 都要做，两套代码维护麻烦。

怎么解决？用 Flutter，一套代码同时跑 Android/iOS/Web。

2. Flutter 是什么

你遇到的问题

Flutter 是什么？

怎么解决？Google 开源的跨端 UI 框架，一套代码多端运行。

3. 和 RN 区别

你遇到的问题

Flutter 和 React Native 区别？

怎么解决？Flutter 自绘 UI，性能好；RN 用原生组件，性能一般。

对比

对比FlutterRN
性能好（自绘）一般
UI 一致性高中

新手最容易踩的坑
  • 新手学 DartFlutter 用 Dart 语言，简单好学。
  • 一套代码多端一套代码同时跑 Android/iOS/Web，省成本。
