Vue 实战：从你遇到的问题出发

🏷️ Vue

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Vue怎么帮你解决。

flowchart TB A[Vue] --> B[模板] B --> C[响应式] C --> D[组件]

1. Vue 怎么学

你遇到的问题

想学习 Vue，怎么开始？

怎么解决？先学 HTML/CSS/JS 基础，再学 Vue 3（Composition API）。

2. Vue 3 新特性

你遇到的问题

Vue 3 有什么新特性？

怎么解决？Composition API、性能更好、TypeScript 支持好。

3. 状态管理选什么

你遇到的问题

Vue 状态管理选什么？

怎么解决？Pinia，Vue 官方推荐，替代 Vuex。
