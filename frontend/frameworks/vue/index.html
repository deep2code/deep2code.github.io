Vue 入门：从你遇到的问题出发

🏷️ Vue 入门

你想快速写个交互页面，不想学 React 那么多概念，模板写法简单直观，上手快。或者你刚进公司，发现项目全是 Vue 写的。

这篇不讲理论，就讲你真的会用到的 Vue 知识，以及常见的坑。

场景一：不想学 React 那么多概念，想快速上手

你遇到的问题

你看了 React 的教程，JSX、Hooks、状态管理，一堆概念，学了一周还是懵的。你就想快速写个表单页、个列表页，为什么要搞这么复杂？

Vue 怎么解决？模板写法，就像写 HTML 一样，加几个指令就行，直观，上手快。

<template>
  <div>
    <h3>{{ product.name }}</h3>
    <p>¥{{ product.price }}</p>
    <button @click="like" :class="{ liked: isLiked }">
      {{ isLiked ? '已收藏' : '收藏' }}
    </button>
  </div>
</template>

<script setup>
import { ref, reactive } from 'vue'

const product = reactive({ name: 'iPhone 16', price: 5999 })
const isLiked = ref(false)

function like() {
  isLiked.value = !isLiked.value
}
</script>

就这么简单。模板就是普通 HTML，加个 {{ }} 渲染数据，@click 绑事件，:class 绑样式。比 JSX 直观多了。

场景二：写个登录表单，提交后要验证

你遇到的问题

你要写个登录页，有用户名、密码两个输入框，点登录要先验证是不是空的，然后调接口提交。用原生 JS 写要拿 DOM、取 value、验证，写一堆代码。

Vue 怎么解决？双向绑定，输入框的值自动同步到变量，不用手动取 DOM。

<template>
  <div>
    <input v-model="username" placeholder="用户名" />
    <input v-model="password" type="password" placeholder="密码" />
    <button @click="login">登录</button>
    <p v-if="error" style="color:red">{{ error }}</p>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const username = ref('')
const password = ref('')
const error = ref('')

async function login() {
  if (!username.value) {
    error.value = '用户名不能为空'
    return
  }
  if (!password.value) {
    error.value = '密码不能为空'
    return
  }
  // 调接口登录
  console.log('登录', username.value, password.value)
}
</script>

现在输入框的值自动绑定到 username 和 password，你直接用就行，不用去拿 DOM。错误信息用 v-if 控制显示，也很简单。

场景三：渲染一个商品列表，点删除要更新

你遇到的问题

你有一个商品列表，点删除按钮要删掉对应的商品。用原生 JS 要找到那个元素，从数组里删掉，再重新渲染整个列表，麻烦死了。

Vue 怎么解决？数据变了，界面自动变。你只要改数组，列表自动更新。

<template>
  <div>
    <div v-for="item in products" :key="item.id">
      <span>{{ item.name }} - ¥{{ item.price }}</span>
      <button @click="remove(item.id)">删除</button>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const products = ref([
  { id: 1, name: '苹果', price: 5 },
  { id: 2, name: '香蕉', price: 3 },
  { id: 3, name: '橙子', price: 4 },
])

function remove(id) {
  products.value = products.value.filter(p => p.id !== id)
}
</script>

现在你只要改 products 数组，列表自动就更新了。不用手动操作 DOM。

常用指令什么时候用
{{ }}渲染数据，显示变量
v-if / v-else条件显示，满足条件才渲染
v-for循环渲染列表
v-model双向绑定，表单输入框用
@click绑定点击事件
:src / :class绑定属性，src、class 这些
新手最容易踩的坑
  • ref 的值要 .value：在 script 里用 ref 定义的变量，要加 .value 才能改值，模板里不用。
  • v-for 一定要加 key：不加 key 会出 bug，key 要唯一。
  • 不要在 v-for 里用 index 当 key：列表会增删的话，用 id 当 key。
  • Vue 2 和 Vue 3 写法不一样：现在新项目都用 Vue 3 + Composition API，别学老的 Options API 了。
