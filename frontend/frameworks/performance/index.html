前端性能优化：从你遇到的问题出发

🏷️ 前端性能

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及前端性能怎么帮你解决。

flowchart TB A[加载慢] --> B[资源优化] B --> C[图片压缩] C --> D[代码分割] D --> E[缓存]

1. 首屏加载太慢

你遇到的问题

网站打开要 3 秒多，用户都跑了。

怎么解决？做前端性能优化：压缩资源、代码分割、图片优化、缓存。

2. 优化方向

你遇到的问题

前端性能优化主要方向有哪些？

怎么解决？加载性能、渲染性能、运行性能。

3. 常用手段

你遇到的问题

常用优化手段有哪些？

怎么解决？压缩、代码分割、懒加载、CDN、缓存。

常用手段

手段说明
代码分割按路由分块加载
图片优化压缩、WebP、懒加载
CDN静态资源放 CDN
缓存浏览器/CDN 缓存
新手最容易踩的坑
  • 先测再优化先用 Lighthouse 测，看哪慢再优化，不要瞎改。
  • 图片优化收益最大图片优化一般是收益最大的。
