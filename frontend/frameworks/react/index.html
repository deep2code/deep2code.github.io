React 实战：从你遇到的问题出发

🏷️ React

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及React怎么帮你解决。

flowchart TB A[React] --> B[组件] B --> C[Hooks] C --> D[状态]

1. React 怎么学

你遇到的问题

想学习 React，怎么开始？

怎么解决？先学 JS 基础，再学 React 基础（组件、props、state、Hooks）。

2. React Hooks

你遇到的问题

React Hooks 是什么？

怎么解决？函数组件里用状态和生命周期的 API，useState、useEffect 最常用。

3. 状态管理选什么

你遇到的问题

React 状态管理选什么？

怎么解决？小项目用 Zustand，大型项目用 Redux Toolkit。

Hook说明

新手最容易踩的坑
  • 先学基础先学组件、props、state、Hooks 基础。
  • 不要过度设计小项目不要上 Redux，Context/Zustand 够了。
