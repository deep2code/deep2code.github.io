React 入门：从你遇到的问题出发

🏷️ React

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及React怎么帮你解决。

flowchart LR A[UI] --> B[组件化] B --> C[JSX] C --> D[Hooks] D --> E[状态管理]

1. React 为什么这么火

你遇到的问题

听说 React 很流行，为什么？

怎么解决？组件化、虚拟 DOM、生态大，大厂都用。

2. 组件化是什么

你遇到的问题

React 天天说组件化，到底是什么？

怎么解决？把页面拆成一个个独立组件，复用，好维护。

3. Hooks 是什么

你遇到的问题

听说 React Hooks，是什么意思？

怎么解决？函数组件里用状态和生命周期的方式，现在 React 都用 Hooks。

React 特点

特点说明
组件化UI 拆成组件
JSXHTML 写在 JS 里
虚拟 DOM性能优化
单向数据流数据流向清晰
新手最容易踩的坑
  • 先学 Hooks不要学老的 Class 写法，直接学 Hooks。
  • 状态管理按需用小项目不用 Redux/Zustand，大项目再加。
