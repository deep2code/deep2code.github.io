前端工程化：从你遇到的问题出发

🏷️ 前端工程化

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及前端工程化怎么帮你解决。

flowchart TB A[前端工程化] --> B[构建工具] B --> C[代码规范] C --> D[自动化测试] D --> E[CI/CD]

1. 多人协作代码乱

你遇到的问题

多人写前端代码，风格不统一，提交完经常冲突。

怎么解决？做前端工程化，统一规范、自动检查、自动构建部署。

2. 工程化包括什么

你遇到的问题

前端工程化包括哪些？

怎么解决？构建工具（Vite/Webpack）、代码规范（ESLint/Prettier）、自动化测试、CI/CD。

3. 新手怎么开始

你遇到的问题

新手怎么开始搞工程化？

怎么解决？先把构建工具和代码规范配好，其他慢慢来。

常用工具

类别工具
构建Vite / Webpack
规范ESLint / Prettier
测试Vitest / Jest
新手最容易踩的坑
  • 先从构建开始先把构建工具配好，再搞其他的。
  • 配置自动提交检查配 husky，提交前自动检查代码规范。
