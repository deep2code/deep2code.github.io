TypeScript 实战：从你遇到的问题出发

🏷️ TypeScript

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及TypeScript怎么帮你解决。

flowchart TB A[JS] --> B[加类型] B --> C[编译时检查] C --> D[少出 bug]

1. JS 类型错了运行才发现

你遇到的问题

JS 写项目，类型错了运行到那才报错，容易出 bug。

怎么解决？用 TypeScript，编译时就检查类型，提前发现问题。

2. TS 是什么

你遇到的问题

TypeScript 是什么？

怎么解决？JS 的超集，加了类型系统，编译成 JS 运行。

3. 新手怎么学

你遇到的问题

新手怎么学 TypeScript？

怎么解决？先会 JS，再学基础类型（string/number/boolean/interface/type）。

基础类型

类型说明
string/number/boolean基础类型
interface/type对象类型
union联合类型
新手最容易踩的坑
  • 新项目都用 TS新项目都用 TypeScript，不要用纯 JS 了。
  • 不要开 any尽量不要用 any，用了等于白写 TS。
