Zustand 入门：从你遇到的问题出发

🏷️ Zustand 入门

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Zustand 入门怎么帮你解决。

flowchart TB A[创建 store] --> B[组件 useStore] B --> C[状态变自动更新] C --> D[按需订阅]

1. React 全局状态乱

你遇到的问题

用 Context 传状态，改一个值所有组件都重渲染。

怎么解决？用 Zustand，轻量状态管理，按需订阅，不会不必要的重渲染。

2. Zustand 核心概念

你遇到的问题

Zustand 核心概念有哪些？

怎么解决？create 创建 store、useStore 取状态、set 更新状态。

3. 和 Redux 区别

你遇到的问题

Zustand 和 Redux 区别？

怎么解决？Zustand 简单轻量，不用写 action/reducer；Redux 重，适合大型项目。

对比

对比ReduxZustand
体积大小（~1KB）
样板代码多少
学习曲线陡平缓
新手最容易踩的坑
  • 小项目用 Zustand中小项目用 Zustand，不要上来就 Redux。
  • 状态要分 store不同模块分开 store，不要都放一个大 store。
