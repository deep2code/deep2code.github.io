Zustand 入门

Zustand 是什么

Zustand（德语"状态"）是一个极简 React 状态管理库。只有 2KB，没有 Provider，没有 reducer，没有 action type，写起来就是普通的 JS 函数。

特性ReduxContext + useReducerZustand
包大小~10KB0~2KB
样板代码多中极少
重渲染可控全量精准订阅
Provider需要需要不需要
DevTools极好无内置支持

第一个 Store

import { create } from 'zustand'

interface UserState {
  user: User | null
  isLoading: boolean
  login: (email: string, password: string) => Promise
  logout: () => void
}

export const useUserStore = create((set) => ({
  user: null,
  isLoading: false,
