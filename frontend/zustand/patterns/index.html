高级模式与最佳实践

持久化

import { create } from 'zustand'
import { persist } from 'zustand/middleware'

export const useUserStore = create()(
  persist(
    (set) => ({
      user: null,
      login: async (email, password) => { ... },
      logout: () => set({ user: null }),
    }),
    {
      name: 'user-storage', // localStorage key
    }
  )
)

immer 中间件

import { immer } from 'zustand/middleware/immer'

export const useCartStore = create()(
  immer((set) => ({
    items: [],
    addItem: (product) => set((state) => {
      // 直接修改， immer 帮你处理不可变更新
      state.items.push(product)
    }),
  }))
)

最佳实践

  • 按领域拆分 store：用户 store、购物车 store、UI store，不要一个大 store
  • 选择器函数：只订阅需要的字段，避免多余重渲染
  • 服务端状态用 React Query：Zustand 管客户端状态，React Query 管服务端状态
  • 不要存太多：URL 里有的、localStorage 能存的，就别放 store 里

什么时候不用 Zustand

  • 简单组件状态：useState 就够了
  • 服务端数据：用 React Query/SWR
  • 表单状态：用 React Hook Form
