gRPC

gRPC 是什么

gRPC 是 Google 开源的跨语言高性能 RPC 框架，基于 HTTP/2 传输与 Protocol Buffers（protobuf） 二进制序列化，天然支持多路复用、双向流式通信与跨语言代码生成。服务间以 .proto 文件定义契约，由 protoc 生成各语言客户端/服务端骨架，是微服务、云原生架构中最常见的服务间调用协议之一。

截至 2026 年，gRPC-Go 已迭代到 v1.8x 系列（v1.81.1 于 2026 年 5 月发布），并开始要求 Go 1.25+；生态侧 gRPC-Web 2.x、Protobuf Editions、Buf Connect 协议均进入生产可用阶段（详见文末「2026 生态更新」）。

gRPC 2026 生态更新

gRPC-Go 版本与安全

  • 版本节奏：gRPC-Go 保持月度小版本迭代，2026 年 5 月发布 v1.81.1（安全修复版），年中已推进到 v1.8x；v1.81 起最低支持 Go 1.25，建议随 Go 1.26 一起升级。
  • 安全加固：2026 年上半年披露并修复了 xDS RBAC 鉴权绕过（GO-2026-6061 等）——升级 xDS 场景务必同步跟进补丁版本，避免 URI/DNS SAN 匹配回退导致的未授权访问。
  • 可观测性：v1.81 起 per-call metrics 支持自定义标签（gRFC A108），客户端/服务端 RPC 指标与链路分离，配合 OpenTelemetry 采集更干净。

HTTP/3 与 QUIC

面向弱网、高丢包与移动端场景，基于 QUIC 的 HTTP/3 传输逐步进入 gRPC 生态：连接建立从 1-RTT 降到 0-RTT，并从根本上消除 HTTP/2 的 TCP 层队头阻塞。gRPC-Go 与 C-core 均以实验/预览方式支持 QUIC 客户端通道，2026 年尚未全量默认开启，生产接入前需评估服务端与中间链路（负载均衡、防火墙 UDP 放行）的兼容性。

生态新进展

  • gRPC-Web 2.x：2025 年发布 2.0，支持 Protobuf Editions 并使用新代码生成 API，浏览器直连 gRPC 服务（经 Envoy/gRPC-Web 代理）更成熟。
  • Protobuf Editions：proto3 演进为 Editions 版本模型，统一管理字段行为与平台特性；2026 年各语言插件与 buf 均已全面支持。
  • Buf 工具链：buf 一站式管理 lint、breaking 检查与代码生成，替代裸 protoc + 插件拼装，是 Go 项目推荐做法。
  • Connect-RPC：Buf 推出的 Connect 协议与 gRPC 双向兼容，同时暴露 HTTP/JSON 端点，无需 grpc-gateway 即可被浏览器与普通客户端访问（见下节）。

Buf 工具链（推荐）

buf 是现代 Protobuf 管理工具，替代 protoc + 各种插件：

# 安装 buf
brew install bufbuild/buf/buf

# buf.gen.yaml - 代码生成配置
version: v2
plugins:
  - local: protoc-gen-go
    out: gen/go
  - local: protoc-gen-go-grpc
    out: gen/go
  - local: protoc-gen-connect-go
    out: gen/go

# 生成代码
buf generate

# 检查兼容性
buf breaking --against .git#branch=main

Connect-RPC（gRPC 兼容优雅替代）

Connect-RPC 兼容 gRPC 协议，同时支持 HTTP/JSON 客户端，无需 gRPC 代理：

// Go 服务端
import "connectrpc.com/connect"

func main() {
    mux := http.NewServeMux()
    handler := connect.NewHandler(
        pingv1connect.NewPingServiceHandler(&PingServer{}),
    )
    mux.Handle(pingv1connect.NewPingServiceHandler(
        &PingServer{},
    ))
    http.ListenAndServe(":8080", mux)
}

// 客户端可以直接用 HTTP/JSON 调用
// curl -H 'Content-Type: application/json' \
//   -d '{"name":"world"}' \
//   http://localhost:8080/ping.v1.PingService/Ping
