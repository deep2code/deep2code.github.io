Python 可视化：从 Excel 到浏览器

我刚入行时，分析师同事把数据往 Excel 一粘，拉个柱状图就开始讲结论。后来我接手做数据平台，发现「画图」这件事在 Python 里其实分三个完全不同的世界：分析时探索着画、出版时精修着画、网页上交互式画。混用工具是新手最常见的错。这篇按这三条线讲。

先选型再写代码

别急着 import。先问：这张图给谁看？给我自己探索 → Matplotlib/Seaborn；写进论文报告 → Matplotlib 精修；给业务方在网页上点 → Plotly。选错工具，后面全是返工。

Matplotlib：一切的底层

别嫌 Matplotlib 丑，它是 Python 可视化的地基——Seaborn、Pandas 画图、Pyecharts 底层都靠它。

理解它的「Figure / Axes」两层结构，比背十个 API 有用。下图是这个层级关系：

flowchart TD FIG[Figure 整张画布] --> AX1[Axes 第一个坐标系] FIG --> AX2[Axes 第二个子图] AX1 --> L1[Line2D 折线元素] AX1 --> T1[Title 标题] AX2 --> P2[Patch 柱状元素]
  • Figure：整张画布；
  • Axes：画布上的一个坐标系（一张图可以有多个 Axes 子图）。

新手最大的困惑是「plt.plot 和 ax.plot 到底用哪个」。我的建议是：直接用面向对象的 ax 写法，别用 pyplot 状态机那套，不然子图一多就乱：

import matplotlib.pyplot as plt
import numpy as np

fig, ax = plt.subplots(figsize=(6, 4))
x = np.linspace(0, 2*np.pi, 100)
ax.plot(x, np.sin(x), label='sin')
ax.set_title('正弦曲线')
ax.set_xlabel('x'); ax.set_ylabel('y')
ax.legend()
plt.tight_layout()
plt.savefig('sin.png', dpi=150)

出版级图我必做三件事：tight_layout() 防标签被切、dpi=150 以上保证印刷清晰、savefig 用 PDF/SVG 矢量格式而不是 PNG。

我踩过的中文字体坑

必坑

Matplotlib 默认字体不含中文，标题是中文就变方块。我第一次画图全是豆腐块，查了半天才知道要 plt.rcParams['font.sans-serif'] = ['PingFang SC'] 或 ['SimHei']，外加 plt.rcParams['axes.unicode_minus'] = False 让负号正常显示。这两行建议直接写进你的全局配置。

Seaborn：一行出统计图

做 EDA（探索性分析）我几乎只用 Seaborn。它基于 Matplotlib，但封装得让你一行代码画出带回归线的散点图、带分布的箱线图：

import seaborn as sns
tips = sns.load_dataset('tips')

# 箱线图：按天看小费分布
sns.boxplot(data=tips, x='day', y='tip', hue='time')
# 回归线散点
sns.regplot(data=tips, x='total_bill', y='tip')

和 Matplotlib 的区别：Seaborn 默认配色和统计标注就很好看，适合快速看分布；要出版级精细调整再回到 Matplotlib。

Plotly / Pyecharts：网页交互图

静态图的局限是「图做出来什么就是什么」，业务方想自己放大、悬停看数值、切维度，做不到。这时候上 Plotly 或 Pyecharts。我更推荐 Pyecharts——它是百度 ECharts 的 Python 封装，国内业务方看惯了 ECharts 的交互效果，接受度高：

from pyecharts.charts import Bar
from pyecharts import options as opts

bar = (
    Bar()
    .add_xaxis(['周一','周二','周三','周四','周五'])
    .add_yaxis('销售额', [120, 200, 150, 80, 70])
    .set_global_opts(title_opts=opts.TitleOpts(title='周销售额'))
)
bar.render('bar.html')   # 导出独立 HTML

导出的 HTML 自包含，直接发给业务方双击就能看，不用装 Python。这是我给非技术同事交付图表的默认方式。

Streamlit：半天搭个数据看板

如果业务方要「能自己选日期、自己筛维度」的看板，别写前端了，用 Streamlit：

import streamlit as st
import pandas as pd

df = pd.read_csv('data.csv')
week = st.sidebar.selectbox('选周', df['week'].unique())
sub = df[df['week'] == week]
st.bar_chart(sub.set_index('date')['sales'])

写几十行 Python 就能起一个带交互的看板，streamlit run app.py 一键起服务。我做内部数据工具基本都用它，省得再写一套 React。

性能：大数据量怎么画不卡

这是我被问最多的问题。10 万行数据直接 sns.scatterplot，浏览器直接卡死。经验值：

数据量方案渲染耗时（参考值）
<1 万点Matplotlib/Seaborn 直接画秒级
1万-100万datashader 聚合光栅化几秒
>100万点散点WebGL 加速 PrefixFigures秒级
交互探索先聚合再画，别全量——
我的做法

大数据量别想着把原始点全画出来。先在 pandas 里按桶聚合（groupby + 分箱），再画聚合后的结果。人眼根本分辨不出一百万点和一万点的区别，但渲染差一百倍。

FAQ

Q：Matplotlib、Seaborn、Plotly 到底学哪个？
先 Matplotlib 打地基，再 Seaborn 提效率，最后 Plotly/Pyecharts 做交互。别一上来就学 Plotly，它会遮住 Matplotlib 的底层概念。我的顺序是 Matplotlib → Seaborn → Pyecharts → Streamlit。

Q：为什么图里中文全是方块？
默认字体不含中文。加两行 rcParams 设字体，并设 axes.unicode_minus=False。这个配置写进 matplotlibrc 全局生效，省得每个脚本都设。

Q：导出 PNG 模糊怎么办？
dpi 调大（≥150），或者直接导出 PDF/SVG 矢量格式。论文/PPT 里永远用矢量图，别用位图——放大不糊。

Q：2026 了，AI 能帮我画图吗？
能。现在用 Cursor 或 Copilot 描述「用 pandas 读这个 csv，按月份画折线图」，它直接写出 matplotlib 代码。但配色、字体、标签这些审美活还得你把关——AI 默认画出来的图都一股「教程味」。

小结

Python 可视化不是一个工具，是一条流水线：pandas 整理数据、Seaborn 快速探索、Matplotlib 精修出版、Plotly/Pyecharts 做交互、Streamlit 搭看板。把这五个位置想清楚，按需取工具就不会乱。下一篇搜索技术，看怎么从海量信息里找到你要的那一条。
