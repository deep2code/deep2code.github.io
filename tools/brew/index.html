Homebrew 6.0

🏷️ Homebrew

一句话理解 Homebrew

macOS / Linux 上的命令行包管理器，相当于命令行版的 App Store。不用 sudo，装到用户目录，靠 symlink 软链管理版本。

核心原理

四大核心概念

概念说明类比
FormulaRuby 脚本，定义软件怎么装：源码地址、版本、依赖、编译步骤菜谱
Bottle预编译好的二进制包，装的时候直接下，不用现场编译半成品菜
Keg单个软件的某个版本，存放在 Cellar 里一个酒桶
Cellar所有软件版本的总目录 /opt/homebrew/Cellar地窖

安装流程

flowchart LR A[下载 Formula 脚本] --> B[解析依赖关系] B --> C{有 Bottle?} C -->|有| D[下载预编译二进制] C -->|没有| E[下载源码现场编译] D --> F[解压到 Cellar] E --> F F --> G[symlink 软链到 Prefix/bin] G --> H[完成]

目录结构

/opt/homebrew/           # Prefix（根目录）
├── bin/                  # 软链接目录（PATH 指向这里）
│   ├── python3 -> ../Cellar/python@3.12/3.12.4/bin/python3
│   └── node -> ../Cellar/node/20.15.0/bin/node
├── Cellar/               # 地窖：所有软件版本存放地
│   ├── python@3.12/
│   │   └── 3.12.4/       # Keg：单个版本
│   └── node/
│       └── 20.15.0/
├── Caskroom/             # GUI 应用存放地
│   └── google-chrome/
└── var/                  # 服务数据目录
    └── log/              # 日志
为什么不用 sudo？ Homebrew 装到用户目录 /opt/homebrew，不是系统目录 /usr。所有操作都是用户权限，不用 root。这是跟 apt/yum 最大的设计区别。

依赖类型

依赖类型声明方式说明
运行时依赖depends_on "xxx"运行时需要，装并链接
构建依赖depends_on "xxx" => :build只编译时需要，装 Bottle 时跳过
测试依赖depends_on "xxx" => :test只在 brew test 时用

国内镜像加速

默认源在 GitHub，国内慢得要死。配中科大或清华镜像，速度直接起飞。

# 中科大镜像
export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.ustc.edu.cn/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.ustc.edu.cn/homebrew-core.git"
export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles"

# 清华镜像
# export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.tuna.tsinghua.edu.cn/git/brew.git"
# export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.tuna.tsinghua.edu.cn/git/homebrew-core.git"
# export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.tuna.tsinghua.edu.cn/homebrew-bottles"

# 写进 ~/.zshrc 永久生效

常见坑与解决

问题原因解决
装完命令找不到PATH 没配eval "$(brew shellenv)" 写进 ~/.zprofile
update 很慢默认 GitHub 源换国内镜像
权限报错用了 sudo brew永远别 sudo brew，chown -R $(whoami) $(brew --prefix)
Apple Silicon 和 Intel 路径不一样架构差异Apple Silicon: /opt/homebrew；Intel: /usr/local
cleanup 删了要用的版本没预览就直接清先 brew cleanup -n 预览，关键版本 brew pin
Cask 升级失败应用还在运行先退出应用再升级

总结

✅ Formula 是配方，Bottle 是预编译包，Cellar 是存放目录
✅ 不用 sudo，装到用户目录
✅ 路径用 $(brew --prefix)，别硬编码
✅ cleanup 先 -n 预览
✅ 国内先配镜像
✅ 新机器用 Brewfile 一键还原
