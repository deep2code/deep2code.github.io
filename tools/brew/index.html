Homebrew 入门：从你遇到的问题出发

🏷️ Homebrew

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Homebrew怎么帮你解决。

flowchart TB A[Homebrew] --> B[包管理器] B --> C[装软件] C --> D[一键安装]

1. Mac 装软件太麻烦

你遇到的问题

Mac 装软件要去官网下载，太麻烦。

怎么解决？用 Homebrew，一行命令装软件。

2. Homebrew 是什么

你遇到的问题

Homebrew 是什么？

怎么解决？Mac 的包管理器，一行命令装各种开发工具。

3. 常用命令

你遇到的问题

Homebrew 常用命令有哪些？

怎么解决？brew install、brew list、brew uninstall、brew update。

常用命令

命令用途
brew install安装软件
brew list列出已装软件
brew uninstall卸载软件
brew update更新 Homebrew
新手最容易踩的坑
  • Mac 必装Mac 开发必装 Homebrew，省很多事。
  • 不要乱装只装你需要的，不要乱装一大堆。
