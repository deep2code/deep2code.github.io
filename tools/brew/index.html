Homebrew 入门：从你遇到的问题出发

🏷️ Homebrew 入门

你在 Mac 上要装各种软件：git、nginx、redis、node、python……每次都要去官网下载、安装、配置环境变量，太麻烦了。

这篇不讲理论，就讲你真的会遇到的问题，以及 Homebrew 怎么帮你解决。

场景一：装个软件，要去官网下载、安装、配环境变量

你遇到的问题

你要装 git，得去 git-scm.com 下载安装包，双击安装，还要配环境变量。要装 nginx，得去 nginx.org 下载，编译安装，配配置文件。装个 redis 更是麻烦。装 10 个软件，折腾一整天。

Homebrew 怎么解决？一行命令装一个软件，自动帮你下载、安装、配环境变量。

# 装 git
brew install git

# 装 nginx
brew install nginx

# 装 redis
brew install redis

# 装 node
brew install node

现在装软件就是一行命令的事，1 分钟搞定。不用去官网下载，不用配环境变量。

场景二：卸载软件，删了安装包还有一堆残留

你遇到的问题

你装了个软件，后来不想用了，把安装包删了，但是配置文件、日志、缓存还在系统里，占了好几个 G 的空间。你想彻底卸载干净。

Homebrew 怎么解决？一行命令彻底卸载，所有相关文件都删干净。

# 彻底卸载，连配置文件一起删
brew uninstall --zap nginx

场景三：软件版本旧了，要一个个升级

你遇到的问题

你用了半年，发现装的软件版本都旧了，有新功能想用。你要一个个去官网下载新版本，覆盖安装，太麻烦了。

Homebrew 怎么解决？一行命令升级所有软件。

# 升级所有软件
brew upgrade
常用命令什么时候用
brew install xxx装软件
brew uninstall xxx卸载软件
brew list看装了哪些软件
brew search xxx搜索有没有这个软件
brew upgrade升级所有软件
brew cleanup清理旧版本，释放空间
新手最容易踩的坑
  • 不要用 sudo 跑 brew：用 sudo 会把权限搞乱，以后升级就报错了。
  • 装完要 restart 终端：有时候装完软件命令找不到，重启一下终端就好了。
  • brew 很慢要换源：国内访问慢，换成清华源或者中科大源就快了。
  • 不要随便删 /usr/local 目录：Homebrew 的文件都在那，删了就全没了。
