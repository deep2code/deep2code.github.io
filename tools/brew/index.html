Homebrew：从你遇到的问题出发

🏷️ Homebrew

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Homebrew怎么帮你解决。

flowchart LR A[brew install] --> B[自动下载安装] B --> C[自动配好环境变量]

1. Mac 装软件太麻烦

你遇到的问题

你要装 git、nginx、redis，去官网下载、拖到应用程序、配环境变量，半天。

怎么解决？brew install 一条命令搞定，自动装自动配。

2. 软件升级太麻烦

你遇到的问题

你要升级软件，还要重新下载安装。

怎么解决？brew upgrade 一条命令升级所有软件。

3. 软件卸载不干净

你遇到的问题

你删了软件，还有一堆配置文件和缓存。

怎么解决？brew uninstall 自动清理干净。

常用 brew 命令

命令用途
brew install xxx安装软件
brew uninstall xxx卸载软件
brew upgrade升级所有软件
brew list列出已装软件
新手最容易踩的坑
  • 装在 /usr/local不要改安装路径，不然会有奇怪的问题。
  • 换国内源默认源很慢，换成中科大或者清华的源。
