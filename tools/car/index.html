二、燃油车动力深度原理

四冲程循环到底怎么工作

flowchart LR A[进气行程] --> B[压缩行程] B --> C[做功行程] C --> D[排气行程] D --> A
行程活塞位置气门状态能量变化
进气从上止点往下走进气门开，排气门关吸入油气混合气
压缩从下止点往上走全关混合气被压缩，温度升高
做功从上止点往下走全关火花塞点火，爆炸推动活塞
排气从下止点往上走排气门开排出燃烧废气

涡轮增压是干嘛的

发动机排出去的废气本来浪费了，涡轮用废气吹动叶轮，压缩进发动机的空气，多喷油，同排量能多 40% 动力。

flowchart LR A[发动机排气] --> B[涡轮叶片] B --> C[同轴压气机] C --> D[压缩新鲜空气] D --> E[中冷器降温] E --> F[进发动机]

三、新能源车三电系统深度解析

1. 动力电池系统：不是一整块电池

电车的电池包，里面是几百个小电芯串并联，加上 BMS、热管理、外壳，组成一个完整电池系统。

flowchart TD A[BMS] --> B[电压采集 每串电芯] A --> C[电流采集] A --> D[温度采集] A --> E[SOC电量估算] A --> F[均衡充电] A --> G[故障保护]

电池热管理

电池最佳工作温度 25~40℃，太热衰减快，太冷充不进电。电车都有热管理系统：

  • 夏天：液冷循环给电池降温
  • 冬天：PTC 加热把电池预热到合适温度再充电
  • 快充前：先把电池预热到最佳温度，充电更快

2. 驱动电机系统

现在电车基本都是永磁同步电机，效率比燃油车高太多，最高效率 95% 以上，燃油车只有 30%~40%。

flowchart LR A[电池直流电] --> B[MCU控制器] B --> C[三相交流电] C --> D[永磁同步电机] D --> E[减速齿轮] E --> F[车轮]

为什么电车加速快

电机从 0 转速就能输出最大扭矩，燃油车要踩到一定转速扭矩才上来。所以电车不用变速箱，单级减速就够了。

对比永磁同步电机燃油发动机
最大扭矩转速0rpm 就满扭矩1500~4000rpm 才到
最高效率95%35%~40%
需要变速箱单级减速就够多档位变速箱
响应速度毫秒级几百毫秒

3. 电控 MCU 与功率器件

MCU 就是电机的控制器，用 IGBT 或者 SiC 碳化硅器件把电池的直流电变成三相交流电驱动电机。

flowchart TD A[MCU 电机控制器] --> B[IGBT/SiC 功率模块] B --> C[三相逆变桥] C --> D[输出 U/V/W] E[位置传感器] --> F[主控DSP] F --> G[矢量控制算法] G --> B

四、能量回收：为什么电车松油门就减速

松油门或者踩刹车的时候，电机反过来当发电机，把车轮的动能变成电能回充到电池，同时产生制动力。这就是单踏板模式的原理。

flowchart LR A[车轮转动] --> B[电机转起来] B --> C[发电机模式] C --> D[产生直流电] D --> E[充回电池] E --> F[产生阻力减速]

七、新手避坑指南

❌
避坑清单
  • 电车日常充电充到 80% 就行，不要每次都充满到 100%，电池寿命长一倍
  • 冬天续航打 5~7 折是正常的，不是车坏了，开暖风很耗电
  • 不要等电池完全没电了再充，20% 左右就充，过放伤电池
  • 高压部件不要自己拆，几百伏电压会触电，出事要专业人士
  • 电车保养比燃油车便宜一半，别听4S店乱加项目
  • 轮胎比燃油车要求高，车重，胎压不够续航少很多，磨损也快
