Mermaid：从你遇到的问题出发

🏷️ Mermaid

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Mermaid怎么帮你解决。

flowchart LR A[写 Mermaid 代码] --> B[自动渲染成图] B --> C[流程图/架构图/时序图]

1. 画架构图太慢

你遇到的问题

你想用画图软件画个流程图，拖半天。

怎么解决？用 Mermaid 写几行代码，自动渲染成图。

2. 图和代码不同步

你遇到的问题

你改了架构，忘了更新画图软件里的图，图和实际不一样。

怎么解决？图是代码写的，改图就是改代码，能 review 能版本管理。

3. 文档里插图太麻烦

你遇到的问题

Markdown 文档里要插图，要先画图再上传。

怎么解决？直接在 Markdown 里写 Mermaid，GitHub 自动渲染。

常用图类型

类型代码开头用途
流程图flowchart LR流程、架构
时序图sequenceDiagram接口调用
类图classDiagram面向对象设计
状态图stateDiagram-v2状态流转
新手最容易踩的坑
  • 简单为主图越简单越好，节点太多就拆成多个图。
  • 注意语法特殊字符要转义，不然会渲染失败。
