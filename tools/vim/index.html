Vim：从你遇到的问题出发

🏷️ Vim

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Vim怎么帮你解决。

flowchart TB A[普通模式] --> B[插入模式] A --> C[命令模式] B --> A C --> A

1. SSH 到服务器要改文件

你遇到的问题

你 SSH 到服务器，要改个配置文件，没有编辑器。

怎么解决？用 Vim 改，所有 Linux 都自带。

2. 键盘不离手效率高

你遇到的问题

你用鼠标拖来拖去改文件，效率低。

怎么解决？Vim 纯键盘操作，熟练了比 IDE 还快。

3. Vim 太难学不会

你遇到的问题

听说 Vim 很强大，但是进去了退不出来。

怎么解决？先学最基础的：i 插入、Esc 退出、:wq 保存退出。

Vim 基础命令

命令用途
i进入插入模式
Esc回到普通模式
:w保存
:q退出
:wq保存退出
dd删一行
新手最容易踩的坑
  • 先学最基础的不要一上来就学所有快捷键，先学会改文件保存退出。
  • 退不出来就按 Esc 再 :q!不管进去哪了，按 Esc 再 :q! 就能强退。
