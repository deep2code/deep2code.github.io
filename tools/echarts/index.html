Apache ECharts 数据可视化

🏷️ 代码生图

ECharts 简介

Apache ECharts 原来是百度 EFE 团队 2013 年做的，2018 年捐给 Apache 软件基金会，2020 年成为 Apache 顶级项目。它提供直观、交互丰富、可高度个性化定制的数据可视化图表，是国内最流行的图表库。我做国内项目的后台，图表基本默认 ECharts，中文文档、配置项全、社区案例多。

我的感受

ECharts 的核心是"一个 option 对象描述一切"。你不用操作 DOM，不用写 Canvas，配 JSON 就行。新手第一天就能出图，老手靠配置项调精细效果。缺点是配置项太多，翻文档翻到吐——但熟了之后效率极高。

核心特性

  • 图表丰富：折线/柱状/饼图/散点/雷达/地图/热力/桑基/树图/关系图/仪表盘/漏斗/旭日/平行坐标等 20+ 种
  • 双渲染引擎：自动选 Canvas 或 SVG
  • 交互强：tooltip、legend 筛选、dataZoom 缩放、brush 框选、visualMap 视觉映射
  • 性能优秀：千万级数据点渲染（增量渲染、降采样），echarts-gl 支持 3D 和地理可视化
  • 配置驱动：通过 option 声明图表，不用操作 DOM
  • 主题定制：内置多套主题，主题编辑器在线定制，导出 JSON
渲染引擎怎么选

Canvas 适合大数据量（千万级数据点，一次性绘制性能好）；SVG 适合小数据量和清晰缩放（SVG 是 DOM 元素，可无障碍访问、可 CSS 控制、矢量缩放不失真）。ECharts 5 默认按数据量自动选。

快速开始

安装

# npm
npm install echarts

# CDN
<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>

第一个图表

三步出图：初始化实例、写 option、setOption。我新项目基本都从这个模板抄：

// 1. 初始化实例
const chart = echarts.init(document.getElementById('main'));

// 2. 配置项
const option = {
    title: { text: '周销售额' },
    tooltip: { trigger: 'axis' },
    legend: { data: ['销售额'] },
    xAxis: { type: 'category', data: ['Mon','Tue','Wed','Thu','Fri','Sat','Sun'] },
    yAxis: { type: 'value' },
    series: [{
        name: '销售额',
        type: 'bar',
        data: [120, 200, 150, 80, 70, 110, 130],
        itemStyle: { color: '#5470c6' }
    }]
};

// 3. 设置配置
chart.setOption(option);

// 4. 响应式
window.addEventListener('resize', () => chart.resize());

配置项体系

ECharts 的核心是 option 配置对象，理解它的结构是掌握 ECharts 的关键。我自己把它拆成四块记：基础组件、系列数据、坐标系、视觉映射。

核心概念

  • 组件（Component）：title、tooltip、legend、xAxis、yAxis 都是组件，独立配置复用
  • 系列（Series）：series 数组每一项是一个系列，指定 type 和 data，决定图表类型
  • 坐标系：cartesian2d（直角）、polar（极坐标）、geo（地理）、radar（雷达）
  • 视觉映射（VisualMap）：把数据值映射到颜色、大小、透明度
  • 数据集（Dataset）：统一管理数据，多个系列共享

常用图表类型详解

折线图 / 面积图

series: [{
    type: 'line',
    data: [120, 200, 150, 80, 70, 110, 130],
    smooth: true,           // 平滑曲线
    areaStyle: {},          // 面积图
    symbol: 'circle',       // 数据点形状
    symbolSize: 8,
    lineStyle: { width: 3 },
    markPoint: { data: [{ type: 'max', name: '最大值' }] },
    markLine: { data: [{ type: 'average', name: '平均值' }] }
}]

柱状图 / 条形图

圆角和渐变是我让柱状图"看起来专业"的常用招：

series: [{
    type: 'bar',
    data: [120, 200, 150, 80, 70, 110, 130],
    barWidth: '50%',
    itemStyle: {
        borderRadius: [4, 4, 0, 0],  // 圆角
        color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
            { offset: 0, color: '#83bff6' },
            { offset: 1, color: '#188df0' }
        ])
    },
    label: { show: true, position: 'top' }
}]

饼图 / 环形图

series: [{
    type: 'pie',
    radius: ['40%', '70%'],  // 环形图：内半径,外半径
    center: ['50%', '50%'],
    avoidLabelOverlap: true,
    itemStyle: { borderRadius: 8, borderColor: '#fff', borderWidth: 2 },
    label: { show: true, formatter: '{b}: {d}%' },
    emphasis: { scale: true, scaleSize: 10 },
    data: [
        { value: 1048, name: '搜索引擎' },
        { value: 735, name: '直接访问' },
        { value: 580, name: '邮件营销' }
    ]
}]

热力图

热力图配 visualMap 色阶，做用户活跃分析特别好用：

xAxis: { type: 'category', data: hours, splitArea: { show: true } },
yAxis: { type: 'category', data: days, splitArea: { show: true } },
visualMap: {
    min: 0, max: 10, calculable: true,
    orient: 'horizontal', left: 'center', bottom: '2%',
    inRange: { color: ['#313695', '#4575b4', '#74add1', '#abd9e9', '#fee090', '#f46d43', '#d73027'] }
},
series: [{
    type: 'heatmap',
    data: heatmapData,  // [[xIndex, yIndex, value], ...]
    label: { show: true }
}]

桑基图

转化漏斗、资金流向都用桑基图，links 里定义 source/target/value：

series: [{
    type: 'sankey',
    left: '5%', right: '15%', top: '5%', bottom: '5%',
    emphasis: { focus: 'adjacency' },
    data: [{ name: '访问' }, { name: '咨询' }, { name: '订单' }],
    links: [
        { source: '展现', target: '点击', value: 100 },
        { source: '点击', target: '访问', value: 80 },
        { source: '访问', target: '咨询', value: 60 },
        { source: '咨询', target: '订单', value: 40 }
    ],
    lineStyle: { color: 'gradient', curveness: 0.5 }
}]

数据集（Dataset）

Dataset 是 ECharts 4.0 引入的，统一管理数据，多个系列共享，避免每个 series 重复写数据：

option = {
    legend: {},
    tooltip: { trigger: 'axis' },
    dataset: {
        source: [
            ['产品', '2024', '2025', '2026'],
            ['产品A', 43.3, 85.8, 93.7],
            ['产品B', 83.1, 73.4, 55.1]
        ]
    },
    xAxis: { type: 'category' },
    yAxis: { type: 'value' },
    series: [
        { type: 'bar' },  // 默认取第一列数据
        { type: 'bar' },
        { type: 'line' }
    ]
};

性能优化

大数据量方案

图表卡，ECharts 有几个专门的开关，我做监控大屏必开：

// 1. 脏矩形渲染，只重绘变化区域
const chart = echarts.init(dom, null, {
    useDirtyRect: true,
    renderer: 'canvas'
});

// 2. 降采样（折线图大数据，LTTb 算法）
series: [{
    type: 'line',
    data: largeData,
    sampling: 'lttb',  // 最大保持特征的降采样
    showSymbol: false,
    hoverAnimation: false
}]

// 3. 散点图大数据模式
series: [{
    type: 'scatter',
    data: largeData,
    large: true,
    largeThreshold: 2000
}]
实测感受

同等 5 万个点的折线图：不做处理，hover 大概掉到 20fps；开 sampling: 'lttb' + showSymbol: false，稳定 60fps。这个量级差做过一次就忘不了。

优化技巧

  1. 按需引入：用 echarts/core 按需引图表和组件，减少包体积
  2. Canvas 渲染：大数据量用 Canvas，SVG 适合小数据量和清晰缩放
  3. 避免频繁 setOption：批量更新数据，用 notMerge: false 合并配置
  4. dispose 销毁：页面切换调 chart.dispose() 释放内存
  5. resize 防抖：窗口 resize 用防抖，避免频繁重绘
  6. 数据分片：超大数据用 dataZoom 只渲染可视区域

按需引入（Tree Shaking）

// 完整引入（~1MB）
import * as echarts from 'echarts';

// 按需引入（~300KB）
import * as echarts from 'echarts/core';
import { BarChart, LineChart, PieChart } from 'echarts/charts';
import {
    TitleComponent, TooltipComponent, LegendComponent,
    GridComponent, DataZoomComponent
} from 'echarts/components';
import { CanvasRenderer } from 'echarts/renderers';

echarts.use([
    BarChart, LineChart, PieChart,
    TitleComponent, TooltipComponent, LegendComponent,
    GridComponent, DataZoomComponent,
    CanvasRenderer
]);

与框架集成

React

import { useEffect, useRef } from 'react';
import * as echarts from 'echarts';

function EChart({ option, style }) {
    const chartRef = useRef(null);
    const instanceRef = useRef(null);

    useEffect(() => {
        instanceRef.current = echarts.init(chartRef.current);
        const handleResize = () => instanceRef.current?.resize();
        window.addEventListener('resize', handleResize);
        return () => {
            window.removeEventListener('resize', handleResize);
            instanceRef.current?.dispose();
        };
    }, []);

    useEffect(() => {
        instanceRef.current?.setOption(option);
    }, [option]);

    return <div ref={chartRef} style={{ width: '100%', height: 400, ...style }} />;
}

Vue 3

<template>
    <div ref="chartRef" :style="{ width: '100%', height: '400px' }"></div>
</template>

<script setup>
import { ref, onMounted, onUnmounted, watch } from 'vue';
import * as echarts from 'echarts';

const props = defineProps(['option']);
const chartRef = ref(null);
let chart = null;

onMounted(() => {
    chart = echarts.init(chartRef.value);
    chart.setOption(props.option);
    window.addEventListener('resize', handleResize);
});

watch(() => props.option, (newOption) => {
    chart?.setOption(newOption);
}, { deep: true });

const handleResize = () => chart?.resize();
onUnmounted(() => {
    window.removeEventListener('resize', handleResize);
    chart?.dispose();
});
</script>

高级特性

自定义系列（Custom Series）

自定义系列让你用代码完全控制每个数据项的渲染，实现 ECharts 不内置的图表类型：

series: [{
    type: 'custom',
    renderItem: function(params, api) {
        const categoryIndex = api.value(0);
        const start = api.coord([categoryIndex, api.value(1)]);
        const end = api.coord([categoryIndex, api.value(2)]);
        const height = end[1] - start[1];
        return {
            type: 'rect',
            shape: { x: start[0] - 10, y: start[1], width: 20, height: height },
            style: api.style()
        };
    },
    encode: { x: 0, y: [1, 2] }
}]

多图联动

多个图表共享 tooltip 和 dataZoom，监控大屏常用：

// 多个图表联动
echarts.connect([chart1, chart2]);  // 通过实例
echarts.connect('group1');           // 通过 group ID

调试技巧

  • getDataURL：chart.getDataURL({ type: 'png', pixelRatio: 2 }) 导出高清图
  • getOption：chart.getOption() 拿当前完整配置，排查合并问题
  • convertToPixel：chart.convertToPixel({ xAxisIndex: 0 }, value) 数据坐标转像素
  • on 事件：chart.on('click', params => console.log(params)) 监听交互
  • showLoading：数据加载时显示 loading 动画

FAQ

Q1：图表在 Vue/React 里不显示？
几乎都是初始化时 DOM 还没宽高。把 echarts.init 放 mounted / useEffect 里，容器必须有确定高度（如 400px），窗口 resize 时调 chart.resize()。

Q2：setOption 后旧数据没清掉？
默认是合并模式。要完全替换数据用 setOption(option, true)（notMerge），或只更新数据字段。

Q3：一万个点的折线图卡？
开 sampling: 'lttb' 降采样、showSymbol: false 关点、hoverAnimation: false，散点开 large: true。

Q4：包体积太大？
用 echarts/core 按需引图表和组件，配合 tree-shaking 从 1MB 降到约 300KB。

Q5：5 升 4 兼容问题？
ECharts 5 有破坏性变更，生产环境锁定主版本号，别随便升大版本。

总结

ECharts 的核心是"一个 option 对象描述一切"：理解组件 / 系列 / 坐标系 / 视觉映射四块，再掌握按需引入、脏矩形、降采样、dispose 这四条性能纪律，就能 hold 住绝大多数国内仪表盘场景。它是配置驱动，别拿 D3 的命令式思维去硬写。
