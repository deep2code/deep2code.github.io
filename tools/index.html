开发工具入门：从你遇到的问题出发

🏷️ 开发工具

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及开发工具怎么帮你解决。

flowchart TB A[开发工具] --> B[编辑器 VS Code] B --> C[版本控制 Git] C --> D[包管理 Homebrew] D --> E[终端 iTerm2]

1. 刚入职不知道用什么工具

你遇到的问题

新程序员不知道开发要装什么工具。

怎么解决？先把 VS Code、Git、终端、浏览器装好，其他按需加。

2. 编辑器选哪个

你遇到的问题

VS Code、Sublime、Vim 选哪个？

怎么解决？VS Code 现在最主流，插件多，新手用这个。

3. 效率怎么提高

你遇到的问题

怎么提高开发效率？

怎么解决？用好插件、快捷键、命令行工具，少用鼠标。

必备工具

工具用途
VS Code代码编辑器
Git版本控制
Chrome浏览器调试
Postman接口测试
新手最容易踩的坑
  • 先把基础工具用熟不要装一堆插件，先把基础的用熟。
  • 快捷键多练多用快捷键，少用鼠标，效率高很多。
