Chart.js 轻量图表库

🏷️ 代码生图

Chart.js 简介

Chart.js 是 Nick Downie 2013 年做的开源图表库，现在由官方团队维护。它用 HTML5 Canvas 渲染，支持 8 种基础图表，设计就一句话：用最少的代码画出标准图表。

我什么时候用它

做内部小工具、活动落地页、数据看板的快速原型，我第一反应就是 Chart.js。包小、配置直观、响应式开箱即用。真要做企业级复杂仪表盘，我才上 ECharts。别拿 Chart.js 去扛千万级数据，它不是干那个的。

flowchart LR A[data 加 options] --> B[Chart 实例] B --> C[Canvas 渲染] C --> D[浏览器显示] B --> E[插件系统] E --> F[tooltip legend title]

核心特性

  • 轻量：核心库约 200KB（gzip 约 60KB），Tree-shaking 后更小
  • 8 种图表：折线、柱状、饼图/环形、雷达、极坐标、散点/气泡、面积、混合
  • Canvas 渲染：性能好，大数据量比 SVG 流畅
  • 响应式：容器尺寸变了自动重绘，不用手动处理
  • 交互内置：tooltip、legend 点击筛选、hover 高亮，开箱即用
  • 插件系统：生命周期钩子扩展，能加自定义图表类型
  • TypeScript：完整类型定义

快速开始

安装

# npm
npm install chart.js

# CDN
<script src="https://cdn.jsdelivr.net/npm/chart.js@4"></script>

第一个图表

最小可跑的例子，抄了就能用：

<canvas id="myChart" width="400" height="200"></canvas>

<script>
const ctx = document.getElementById('myChart').getContext('2d');
new Chart(ctx, {
    type: 'bar',
    data: {
        labels: ['Red', 'Blue', 'Yellow', 'Green', 'Purple', 'Orange'],
        datasets: [{
            label: '投票数',
            data: [12, 19, 3, 5, 2, 3],
            backgroundColor: 'rgba(54, 162, 235, 0.5)',
            borderColor: 'rgba(54, 162, 235, 1)',
            borderWidth: 1
        }]
    },
    options: {
        responsive: true,
        scales: { y: { beginAtZero: true } }
    }
});
</script>

图表类型怎么选

选图别纠结，跟着这棵决策树走就行：

flowchart TD START[选择图表类型] --> Q1{数据关系?} Q1 -->|趋势变化| LINE[折线图 Line] Q1 -->|对比排名| BAR[柱状图 Bar] Q1 -->|占比构成| PIE[饼图环形图] Q1 -->|多维对比| RADAR[雷达图 Radar] Q1 -->|相关分布| SCATTER[散点气泡图] Q1 -->|极坐标占比| POLAR[极坐标图] Q1 -->|混合场景| MIXED[混合图表] LINE --> Q2{数据量?} Q2 -->|小数据| LINE Q2 -->|大数据降采样| PERF[先降采样再渲染]
性能第一原则

超过 1000 个数据点，务必先降采样再渲染。这是我做图表踩过最多的坑——直接把几万点塞给 Chart.js，鼠标一划就卡成幻灯片。LTTB 降采样算法能把视觉特征几乎全保留，点数砍到千级。

折线图（Line）

{
    type: 'line',
    data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        datasets: [{
            label: '销售额',
            data: [65, 59, 80, 81, 56, 55],
            fill: true,              // 面积图
            borderColor: 'rgb(75, 192, 192)',
            backgroundColor: 'rgba(75, 192, 192, 0.2)',
            tension: 0.4,            // 平滑曲线（0=直线，1=最平滑）
            pointRadius: 5,
            borderWidth: 2
        }]
    },
    options: {
        interaction: { mode: 'nearest', axis: 'x', intersect: false }
    }
}

柱状图（Bar）

堆叠柱状图就把 x/y 轴都设 stacked: true，水平柱状图加个 indexAxis: 'y'：

{
    type: 'bar',
    data: {
        labels: ['Q1', 'Q2', 'Q3', 'Q4'],
        datasets: [
            { label: '2024', data: [44, 55, 41, 37], backgroundColor: '#4dc9f6' },
            { label: '2025', data: [53, 48, 62, 58], backgroundColor: '#f67019' }
        ]
    },
    options: {
        scales: {
            x: { stacked: true },
            y: { stacked: true, beginAtZero: true }
        }
    }
}

饼图 / 环形图（Pie / Doughnut）

{
    type: 'doughnut',  // 或 'pie'
    data: {
        labels: ['Red', 'Blue', 'Yellow', 'Green', 'Purple'],
        datasets: [{
            data: [300, 50, 100, 40, 120],
            backgroundColor: ['#ff6384', '#36a2eb', '#ffce56', '#4bc0c0', '#9966ff'],
            hoverOffset: 8,
            borderColor: '#fff'
        }]
    },
    options: {
        cutout: '60%',  // 环形图中心空洞大小
        plugins: {
            tooltip: {
                callbacks: {
                    label: function(context) {
                        const total = context.dataset.data.reduce((a, b) => a + b, 0);
                        const percentage = ((context.parsed / total) * 100).toFixed(1);
                        return `${context.label}: ${context.parsed} (${percentage}%)`;
                    }
                }
            }
        }
    }
}

雷达图（Radar）

多维能力对比常用雷达图，r 轴控制角度线和刻度：

{

              backgroundColor: 'rgba(255, 99, 132, 0.2)', borderColor: 'rgb(255, 99, 132)' }

    }
}

混合图表

柱状图加折线目标线，这种"销量柱 + 目标线"的组合报表特别常见，type 在 dataset 级别就能混：

{
    data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        datasets: [
            { type: 'bar', label: '销售额', data: [65, 59, 80, 81, 56, 55], backgroundColor: 'rgba(54, 162, 235, 0.5)' },
            { type: 'line', label: '目标', data: [60, 60, 70, 70, 60, 60], borderColor: 'rgb(255, 99, 132)', tension: 0.4, fill: false }
        ]
    }
}

插件系统

插件是 Chart.js 最强大的扩展机制。原理就是生命周期钩子——渲染流水线每个阶段触发一个钩子，你在钩子里注入逻辑。最常用的是 afterDraw，在图表画完后叠水印、标注什么的。

生命周期钩子

钩子触发时机
beforeInit / afterInit图表初始化前 / 后
beforeUpdate / afterUpdate数据更新前 / 后
beforeLayout / afterLayout布局计算前 / 后
beforeDatasetsDraw数据集绘制前
afterDatasetsDraw数据集绘制后
beforeDraw / afterDraw整个图表绘制前 / 后
resize / destroy尺寸变化 / 销毁时

自定义水印插件

下面这个"机密"水印插件是我常用的，客户内部报表直接套：

const watermarkPlugin = {
    id: 'watermark',
    afterDraw: (chart) => {
        const ctx = chart.ctx;
        ctx.save();
        ctx.globalAlpha = 0.1;
        ctx.font = 'bold 48px sans-serif';
        ctx.fillStyle = '#000';
        ctx.textAlign = 'center';
        ctx.translate(chart.width / 2, chart.height / 2);
        ctx.rotate(-Math.PI / 6);
        ctx.fillText('CONFIDENTIAL', 0, 0);
        ctx.restore();
    }
};

Chart.register(watermarkPlugin);

性能优化

图表卡基本就三个原因：点太多、动画没关、实例没销毁。对应三招：

  1. 数据点降采样：超过 1000 点先用 LTTB 算法降采样再传
  2. 禁用动画：大数据量 animation: false
  3. 销毁实例：页面切换 chart.destroy()，Canvas 实例不会自动 GC
  4. 无动画更新：批量更新用 chart.update('none')
实测感受

同等折线图数据（约 5 万点）：不做处理直接画，鼠标 hover 帧率大概掉到 15fps；LTTB 降采样到 1000 点 + 关动画，稳定 60fps。这个量级差，做过一次就忘不了。

const chart = new Chart(ctx, {
    type: 'line',
    data: { datasets: [{ data: largeData, pointRadius: 0, borderWidth: 1 }] },
    options: {
        animation: false,
        responsive: true,
        maintainAspectRatio: false,
        devicePixelRatio: 2
    }
});

// 无动画更新数据
chart.data.datasets[0].data = newData;
chart.update('none');

与框架集成

React

装完依赖后，用 react-chartjs-2 封装组件。注意要手动注册用到的组件，否则图表不渲染：

npm install react-chartjs-2 chart.js

import { Chart as ChartJS, CategoryScale, LinearScale, BarElement, Title, Tooltip, Legend } from 'chart.js';
import { Bar } from 'react-chartjs-2';

ChartJS.register(CategoryScale, LinearScale, BarElement, Title, Tooltip, Legend);

function MyChart() {
    const data = {
        labels: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'],
        datasets: [{ label: '销售额', data: [12, 19, 3, 5, 2], backgroundColor: 'rgba(54, 162, 235, 0.5)' }]
    };
    return <Bar data={data} options={{ responsive: true }} />;
}

FAQ

Q1：图表在容器里不显示或尺寸为 0？
Canvas 初始化时父容器必须有确定尺寸。SPA 里元素还没渲染就 new Chart，拿到的就是 0 宽高。放到 DOM 就绪 / 组件 mounted 后初始化，父容器给固定高度。

Q2：响应式时图表变形？
设 responsive: true 且 maintainAspectRatio: false，高度父容器自己控；否则它会按默认 2:1 硬维持宽高比。

Q3：切换页面后内存暴涨？
SPA 路由切换必须 chart.destroy()。Canvas 实例不会被 GC 自动回收，漏 destroy 越用越卡。

Q4：数据超过一万个点就卡？
Canvas 每帧全量重绘。先用 LTTB 降采样到千级，再 pointRadius: 0 关点、animation: false 关动画。

Q5：Tooltip 想自己定制样式？
tooltip.enabled = false 关默认，用 external 回调自己渲染一个 HTML div，样式随便控。

总结

Chart.js 的定位就是"轻量够用"：8 种基础图表加插件生态加简洁配置，覆盖绝大多数报表场景。真正要守住的是按需注册、及时 destroy、大数据降采样这三条性能纪律。要地图、桑基、3D 或千万级数据，再升级到 ECharts。
