<h3 id="redis-vector">向量搜索与 Vector Sets</h3>
<p>7.2 引入可扩展的向量相似性索引；8.x 起 <strong>Vector Sets</strong> 成为独立数据类型，专为向量存储加相似检索设计，内存占用更省、索引管理更简单。</p>
<pre><code class="language-bash"># Redis 8.x 原生命令（无需加载模块）
VADD myset item1 0.51 0.96 0.23 ...     # 向向量集添加元素
VSIM myset 0.42 0.80 0.11 ... COUNT 10  # 与查询向量相似度 Top-10</code></pre>
<p>Python 侧用官方 <code>redis-py</code>（5.x+），通过 VectorField + KNN 查询做语义搜索/推荐系统：</p>
<pre><code class="language-python">from redis import Redis
from redis.commands.search.field import VectorField, TextField
from redis.commands.search.indexDefinition import IndexDefinition
from redis.commands.search.query import Query

r = Redis(host='localhost', port=6379)
schema = (TextField("title"),
          VectorField("embedding", "HNSW", {"TYPE": "FLOAT32", "DIM": 768,
                                            "DISTANCE_METRIC": "COSINE"}))
r.ft("doc_index").create_index(schema, definition=IndexDefinition(prefix=["doc:"]))</code></pre>
