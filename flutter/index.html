常用命令

# 检查环境
flutter doctor

# 创建新工程
flutter create xxx

# 调试运行
flutter run

# 生成 apk，默认 release；上架应用市场需要签名，个人使用直接生成即可
flutter build apk

# 插上数据线、连上手机、手机打开调试选项后，直接安装
flutter install

# 生成 iOS 应用包：默认 App Store 导出；没有付费开发者账号时只能 development（真机调试），
# 付费账号可指定 ad-hoc（内测）或 enterprise（企业分发）
flutter build ipa

flutter build ipa --export-method development

# Deployment Target（部署目标）需不低于当前 Flutter 版本要求（以发版说明为准），
# 常见坑：Target 设太低时，打包后在低版本 macOS 上报错或无法运行
flutter build macos

# 出现类似下面的提示，可能是 Xcode 版本或 Apple Silicon 造成，仍可正常打包
# --- xcodebuild: WARNING: Using the first of multiple matching destinations:
# { platform:macOS, arch:arm64, id:xxxxx }
# { platform:macOS, arch:x86_64, id:xxxx }

# cd project/build/web
# python3 -m http.server 8000
flutter build web

# linux仅限linux主机支持
flutter build linux

# windows仅限windows主机支持
flutter build windows

Bundle和apk区别

Bundle（Android App Bundle，.aab）是 Google 推出的发布格式：提交 .aab 到 Google Play，Play 根据用户设备在资源、ABI、语言等维度拆分，按需拼装出专属 apk。例如 x86 + xhdpi 设备下载时，Google Play 会基于 .aab 拼装一个只含 xhdpi 资源和 x86 so 库的 apk，剔除无关内容，从而显著减小下载体积。

xcode无线调试真机(同局域内)

  • 手机采用数据线连接上Xcode，打开Xcode菜单：Windows->Device and Simulators。找到连接上的设备，把Connect via network选项打勾.

  • 之后Xcode将会转一会圈圈，耐心等待一会就成功了，此时拔掉数据线，可以看到左侧的设备连接列表上手机仍在列表中

  • 运行我们的项目，在设备列表中不出意外会看到我们的无线连接的手机。选择手机后运行

  • 不出意外的话，此时是跑不起来的。还需要最后一步，回到刚刚的设备列表中，选中手机右键，在出来的选项卡中选择一个Connect via IP Address项。选择之后输入手机的局域网ip地址。

  • 完成后可以看到在连接的手机右边有一个地球连接标志.

  • 以后项目运行，在下拉列表如果手机在局域网中也会有这个标志

  • 最后一步，选择后直接运行，不出意外的话，项目无需数据线就跑起来了

  • 此方法支持无线调试，连过一次之后就不需要数据线了

苹果帐户添加设备uuid

  • 打开https://developer.apple.com/ 登录苹果开发者账号，只有付费账号才能看到设备管理界面

  • 登进去之后点击Certificates, Identifiers & Profiles

  • 左侧点击Devices，可以看到现在账号里面注册的设备，再点击+号新增设备

  • 填写设备的名字（这个自己随便写就好了，方便你知道是谁的什么设备就行）还有设备的UDID，完成后点击Continue

  • 然后会让你再次确认信息，看你填写是否正确，下面显示的是该账号最多可以添加的测试设备数目和剩余可添加设备的数目。信息无误，点击Register下一步。再点击done完成注册，跳转回Devices页面，就可以看到我们新添加的设备了。如果是做app开发，需要重新打包之后，新设备才能进行测试

  • 平时打adhoc，不用打store包

  • 设备的 UUID（如 0da33645…a845 的格式；切勿在公开文档中贴出真实 UDID）

Flutter 3.44 / Dart 3.12 与 Google I/O 2026

  • GenUI SDK：官方推出 AI 驱动的 UI 生成 SDK，可基于自然语言动态生成 Flutter 界面，并与 Google DeepMind 技术联动。
  • Create with AI：官方强化 AI 创建路径，通过 Firebase 生成式 AI 对接文本、多模态与会话类能力。
  • Dart Cloud Functions for Firebase：Dart 后端能力打通，前后端同语言全栈化。
  • Impeller 全面深化：渲染与着色器编译持续优化，Web 端渲染向 Impeller 统一迁移。
  • 桌面生态升级：Canonical 成为 Flutter 桌面端主要维护者；Material 与 Cupertino 组件库进入解耦演进阶段。
  • 落地场景外扩：车载系统（如丰田 RAV4 试点）等嵌入式跨平台场景增多。

Flutter 3.x 基础回顾

  • Impeller 渲染引擎：替代 Skia，预先编译着色器，消除卡顿。
  • Material 3：全面支持 Material Design 3 设计规范。
  • Dart 3：空安全、记录类型（Records）、模式匹配。 
    // Dart 3 记录类型
var record = ('first', a: 2, b: true, 'last');
print(record.$1);    // first
print(record.a);     // 2

  case 200:

    print('Server error');
}
  • Flutter Web 改进：CanvasKit 渲染器、Wasm 编译支持。
  • Widget 状态管理：社区主流 Riverpod / Provider / Bloc。
