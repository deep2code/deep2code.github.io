GitOps 入门：从你遇到的问题出发

🏷️ GitOps

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及GitOps怎么帮你解决。

flowchart TB A[Git 仓库] --> B[GitOps 工具] B --> C[K8s 集群] C --> D[自动同步]

1. 部署手动改容易错

你遇到的问题

每次部署手动 kubectl apply，容易漏。

怎么解决？用 GitOps，Git 仓库是唯一源，自动同步到 K8s。

2. GitOps 是什么

你遇到的问题

GitOps 是什么？

怎么解决？用 Git 作为唯一事实源，自动部署到 K8s，变更都在 Git 里可追溯。

3. 常用工具

你遇到的问题

常用 GitOps 工具有哪些？

怎么解决？ArgoCD（最常用）、Flux。

核心概念

概念说明
Git 源Git 里存部署配置
自动同步Git 变了自动同步到集群
可追溯所有变更都在 Git 里
新手最容易踩的坑
  • Git 是唯一源所有配置变更都通过 Git，不要直接改集群。
  • 生产留审批生产环境自动同步最好留人工确认。
