GitOps：从你遇到的问题出发

🏷️ GitOps

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及GitOps怎么帮你解决。

flowchart LR A[Git 仓库存配置] --> B[ArgoCD 监听] B --> C[自动同步到 K8s] C --> D[配置和实际一致]

1. K8s 配置到处手动改

你遇到的问题

你 kubectl edit 改了配置，过段时间又被改回去了，不知道谁改的。

怎么解决？所有配置存 Git，改配置走 PR，自动同步到 K8s。

2. 多环境配置不一致

你遇到的问题

测试环境和生产环境配置不一样，不知道哪不一样。

怎么解决？Git 里分环境存配置，一目了然。

3. 部署后状态漂移

你遇到的问题

运维手动改了 K8s 里的配置，和 Git 里的不一样了。

怎么解决？ArgoCD 自动检测漂移，自动恢复成 Git 里的状态。

GitOps 工具

工具特点
ArgoCDK8s 原生、UI 好
Flux轻量、CI 集成
新手最容易踩的坑
  • Git 是唯一事实来源所有配置都从 Git 来，不要手动改 K8s。
  • PR 审批要做改配置要走 PR，不要直接 push main。
