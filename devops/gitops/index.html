flowchart LR A[Git 仓库] --> B[Argo CD] B --> C[同步到 K8s] C --> D[自动部署]

1. K8s 部署乱

你遇到的问题

手动 kubectl apply，没人知道现在跑的什么版本。

怎么解决？用 GitOps，Git 仓库是唯一事实源，自动同步到 K8s。

2. GitOps 是什么

你遇到的问题

怎么解决？用 Git 仓库管理部署配置，Git 改了自动同步到集群。
