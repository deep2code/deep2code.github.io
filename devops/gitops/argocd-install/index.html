Argo CD 安装：从你遇到的问题出发

🏷️ Argo CD

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Argo CD怎么帮你解决。

flowchart LR A[kubectl apply] --> B[装 Argo CD] B --> C[访问 Web UI] C --> D[接 Git 仓库]

1. 怎么装 Argo CD

你遇到的问题

想用 GitOps，怎么装 Argo CD？

怎么解决？一条 kubectl apply 命令装到 K8s 里。

2. 装完怎么登录

你遇到的问题

装完了怎么登录 Web UI？

怎么解决？装完后拿到初始密码，访问 NodePort。

3. 怎么接 Git 仓库

你遇到的问题

怎么把 Git 仓库的应用部署到 K8s？

怎么解决？在 Argo CD 里建 Application，填 Git 地址和 K8s 命名空间。

常用命令

操作命令
装 Argo CDkubectl apply -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
获取密码kubectl get secret -n argocd argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
新手最容易踩的坑
  • 先在测试集群装不要一上来就装生产，先测试环境试试。
  • 用 Ingress 暴露不要用 NodePort，用 Ingress 配域名。
