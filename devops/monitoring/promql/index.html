PromQL 入门：从你遇到的问题出发

🏷️ PromQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PromQL怎么帮你解决。

flowchart LR A[指标名] --> B[PromQL 查询] B --> C[Prometheus] C --> D[结果数据]

1. Prometheus 怎么查数据

你遇到的问题

Prometheus 存了指标，怎么查？

怎么解决？用 PromQL 查询语言，和 SQL 差不多。

2. 怎么查 CPU 使用率

你遇到的问题

想查现在 CPU 使用率是多少。

怎么解决？用 rate() 函数查 CPU 使用率，最常用的查询。

3. 怎么按服务过滤

你遇到的问题

怎么只查某个服务的指标？

怎么解决？用 {} 加标签过滤，比如 {service="xxx"}。

常用函数

函数用途
rate()计算增长率
sum by()分组聚合
avg()平均值
新手最容易踩的坑
  • 先跑简单查询不要一开始写复杂 PromQL，先跑简单的。
  • 用 Grafana 辅助Grafana 里写 PromQL 有提示，比命令行方便。
