Grafana 入门：从你遇到的问题出发

🏷️ Grafana

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Grafana怎么帮你解决。

flowchart TB A[Prometheus] --> B[Grafana] B --> C[Dashboard] C --> D[告警]

1. 监控数据怎么看

你遇到的问题

Prometheus 有数据，怎么看图表？

怎么解决？用 Grafana，接 Prometheus 数据源，做可视化仪表盘。

2. Grafana 是什么

你遇到的问题

Grafana 是什么？

怎么解决？开源可视化仪表盘工具，接各种数据源做监控图表。

3. 怎么用

你遇到的问题

怎么开始用 Grafana？

怎么解决？装 Grafana，加 Prometheus 数据源，导入现成 Dashboard。

常用数据源

数据源说明
Prometheus监控指标
ELK日志
MySQL数据库
新手最容易踩的坑
  • 用现成 Dashboard不要自己画，Grafana 官网有一堆现成 Dashboard，导入就行。
  • 面板要少而精一个 Dashboard 不要放太多面板，关键指标就行。
