Prometheus 入门：从你遇到的问题出发

🏷️ Prometheus

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Prometheus怎么帮你解决。

flowchart TB A[应用埋点] --> B[Prometheus 采集] B --> C[存储] C --> D[Grafana 展示] C --> E[告警]

1. 服务挂了不知道

你遇到的问题

服务挂了用户反馈才知道，太被动。

怎么解决？用 Prometheus 监控，指标采集，告警通知。

2. Prometheus 是什么

你遇到的问题

Prometheus 是什么？

怎么解决？开源监控告警系统，拉模式采集指标，时序数据库存储。

3. 核心组件

你遇到的问题

Prometheus 核心组件有哪些？

怎么解决？Server（采集存储）、Exporter（指标导出）、AlertManager（告警）。

核心组件

组件作用
Server采集存储查询
Exporter导出指标
AlertManager告警管理
