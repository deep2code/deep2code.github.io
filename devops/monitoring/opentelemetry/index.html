OpenTelemetry 入门：从你遇到的问题出发

🏷️ OpenTelemetry

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及OpenTelemetry怎么帮你解决。

flowchart TB A[应用埋点] --> B[OTel SDK] B --> C[Collector] C --> D[Jaeger/Zipkin]

1. 链路追踪怎么接

你遇到的问题

想做链路追踪，每个服务都要自己接 SDK 太麻烦。

怎么解决？用 OpenTelemetry，统一标准，一次接入到处用。

2. OpenTelemetry 是什么

你遇到的问题

OpenTelemetry 是什么？

怎么解决？CNCF 标准化的可观测性框架，统一日志、指标、链路追踪。

3. 核心概念

你遇到的问题

核心概念有哪些？

怎么解决？Trace（链路）、Metric（指标）、Log（日志）。

三大支柱

类型说明
Trace链路追踪
Metric指标监控
Log日志
新手最容易踩的坑
  • 新系统用 OTel新系统直接用 OpenTelemetry，不要自己造轮子。
  • 厂商无关OTel 是标准，可以随便换后端（Jaeger/Prometheus）。
