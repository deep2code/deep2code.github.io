运维开发：从你遇到的问题出发

🏷️ 运维开发总览

你写完代码要部署到服务器上，每次手动传文件、重启服务，经常出错。出了问题不知道哪里挂了，网站挂了用户比你先发现。

这篇不讲理论，就按你做项目会遇到的真实问题，给你列出来每个运维技术是解决什么问题的，你按需看就行。

🌐 网站怎么对外提供服务？

用户要通过域名访问你的网站，端口、多站点、HTTPS 怎么配？

📦 环境不一致怎么解决？

"我本地是好的啊"，一到服务器就跑不起来，环境不一致。

Docker 入门 →

🚀 多服务怎么管理？

十几个服务在不同服务器上，挂了不知道，扩容要手动加机器。

K8s 入门 →

🔄 部署怎么自动化？

改完代码要手动打包传服务器重启，太麻烦还容易错。

CI/CD 入门 →

做项目你一定会遇到这些运维问题

你遇到的问题看哪个技术
本地好的，线上跑不起来Docker 容器化
网站挂了用户先知道Prometheus 监控告警
找错误日志要 grep 半天ELK 日志系统
部署要手动传文件重启CI/CD 自动部署
多台服务器配置不一致GitOps / IaC
新手避坑
  • 小项目不要上来就上 K8s：一个 VPS 跑 Docker Compose 就够了，K8s 是给大项目用的，小项目用了反而更复杂。
  • 监控一定要先做：不要等出问题了才想起来加监控，网站挂了你要能第一时间知道。
  • 备份一定要做：数据库定期备份，不然服务器挂了数据就全没了。
