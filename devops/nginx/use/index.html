Nginx 实战：从你遇到的问题出发

🏷️ Nginx 实战

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Nginx 实战怎么帮你解决。

flowchart TB A[Nginx] --> B[反向代理] B --> C[负载均衡] C --> D[HTTPS] D --> E[静态文件]

1. 前端跨域了

你遇到的问题

前端调后端接口，浏览器报跨域。

怎么解决？Nginx 配反向代理，/api 转发到后端，前端请求同域。

2. 要配 HTTPS

你遇到的问题

网站要上 HTTPS。

怎么解决？Nginx 配 SSL 证书，监听 443，HTTP 重定向到 HTTPS。

3. 多台后端分流

你遇到的问题

后端有 2 台服务器，要分流。

怎么解决？Nginx 配负载均衡，upstream 配多台，轮询分发请求。
