Nginx 入门：从你遇到的问题出发

🏷️ Nginx

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Nginx怎么帮你解决。

flowchart TB A[Nginx] --> B[反向代理] B --> C[负载均衡] C --> D[静态文件]

1. 怎么把请求转发到后端

你遇到的问题

前端要访问后端服务，跨域。

怎么解决？Nginx 配反向代理，/api 转发到后端端口。

2. Nginx 是什么

你遇到的问题

Nginx 是什么？

怎么解决？高性能 Web 服务器，做反向代理、负载均衡、静态文件。

3. 常用配置

你遇到的问题

Nginx 常用配置有哪些？

怎么解决？反向代理、负载均衡、HTTPS、静态文件服务。

常用功能

功能用途
反向代理转发请求到后端
负载均衡多台后端分流
静态文件托管前端静态文件
新手最容易踩的坑
  • 改完 reload改完配置 nginx -s reload 生效。
  • 先检查语法改配置前 nginx -t 检查语法。
