Nginx HTTP 配置：从你遇到的问题出发

🏷️ Nginx HTTP

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Nginx HTTP怎么帮你解决。

flowchart TB A[浏览器请求] --> B[Nginx] B --> C[静态文件] B --> D[反向代理]

1. 前端部署怎么配

你遇到的问题

前端打包完怎么部署到服务器？

怎么解决？Nginx 配 root 指向静态文件目录，直接访问。

2. 反向代理怎么配

你遇到的问题

前端调后端跨域，怎么解决？

怎么解决？Nginx 配反向代理，前端请求 /api，代理到后端服务。

3. 常用配置

你遇到的问题

Nginx 常用配置有哪些？

怎么解决？root、index、proxy_pass、gzip、缓存。

常用指令

指令说明
root静态文件目录
proxy_pass反向代理
gzip开启压缩
新手最容易踩的坑
  • 改完 nginx -t改完配置先 nginx -t 检查语法，再 reload。
  • SPA 要 try_files前端 SPA 要配 try_files，刷新不 404。
