Nginx RTMP 推流：从你遇到的问题出发

🏷️ Nginx RTMP

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Nginx RTMP怎么帮你解决。

flowchart LR A[OBS 推流] --> B[Nginx RTMP] B --> C[FLV/HLS 播放] B --> D[录制]

1. 想自己搭直播推流

你遇到的问题

想搭个直播推流服务器，用什么？

怎么解决？用 Nginx + RTMP 模块，OBS 推流，网页播放。

2. RTMP 是什么

你遇到的问题

RTMP 是什么？

怎么解决？Real-Time Messaging Protocol，实时流传输协议，直播推流常用。

3. 怎么搭

你遇到的问题

怎么搭 Nginx RTMP？

怎么解决？装带 RTMP 模块的 Nginx，配 rtmp 块，OBS 推流地址配上去。
