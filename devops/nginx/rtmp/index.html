Nginx RTMP 推流：从你遇到的问题出发

🏷️ RTMP

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及RTMP怎么帮你解决。

flowchart LR A[OBS 推流] --> B[Nginx RTMP] B --> C[HLS 拉流] B --> D[RTMP 拉流]

1. 想自己搭直播服务器

你遇到的问题

你想做直播，不想用第三方直播服务。

怎么解决？Nginx + RTMP 模块，自己搭直播服务器。

2. 怎么推流拉流

你遇到的问题

知道要搭，不知道怎么弄。

怎么解决？OBS 推流到 Nginx，前端用 HLS 拉流播放。

3. 和 OBS 怎么配合

你遇到的问题

怎么用 OBS 推流？

怎么解决？OBS 里设置推流地址到你的 Nginx RTMP 地址。

常用地址

类型地址
推流地址rtmp://你的ip/live/你的流名
拉流 HLShttp://你的ip/hls/你的流名.m3u8
新手最容易踩的坑
  • 带宽要够直播很吃带宽，带宽不够会卡。
  • 延迟要调HLS 延迟比较高，要低延迟用 WebRTC。
