CI/CD 部署流水线：从你遇到的问题出发

🏷️ CI/CD

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CI/CD怎么帮你解决。

flowchart LR A[代码 push] --> B[CI 阶段] B --> C[构建] B --> D[测试] B --> E[CD 阶段] E --> F[部署 dev] E --> G[部署 prod]

1. 手动部署太麻烦

你遇到的问题

你改完代码要手动 build、传服务器、重启，经常出错。

怎么解决？CI/CD 自动化，push 完自动部署。

2. 怎么分阶段部署

你遇到的问题

怎么先部署到测试环境，验证完再上生产？

怎么解决？流水线分阶段：build -> test -> deploy dev -> manual approve -> deploy prod。

3. 回滚怎么做

你遇到的问题

上线出问题了怎么回滚？

怎么解决？每次部署记录版本，出问题一键回滚到上一个版本。

流水线阶段

阶段做什么
CI拉代码、构建、测试
CD部署到对应环境
新手最容易踩的坑
  • 先自动化 CI先把自动构建测试做了，再做自动部署。
  • 生产要手动确认生产环境部署前加个人工确认，不要全自动。
