CI/CD 入门：从你遇到的问题出发

🏷️ CI/CD

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CI/CD怎么帮你解决。

flowchart LR A[代码提交] --> B[自动构建] B --> C[自动测试] C --> D[自动部署]

1. 每次部署都要手动操作

你遇到的问题

改完代码要手动 SSH 到服务器，拉代码，重启，太麻烦。

怎么解决？用 CI/CD，代码 push 上去自动构建自动部署。

2. CI/CD 是什么

你遇到的问题

听说 CI/CD，到底是什么？

怎么解决？持续集成持续部署，代码提交后自动跑测试部署。

3. 新手用什么工具

你遇到的问题

想搞 CI/CD，用什么工具？

怎么解决？GitHub Actions 最简单，push 代码自动跑，不用自己搭服务器。

常用工具

工具说明
GitHub Actions最简单，GitHub 自带
GitLab CIGitLab 自带
Jenkins自己搭，功能全
新手最容易踩的坑
  • 新手先用 GitHub Actions不用自己搭服务器，最简单。
  • 从简单开始先自动部署到测试环境，再搞生产。
