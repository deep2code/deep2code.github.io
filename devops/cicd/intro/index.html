CI/CD 入门：从你遇到的问题出发

🏷️ CI/CD

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CI/CD怎么帮你解决。

flowchart LR A[代码提交] --> B[自动构建] B --> C[自动测试] C --> D[自动部署到测试] D --> E[人工确认] E --> F[自动部署到生产]

1. 每次部署要手动打包传文件

你遇到的问题

改完代码要手动编译、传服务器、重启，经常出错。

怎么解决？代码 push 后自动完成构建、测试、部署。

2. 手动部署经常出问题

你遇到的问题

忘了装依赖、配置没改、端口不对，每次上线都提心吊胆。

怎么解决？全部自动化，每次部署步骤都一样，不会出错。

3. 代码提交了别人不知道

你遇到的问题

你改了代码直接跑了，同事不知道，测试也不知道。

怎么解决？每次提交自动触发流水线，所有人都能看到状态。

常用 CI/CD 工具

工具特点适合
GitHub Actions和 GitHub 集成开源项目、小团队
GitLab CI和 GitLab 集成企业内网部署
Jenkins功能强大复杂定制化流程
新手最容易踩的坑
  • 先做 CI 再做 CD先把自动测试跑起来，再做自动部署。
  • 生产部署要有人确认不要全自动部署生产，加个人工审批步骤。
