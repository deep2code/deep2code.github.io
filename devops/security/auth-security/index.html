认证安全实战：从你遇到的问题出发

🏷️ 认证安全

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及认证安全怎么帮你解决。

flowchart TB A[用户登录] --> B[密码校验] B --> C[Token 签发] C --> D[请求验证]

1. 密码明文存

你遇到的问题

数据库里用户密码是明文，数据库泄露就完了。

怎么解决？密码加盐哈希存储，不要明文。

2. 登录防暴力破解

你遇到的问题

别人用脚本暴力破解密码，怎么防？

怎么解决？加验证码、限流、锁定账号。

3. Token 怎么存

你遇到的问题

JWT Token 怎么存？

怎么解决？前端存 HttpOnly Cookie，不要存 localStorage。

安全要点

要点说明
密码哈希加盐哈希，不要明文
暴力破解验证码 + 限流
TokenHttpOnly Cookie 存
新手最容易踩的坑
  • 密码永远不要明文密码一定要加盐哈希（bcrypt），不要 MD5。
  • 敏感操作二次验证改密码、转账这些敏感操作要二次验证。
