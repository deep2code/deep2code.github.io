认证授权安全：从你遇到的问题出发

🏷️ 认证安全

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及认证安全怎么帮你解决。

flowchart TB A[认证] --> B[你是谁] C[授权] --> D[你能干什么]

1. 认证和授权区别

你遇到的问题

认证和授权有什么不一样？

怎么解决？认证是验证你是谁（登录），授权是验证你能干什么（权限）。

2. 密码怎么存

你遇到的问题

用户密码存数据库，能不能明文存？

怎么解决？绝对不能明文，要加盐哈希，比如 bcrypt。

3. Session 和 JWT 选哪个

你遇到的问题

登录状态存 Session 还是 JWT？

怎么解决？传统系统用 Session，分布式/前后端分离用 JWT。

密码存储

方式安全性
明文绝对不行
MD5不行，能彩虹表破解
bcrypt/argon2安全，加盐哈希
新手最容易踩的坑
  • 密码不要明文存永远用加盐哈希，bcrypt 就行。
  • 不要自己写加密用成熟的库，不要自己造轮子。
