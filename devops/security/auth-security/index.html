认证安全：从你遇到的问题出发

🏷️ 认证安全

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及认证安全怎么帮你解决。

flowchart TB A[认证安全] --> B[密码加密] B --> C[Session/Token] C --> D[权限控制]

1. 用户密码明文存数据库

你遇到的问题

数据库被拖了，所有用户密码都泄露了。

怎么解决？密码用 bcrypt 哈希存，不要明文，也不要 MD5。

2. 怎么防止暴力破解

你遇到的问题

有人一直试密码，暴力破解。

怎么解决？登录失败多次锁定，加验证码，限速。

3. 权限怎么控制

你遇到的问题

普通用户不能访问管理员页面。

怎么解决？基于角色的权限控制，RBAC。

密码存储

方式安全性
明文极差
MD5差（彩虹表）
bcrypt好（加盐慢哈希）
新手最容易踩的坑
  • 密码一定要 bcrypt不要自己发明加密，用 bcrypt。
  • 重要操作二次验证改密码、转钱要再验证身份。
