HTTPS 与加密入门：从你遇到的问题出发

🏷️ HTTPS 加密

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及HTTPS 加密怎么帮你解决。

flowchart TB A[浏览器] --> B[请求 HTTPS] B --> C[SSL 握手] C --> D[协商密钥] D --> E[加密传输]

1. 网站要上 HTTPS

你遇到的问题

浏览器提示"不安全"，要给网站上 HTTPS。

怎么解决？申请 SSL 证书，Nginx 配 HTTPS，免费证书用 Let's Encrypt。

2. HTTPS 是什么

你遇到的问题

HTTPS 是什么？

怎么解决？HTTP + SSL/TLS，加密传输，防窃听防篡改。

3. SSL 证书怎么申请

你遇到的问题

SSL 证书怎么申请？

怎么解决？免费的用 Let's Encrypt（Certbot 自动续期），付费的买 CA 机构的。

证书类型

类型说明价格
DV域名验证免费
OV组织验证付费
EV扩展验证贵
新手最容易踩的坑
  • 免费证书够了个人/小项目用 Let's Encrypt 免费证书就行。
  • 自动续期用 Certbot 自动续期，不要手动续。
