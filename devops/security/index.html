你遇到的问题

做网站要注意哪些安全问题？

怎么解决？XSS、CSRF、SQL 注入、认证授权，这几个最常见。

2. 怎么防 XSS

你遇到的问题

怎么解决？输出转义、CSP 头、HttpOnly Cookie。

3. 怎么防 SQL 注入

怎么解决？永远用预编译语句，不要拼 SQL。
