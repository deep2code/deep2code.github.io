Web 安全

从 OWASP Top 10 全局地图出发，深入 XSS、CSRF/点击劫持、SQL 注入、JWT/OAuth/OIDC 认证授权、HTTPS 与安全响应头/CSP 的原理与生产级防御代码，覆盖攻击演示与 Go/Python/nginx/YAML 实战配置。

系列文章目录

OWASP Top 10

从注入、失效身份认证到组件漏洞与配置错误，系统梳理 OWASP Top 10 2021 的风险本质、检测方法与纵深防御体系，建立 Web 安全的全局视角。

XSS 防御

深入反射型、存储型、DOM 型 XSS 的攻击链路，从输入输出编码、CSP 到 HttpOnly Cookie 层层设防，附带攻击 Payload 与 Go/Python 防御代码对比。

CSRF 与点击劫持

拆解 CSRF 与点击劫持的浏览器信任机制，讲解 SameSite Cookie、CSRF Token、Origin 校验与 Frame 防御头的实战配置，含 nginx 与 Go 中间件示例。

SQL 注入防护

从联合查询、盲注到二阶注入，剖析 SQL 注入的根因是"数据与控制流未分离"，用预编译、ORM、最小权限三条防线给出可落地的 Go/Python 防护代码。

认证授权安全

讲透 JWT 结构与签名陷阱、OAuth 2.0 四种授权流程、OIDC 与 PKCE，覆盖令牌泄露、越权、刷新令牌轮换等真实事故的修复方案。

HTTPS 与 CSP

从对称/非对称加密、证书链、TLS 握手讲到 HSTS、CSP、X-Frame-Options 等安全响应头的完整生产配置，附 nginx 与 Helm 安全基线。
