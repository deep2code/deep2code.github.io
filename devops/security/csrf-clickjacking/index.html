CSRF 防护实战：从你遇到的问题出发

🏷️ CSRF

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CSRF怎么帮你解决。

flowchart TB A[用户登录 A 站] --> B[访问恶意网站] B --> C[恶意请求 A 站] C --> D[CSRF 攻击]

1. 用户 Cookie 被盗用

你遇到的问题

用户登录了银行网站，访问恶意网站，被转账了。

怎么解决？用 CSRF Token + SameSite Cookie，防 CSRF 攻击。

2. CSRF 是什么

你遇到的问题

CSRF 是什么？

怎么解决？跨站请求伪造，盗用用户登录态，在用户不知情的情况下发请求。

3. 怎么防

你遇到的问题

怎么防 CSRF？

怎么解决？CSRF Token、SameSite Cookie、验证 Referer。

防御方式

方式说明
CSRF Token表单带随机 Token
SameSite CookieCookie 限制跨站发送
验证 Referer检查请求来源
新手最容易踩的坑
  • SameSite 很有效Cookie 设 SameSite=Lax，大部分 CSRF 就防住了。
  • POST 请求更安全重要操作用 POST，不要用 GET。
