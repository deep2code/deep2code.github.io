CSRF 防御：从你遇到的问题出发

🏷️ CSRF

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CSRF怎么帮你解决。

flowchart LR A[恶意网站] --> B[诱导用户点击] B --> C[带用户 Cookie 请求] C --> D[执行操作]

1. 用户账号被盗用操作

你遇到的问题

用户没操作，账号却发了消息转了钱。

怎么解决？CSRF 攻击，诱导用户点链接，带着用户的 Cookie 请求你的网站。

2. 什么是 CSRF

你遇到的问题

听说 CSRF 攻击，到底是什么？

怎么解决？跨站请求伪造，利用用户登录状态，在用户不知情情况下发请求。

3. 怎么防 CSRF

你遇到的问题

知道了怎么防？

怎么解决？加 CSRF Token，或者校验 Referer，或者 SameSite Cookie。

防 CSRF 方法

方法说明
CSRF Token表单加随机 Token，最常用
SameSite CookieCookie 设 SameSite=Lax/Strict
校验 Referer检查请求来源
新手最容易踩的坑
  • 重要操作要验证转钱、改密码这种操作要再验证密码。
  • Cookie 设 SameSite现在浏览器默认 SameSite，风险小很多。
