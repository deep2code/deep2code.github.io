Helm：从你遇到的问题出发

🏷️ Helm

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Helm怎么帮你解决。

flowchart LR A[Helm Chart] --> B[模板化配置] B --> C[不同环境部署]

1. K8s YAML 文件太多

你遇到的问题

你部署一个应用要写十几个 YAML 文件，太麻烦。

怎么解决？Helm 把所有 YAML 打包成 Chart，一条命令部署。

2. 不同环境配置不一样

你遇到的问题

测试环境和生产环境配置不一样，要维护两套 YAML。

怎么解决？Helm 用 values.yaml 区分配置，同一套 Chart 部署不同环境。

3. 怎么分享部署配置

你遇到的问题

你写的部署配置想给别人用。

怎么解决？Helm Chart 打包，别人 helm install 就能部署。

核心概念

概念说明
Chart部署包，相当于 apt 包
ReleaseChart 的运行实例
values.yaml配置文件
新手最容易踩的坑
  • 不要把敏感配置放 Chart密码、密钥用 secret 管理，不要放 values。
  • 先会用官方 Chart常用应用先装官方 Chart，不要自己写。
