Helm 入门：从你遇到的问题出发

🏷️ Helm

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Helm怎么帮你解决。

flowchart TB A[Chart] --> B[模板] B --> C[values] C --> D[渲染成 K8s 资源]

1. K8s 部署太麻烦

你遇到的问题

一个应用要写好几个 YAML，每个环境改来改去。

怎么解决？用 Helm，K8s 的包管理器，模板化部署，不同环境改 values 就行。

2. Helm 是什么

你遇到的问题

Helm 是什么？

怎么解决？Kubernetes 的包管理器，Chart 就是应用模板，渲染成 YAML 部署。

3. 常用命令

你遇到的问题

Helm 常用命令有哪些？

怎么解决？install、upgrade、uninstall、list。

常用命令

命令说明
helm install安装 Chart
helm upgrade升级版本
helm uninstall卸载
helm list列已安装
新手最容易踩的坑
  • 先用官方 Chart常用应用先找 Helm 官方 Chart，不用自己写。
  • values 分环境不同环境用不同 values 文件。
