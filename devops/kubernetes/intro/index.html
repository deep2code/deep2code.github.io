Kubernetes 入门：从你遇到的问题出发

🏷️ K8s

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及K8s怎么帮你解决。

flowchart TB A[Deployment] --> B[Pod] B --> C[容器] C --> D[自动扩缩容]

1. 容器多了管理不过来

你遇到的问题

用 Docker 跑了几十个容器，机器挂了自动恢复不了，管理麻烦。

怎么解决？用 K8s，容器编排系统，自动部署、扩缩容、故障恢复。

2. K8s 是什么

你遇到的问题

Kubernetes 是什么？

怎么解决？Google 开源的容器编排系统，管理容器集群，自动运维。

3. 核心概念

你遇到的问题

K8s 核心概念有哪些？

怎么解决？Pod（最小单位）、Deployment（部署）、Service（服务发现）。

核心概念

概念说明
Pod最小调度单位，跑容器
Deployment管理 Pod 副本
Service服务发现负载均衡
新手最容易踩的坑
  • 小项目不用 K8s小项目用 Docker Compose 就够，不要上来就 K8s。
  • 先学基础先学 Pod/Deployment/Service 这几个最基础的。
