Terraform State 入门：从你遇到的问题出发

🏷️ Terraform State

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Terraform State怎么帮你解决。

flowchart TB A[Terraform] --> B[state 文件] B --> C[记录资源状态] C --> D[同步云资源]

1. Terraform state 是什么

你遇到的问题

跑 terraform plan，说要创建已经存在的资源。

怎么解决？state 文件不同步了，terraform import 一下。

2. state 是什么

你遇到的问题

Terraform state 是什么？

怎么解决？记录 Terraform 管理的资源状态的文件。

3. state 怎么存

你遇到的问题

state 文件怎么存？

怎么解决？本地存不安全，多人协作存远程（S3/OSS）。

常用命令

命令说明
terraform import导入已有资源
terraform state list列 state 资源
terraform state rm从 state 删除
新手最容易踩的坑
  • state 一定要备份state 文件很重要，一定要备份好。
  • 多人用远程 state多人协作一定要用远程 state，不要本地。
