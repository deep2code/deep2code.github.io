IaC 工具对比：从你遇到的问题出发

🏷️ IaC 对比

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及IaC 对比怎么帮你解决。

flowchart TB A[IaC] --> B[Terraform] B --> C[Pulumi] C --> D[CloudFormation]

1. 选哪个 IaC 工具

你遇到的问题

做基础设施即代码，选 Terraform 还是 Pulumi？

怎么解决？最流行还是 Terraform，资料多。Pulumi 用真实编程语言。

2. Terraform 是什么

你遇到的问题

Terraform 是干嘛的？

怎么解决？最流行的 IaC 工具，HCL 语言定义资源，多云支持。

3. Pulumi 是什么

你遇到的问题

Pulumi 和 Terraform 区别？

怎么解决？Pulumi 用 TypeScript/Python 真实编程语言，不用学 HCL。
