自建服务入门：从你遇到的问题出发

🏷️ 自建服务

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及自建服务怎么帮你解决。

flowchart TB A[要个服务] --> B[用云服务?] B -->|贵| C[自建] B -->|省心| D[云服务]

1. 想省云服务费

你遇到的问题

用云服务一个月几百块，想自己搭省点钱。

怎么解决？自建服务，用 Docker Compose 跑，省成本但要自己运维。

2. 什么时候自建

你遇到的问题

什么时候该自建，什么时候用云服务？

怎么解决？数据量大、长期用自建划算；小团队、临时用云服务省心。

3. 常用自建服务

你遇到的问题

常用自建服务有哪些？

怎么解决？Gitea（Git）、NocoDB（数据库）、Immich（相册）、Nextcloud（网盘）。

对比

对比自建云服务
成本便宜贵
运维自己管厂商管
灵活高低
新手最容易踩的坑
  • 小团队用云小团队不要什么都自建，运维成本很高。
  • 数据要备份自建服务数据一定要定期备份。
