自建服务：从你遇到的问题出发

🏷️ 自建服务

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及自建服务怎么帮你解决。

flowchart TB A[VPS 服务器] --> B[1Panel 面板] B --> C[一键装各种服务]

1. 想自己搭网站

你遇到的问题

你想做个博客，不想用 GitHub Pages，想自己控制。

怎么解决？买个 VPS，装个 1Panel 面板，一键部署网站。

2. 不想用第三方 SaaS

你遇到的问题

你不想把数据存在别人服务器上，想自己搭。

怎么解决？用 Docker 跑各种开源服务，数据存在自己服务器。

3. 新手不会运维

你遇到的问题

你不会 Linux 命令，怎么搭服务？

怎么解决？装 1Panel 面板，网页上点点鼠标就能装服务。

常用自建服务

服务用途
WordPress博客
GiteaGit 服务
NextCloud网盘
Vaultwarden密码管理
新手最容易踩的坑
  • 安全一定要做改 SSH 端口、禁 root 登录、配防火墙。
  • 数据要备份重要数据定期备份，不然服务器挂了就没了。
