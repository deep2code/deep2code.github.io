自托管服务：把数据掌握在自己手里

🏷️ 自托管

用第三方 SaaS，数据在别人手里，还贵。自托管就是把这些服务自己部署，数据在自己服务器上，省钱还安全。

flowchart TD A[自托管服务] --> B[效率工具] A --> C[开发工具] A --> D[存储备份] B --> B1[Notion→Outline] B --> B2[Trello→Focalboard] C --> C1[GitHub→Gitea] C --> C2[CI/CD→Woodpecker]

SaaS 太贵了，想省钱

⚠️
你遇到的问题

用 Notion、Linear、Figma，一个月几百刀，小团队扛不住。

怎么解决？自托管替代方案，功能差不多，数据在自己服务器，省钱还隐私。

# 常见自托管替代
Notion → Outline / BookStack
Linear → Focalboard / Plane
Figma → Penpot
GitHub → Gitea

数据在别人手里，不放心

⚠️
你遇到的问题

代码、文档都存在第三方平台，万一服务挂了或者涨价了，数据都拿不回来。

怎么解决？自托管，数据在自己服务器，想备份就备份，想迁移就迁移，完全可控。

# 自托管优势
1. 数据完全自己控制
2. 长期省钱
3. 可以深度定制
4. 隐私安全

常用自托管服务

类别 SaaS 替代品 自托管方案
代码托管 GitHub / GitLab Gitea / Forgejo
知识库 Notion / Confluence Outline / BookStack
项目管理 Jira / Linear Plane / Focalboard
设计工具 Figma Penpot
CI/CD GitHub Actions Woodpecker / Drone
网盘 Google Drive Nextcloud

新手最容易踩的坑

❌
避坑指南
  • 自托管不是免费的，你要花时间运维，服务器成本也要算
  • 小团队别什么都自托管，常用的、稳定的用 SaaS，核心数据自己存
  • 自托管一定要配好备份，不然服务器挂了数据就没了
  • 先试用 SaaS 版，觉得好用了再考虑自托管，别上来就折腾
