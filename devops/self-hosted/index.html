自托管入门：从你遇到的问题出发

🏷️ 自托管

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及自托管怎么帮你解决。

flowchart TB A[自托管] --> B[服务器] B --> C[Docker] C --> D[各种应用]

1. 不想用云服务

你遇到的问题

不想用别人的云服务，想自己部署。

怎么解决？自托管，自己买服务器，自己部署各种应用。

2. 自托管是什么

你遇到的问题

Self-hosted 是什么？

怎么解决？自己在自己服务器上部署应用，而不是用 SaaS 云服务。

3. 常用自托管应用

你遇到的问题

有哪些常用自托管应用？

怎么解决？Gitea、Nextcloud、Vaultwarden、Jellyfin 等。

常用自托管

应用用途
Gitea代码托管
Nextcloud云盘
Vaultwarden密码管理
Jellyfin影视流媒体
新手最容易踩的坑
  • 用 Docker 部署自托管用 Docker Compose 部署，方便。
  • 备份很重要自己的数据一定要备份，不要丢了。
