腾讯云

🏷️ 腾讯云

为什么我用腾讯云

我用腾讯云主要两个原因：一是微信生态——做公众号小程序对接最顺，二是游戏云市场份额第一。纯 Web 业务我还是倾向阿里云，但涉及微信生态或者游戏后端，腾讯云是首选。

核心服务速览

CVM：云服务器

跟阿里云 ECS 基本一个东西。我用下来感觉价格比阿里云略低一点，尤其新购折扣力度大。但包年包月到期后续费价格跳涨是个坑——之前有个服务器续费从 99 涨到 399，差点忘了。

CDB：云数据库

CDB 是腾讯云的 RDS 产品。MySQL、Redis、MongoDB 都有。2024 年推出了 TDSQL-C（兼容 MySQL 的云原生数据库），架构跟 PolarDB 类似，存算分离。

产品对标阿里云特点
CVMECS通用计算，新购折扣大
CDB MySQLRDS MySQL自动备份主备切换
TDSQL-CPolarDB存算分离，Serverless 版
COSOSS对象存储，跟 CDN 配合好
CLBSLB/ALB负载均衡，四层七层都有
TKEACK容器服务，K8s 托管

COS：对象存储

COS 的 SLA 是 99.99%，跟 OSS 差不多。我用它存过游戏录像、小程序图片、爬虫数据。COS 的 CDN 加速域名配置比阿里云简单，控制台点几下就好了。

TKE：容器服务

TKE 跟 ACK 一样是 K8s 托管版。2024 年 TKE 推出了 SuperNode，一个节点上能跑几千个 Pod，比传统节点效率高很多。跑 Serverless 类工作负载特别合适。

微信生态：这才是腾讯云的杀手锏

如果你做微信小程序或者公众号后端，腾讯云有独特优势：

  • 云开发 CloudBase：不用管服务器，前端直接调云函数和云数据库，小程序上线超快。我有个小项目从写代码到上线只用了一下午
  • 微信支付对接：官方 SDK 集成最好，文档全是腾讯自家的例子
  • 内容安全：小程序里用户 UGC 内容必须过内容安全检测，腾讯云的文本/图片审核 API 直接对接，不用自己接第三方
  • 消息推送：小程序订阅消息、公众号模板消息，跟腾讯云消息队列打通
小程序开发的坑

2024 年小程序审核越来越严。一开始我写了个功能被驳回，理由是"涉及社交功能但未接入用户实名"。后来才知道微信对 UGC 类小程序要求实名认证，这个在开发前就要考虑好，不然上线前全得改。

命令行工具 tccli

腾讯云的 CLI 叫 tccli，用法跟阿里云的 aliyun CLI 类似。我习惯用命令行管理云资源，比点控制台快多了。

# 安装
pip3 install tccli

# 配置密钥
tccli configure set --region ap-guangzhou
tccli configure set --secretId AKxxxxx
tccli configure set --secretKey xxxxx

# 查询 CVM 实例
tccli cvm DescribeInstances

# 创建 CVM（最简）
tccli cvm RunInstances --InstanceType S5.MEDIUM4 \
  --ImageId img-xxx --InstanceChargeType POSTPAID_BY_HOUR

写自动化脚本的时候 tccli 特别好用。我写过一个脚本：高峰期自动扩容 CVM 实例，低谷期自动缩容，帮团队省了 40% 的开发环境费用。

VPC 网络架构

VPC 设计的核心原则：公网入口只有 CLB，应用层在内网，数据库只对应用子网开放。这样被攻击的面最小。我之前犯过把数据库安全组放成 0.0.0.0/0 的错，赶紧收回来了。

踩坑记录

  1. 新购续费涨价：新购 1 折优惠，续费原价。买的时候注意看下续费价格，别买完第二年吓一跳
  2. CDN 缓存策略：一开始静态文件没设缓存策略，每次回源，OSS 请求量大。后来设置了 7 天缓存，命中率从 30% 涨到 95%
  3. 域名备案：国内服务器必须备案，首次备案要 20 个工作日。急着上线的话先买境外节点
  4. 对象存储配额：COS 默认单 bucket 容量没限制，但有 QPS 限制。我做爬虫的项目一天产生 50 万文件，突然遇到限流才发现
  5. SSH 密钥管理：CVM 默认给密码登录，我忘了改成密钥方式，第二天就被爆破了。赶紧禁用密码登录，只用密钥

FAQ

腾讯云和阿里云哪个便宜？

新购基本都有折扣，差不多。但续费阿里云稍微便宜一点，长期用阿里云更划算。腾讯云的游戏类产品（GPU 实例、音视频处理）性价比更高。

小程序用云开发还是自建服务器？

MVP 阶段用云开发，快。日活过千以后迁到自建服务器，成本更可控，性能更好控制。我见过很多团队一直用云开发，月费跑到两三千还没迁，其实自建服务器成本只要三分之一。

CDN 命中率怎么提高？

几个关键：静态资源文件名加 hash（如 app.abc123.js），改了文件就换 hash，CDN 可以永久缓存。设置合理的 Cache-Control 头。动态接口不缓存。

腾讯云免费额度有多少？

新用户有免费试用套餐。CVM 有 1 个月免费，COS 有 50GB 存储 + 10GB 下行流量免费。但免费额度用完要自己关服务，别让它跑着扣钱。
