配置中心：从你遇到的问题出发

🏷️ 配置中心

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及配置中心怎么帮你解决。

flowchart TB A[配置中心] --> B[用户服务] A --> C[订单服务] A --> D[商品服务] A --> E[灰度发布配置]

1. 多台服务器配置不一样

你遇到的问题

你改了配置要一台台 SSH 上去改，经常漏一台。

怎么解决？所有配置集中到配置中心，服务启动时自动拉取。

2. 改配置要重启服务

你遇到的问题

改个数据库连接池配置，要重启整个服务。

怎么解决？配置中心支持热更新，不用重启。

3. 敏感配置放代码里不安全

你遇到的问题

数据库密码写在代码里，提交到 Git 就泄露了。

怎么解决？敏感配置放配置中心加密存储，代码里只放引用。
