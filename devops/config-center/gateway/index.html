API 网关

网关干什么

所有外部请求都先到网关，网关统一处理：路由、鉴权、限流、日志、协议转换。

功能说明
路由转发根据路径转发到后端服务
认证鉴权统一校验 JWT
限流熔断保护后端服务
日志监控统一记录访问日志
协议转换HTTP → gRPC

网关最佳实践

  • ✅ 鉴权放网关，后端服务不用管
  • ✅ 限流放网关，保护后端
  • ✅ 统一 CORS 处理
  • ✅ 请求 ID 透传
  • ❌ 不要在网关写业务逻辑
