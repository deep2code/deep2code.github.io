API 网关入门：从你遇到的问题出发

🏷️ API 网关

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及API 网关怎么帮你解决。

flowchart TB A[客户端] --> B[API 网关] B --> C[服务 A] B --> D[服务 B] B --> E[服务 C]

1. 客户端要调很多服务

你遇到的问题

前端要调十几个后端服务，每个都要写一遍认证、日志。

怎么解决？加一层 API 网关，统一入口，认证、限流、日志都在网关做。

2. API 网关是什么

你遇到的问题

API 网关是什么？

怎么解决？微服务统一入口，路由、认证、限流、熔断、日志都在这一层做。

3. 常用网关

你遇到的问题

常用 API 网关有哪些？

怎么解决？Kong、Spring Cloud Gateway、Nginx（简单路由）、APISIX。

核心功能

功能说明
路由转发把请求转发到后端服务
认证鉴权统一做登录校验
限流熔断保护后端不被打垮
日志监控统一记录请求日志
新手最容易踩的坑
  • 不要写业务逻辑网关只做通用功能，不要写业务逻辑在网关里。
  • 网关要高可用网关挂了所有服务都挂，一定要多实例部署。
