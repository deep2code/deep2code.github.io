Docker 入门：从你遇到的问题出发

🏷️ Docker

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Docker怎么帮你解决。

flowchart TB A[Dockerfile] --> B[build 镜像] B --> C[run 容器] C --> D[服务跑起来]

1. 本地能跑线上不行

你遇到的问题

代码本地跑没问题，一上线就报错，环境不一样。

怎么解决？用 Docker，把应用和环境打包成镜像，本地线上跑一样的。

2. Docker 是什么

你遇到的问题

Docker 是什么？

怎么解决？容器化工具，把应用和依赖打包成镜像，隔离环境，到处跑。

3. 常用命令

你遇到的问题

Docker 常用命令有哪些？

怎么解决？build、run、ps、images、exec、logs。

常用命令

命令说明
docker build构建镜像
docker run启动容器
docker ps看运行中容器
docker exec进容器
新手最容易踩的坑
  • Dockerfile 要精简用小基础镜像（alpine），多阶段构建，镜像更小。
  • 数据卷挂载数据库数据一定要挂载到宿主机，不然容器删了数据没了。
