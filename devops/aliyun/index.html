阿里云入门：新手第一次买服务器

🏷️ 阿里云

第一次买云服务器，看到一堆配置懵了：ECS、轻量、RDS、OSS，到底买哪个？这篇讲新手最常买的几个服务，怎么选不踩坑。

flowchart TD A[新手买云服务] --> B[跑网站] A --> C[存文件] A --> D[存数据库] B --> B1[轻量应用服务器] C --> C1[OSS对象存储] D --> D1[RDS云数据库]

第一次买，不知道选啥

⚠️
你遇到的问题

打开阿里云官网，看到一堆产品，不知道从哪下手。

怎么解决？新手先买轻量应用服务器，便宜，一键装环境，跑个人博客足够了。

# 新手第一步
买轻量应用服务器 2核2G
选离你最近的地域
选 Ubuntu 系统

网站图片太多，服务器硬盘不够

⚠️
你遇到的问题

博客图片都存在服务器上，硬盘越用越满。

怎么解决？把图片放到 OSS 对象存储，服务器只放代码，图片走 CDN 加速。

# OSS 用法
1. 开通 OSS，建个 bucket
2. 图片上传到 OSS
3. 网站引用 OSS 的图片链接

新手常用服务

服务 干嘛用 新手价格 什么时候买
轻量应用服务器 跑网站、跑代码 ~50元/月 必买，第一个就买它
OSS对象存储 存图片、文件 ~1元/月 图片多了再买
RDS云数据库 托管MySQL ~100元/月 用户量上来了再买
CDN加速 加速静态资源 ~10元/月 全国访问慢了再买

新手最容易踩的坑

❌
避坑指南
  • 新手别买包年，先买一个月试用，熟悉了再续
  • 地域选离你最近的，你在深圳就选深圳或广州，别选北京
  • 安全组一定要配好，只开必要端口，别把 3306、6379 暴露到公网
  • 服务器密码别用弱密码，用密钥登录，安全很多
