日志入门：从你遇到的问题出发

🏷️ 日志

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及日志怎么帮你解决。

flowchart TB A[应用日志] --> B[Filebeat] B --> C[Logstash] C --> D[Elasticsearch] D --> E[Kibana 查看]

1. 出问题找不到日志

你遇到的问题

生产出问题了，不知道去哪查日志。

怎么解决？搭日志系统，所有服务日志集中存，搜索查看。

2. ELK 是什么

你遇到的问题

听说 ELK，到底是什么？

怎么解决？Elasticsearch + Logstash + Kibana，日志收集分析栈。

3. 日志要记什么

你遇到的问题

知道要记日志，不知道记什么。

怎么解决？错误、请求、关键操作，不要瞎打日志，太多了找不到。

ELK 组件

组件用途
Elasticsearch存日志
Logstash处理日志
Kibana看日志
Filebeat采集日志
新手最容易踩的坑
  • 日志要结构化用 JSON 打日志，不要打纯文本，方便搜索。
  • 不要记敏感信息密码、身份证不要记到日志里。
