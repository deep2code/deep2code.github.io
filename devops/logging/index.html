日志系统：从你遇到的问题出发

🏷️ 日志系统

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及日志系统怎么帮你解决。

flowchart LR A[应用日志] --> B[采集] B --> C[存储] C --> D[检索分析] C --> E[告警]

1. 找错误日志要 SSH 到服务器

你遇到的问题

线上出问题，你要登录服务器找日志，翻半天。

怎么解决？所有日志集中到一个系统，网页上直接搜索。

2. 多台服务器不知道日志在哪

你遇到的问题

10 台服务器，你不知道错误在哪台。

怎么解决？日志集中存储，一台一台找的日子结束了。

3. 日志太多磁盘满

你遇到的问题

一天几个 G 日志，很快把磁盘写满。

怎么解决？日志定期清理，压缩存储，热数据存快盘，冷数据存便宜盘。

新手最容易踩的坑
  • 日志要结构化不要打一句一句话，用 JSON 格式，方便检索。
  • 不要打敏感信息密码、身份证不要打日志里。
