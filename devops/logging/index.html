日志入门：从你遇到的问题出发

🏷️ 日志

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及日志怎么帮你解决。

flowchart TB A[应用] --> B[打日志] B --> C[收集] C --> D[存储] D --> E[查询分析]

1. 线上出问题查不到

你遇到的问题

线上报错了，日志散在各个服务器，不知道去哪查。

怎么解决？做统一日志系统，集中收集、存储、检索日志。

2. 日志级别

你遇到的问题

日志级别有哪些？

怎么解决？DEBUG、INFO、WARN、ERROR、FATAL。

3. 怎么打日志

你遇到的问题

日志怎么打才好？

怎么解决？结构化日志（JSON），带 Trace ID，关键节点打日志。

日志级别

级别用途
DEBUG调试用
INFO正常业务流程
WARN警告，不影响主流程
ERROR错误，影响功能
新手最容易踩的坑
  • 不要打太多日志DEBUG 日志生产环境关掉，不然日志太多。
  • 敏感信息脱敏日志里密码、身份证这些敏感信息要脱敏。
