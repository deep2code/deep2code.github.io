结构化日志：从你遇到的问题出发

🏷️ 结构化日志

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及结构化日志怎么帮你解决。

flowchart LR A[文本日志] --> B[JSON 结构化] B --> C[方便搜索分析]

1. 日志格式乱七八糟

你遇到的问题

每个人打的日志格式不一样，搜起来麻烦。

怎么解决？统一结构化 JSON 日志，每个字段固定，方便搜索。

2. JSON 日志怎么打

你遇到的问题

怎么打 JSON 格式日志？

怎么解决？用日志库直接输出 JSON，不要自己拼字符串。

3. 有什么好处

你遇到的问题

怎么解决？方便搜索、统计、做监控告警。
