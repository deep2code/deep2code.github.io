结构化日志

为什么要结构化日志

传统文本日志查起来很痛苦：要 grep、要匹配正则。结构化日志就是 JSON 格式，可以按字段查询、聚合、统计。

{
  "timestamp": "2026-09-19T10:00:00Z",
  "level": "info",
  "service": "order-service",
  "traceId": "abc-123",
  "userId": 12345,
  "action": "create_order",
  "amount": 99.5,
  "duration": 120
}

日志级别

级别使用场景
ERROR错误，需要人工介入
WARN警告，不影响但要关注
INFO关键业务流程
DEBUG调试信息，生产关闭

日志规范

  • 每个请求带 traceId，全链路透传
  • 关键操作要记日志（登录、下单、支付）
  • 错误日志要带上下文（参数、用户、请求）
  • 不要打敏感信息（密码、身份证号）
