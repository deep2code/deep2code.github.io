LangChain 入门

为什么用 LangChain

直接调 OpenAI API 很简单，但做复杂应用就麻烦了：Prompt 管理、上下文窗口、工具调用、记忆、RAG……这些都要自己写。LangChain 把这些抽象成标准组件，拼积木就行。

组件作用类比
Model调用 LLM发动机
Prompt模板化 Prompt指令系统
Chain组合多个步骤流水线
Memory对话历史短期记忆
Retriever知识库检索长期记忆
Tool外部工具调用手和脚

第一个 Chain

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 初始化模型
llm = ChatOpenAI(model="gpt-4o", temperature=0.7)

# Prompt 模板
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}，用简洁的语言回答问题。"),
    ("user", "{question}")
])

# 组装 Chain（LCEL）
chain = prompt | llm | StrOutputParser()

# 调用
result = chain.invoke({
    "role": "Python 专家",
    "question": "什么是装饰器？"
})
print(result)

用 | 管道符把组件串起来，这就是 LCEL（LangChain Expression Language）。

LCEL 的好处

  • 自动批量：chain.batch([...]) 自动并发
  • 自动流式：chain.stream(...) 逐 token 输出
  • 异步支持：chain.ainvoke() 异步调用
  • 可观测：自动接入 LangSmith 追踪
