生产部署与评估

为什么需要监控

LLM 应用和传统软件不一样：同样的输入可能有不同的输出，你不知道哪一步出了问题。LangSmith 就是专门追踪 LangChain 应用的工具。

# 开启 LangSmith 追踪
import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "ls-..."
os.environ["LANGCHAIN_PROJECT"] = "my-chatbot"

# 之后所有的 chain 调用都会被自动追踪

评估体系

评估维度方法
回答准确性人工标注 + LLM 自动评分
相关性检索到的文档和问题是否相关
幻觉率回答是否基于给定文档
延迟首 token 延迟、总耗时
成本每次调用的 token 费用

成本控制

  • 分级模型：简单问题用小模型（gpt-4o-mini），复杂问题用大模型
  • 缓存：重复问题直接返回缓存结果
  • 限制上下文：检索只返回 top-k 个文档，不要塞太多
  • 流式输出：用户感知更快，体验更好

生产检查清单

  • ✅ 开启 LangSmith 或类似追踪
  • ✅ 配置重试和超时
  • ✅ 输入输出安全过滤（Prompt Injection）
  • ✅ 成本监控和告警
  • ✅ 降级策略：LLM 挂了怎么办？
