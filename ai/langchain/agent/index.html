Agent 与工具调用

💡 你想搞懂这个技术到底是干嘛的，什么时候该用它，什么时候不该用。不想上来就背一堆概念。

Agent 是什么

普通 Chain 是固定流程：输入 → Prompt → LLM → 输出。Agent 是让 LLM 自己决定下一步做什么：要不要查数据库？要不要搜索？要不要调用计算器？

from langchain.tools import tool
from langchain_openai import ChatOpenAI
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_core.prompts import ChatPromptTemplate

# 定义工具
@tool
def search_database(query: str) -> str:
    """查询数据库中的用户信息"""
    return f"用户 {query} 的信息：..."

@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    return str(eval(expression))

tools = [search_database, calculate]

# 创建 Agent
llm = ChatOpenAI(model="gpt-4o")
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个助手，可以使用工具回答问题。"),
    ("human", "{input}"),
    ("agent_scratchpad", "{agent_scratchpad}")
])

agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 运行
executor.invoke({"input": "张三的年龄加上 10 等于多少？"})
