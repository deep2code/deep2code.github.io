大语言模型（LLM）技术概览

大语言模型（Large Language Model）以 Transformer 为骨架、拿海量文本喂出来的深度学习模型，能写文本、写代码、做推理、跨语言理解。2022 年 ChatGPT 让 LLM 出圈；到 2025–2026 年，开源模型在推理、代码、数学这些核心能力上跟闭源旗舰的差距已经压到 5% 以内，而且只用差不多 1/30

核心架构

现代 LLM 基本都走 Transformer 的 Decoder-only 架构（2024 年起就是绝对主流），核心机制是自注意力（Self-Attention），再叠一层 Causal mask，保证每个位置只能看到自己及之前的 token：

# Self-Attention 简化示意
import torch
import torch.nn.functional as F

def attention(Q, K, V):
    # Scaled Dot-Product Attention
    # Q: query  (batch, seq_len, d_k)
    # K: key    (batch, seq_len, d_k)
    # V: value  (batch, seq_len, d_v)
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    # Causal mask: 只看当前及之前的 token
    mask = torch.tril(torch.ones(scores.size(-2), scores.size(-1)))
    scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = F.softmax(scores, dim=-1)
    return torch.matmul(weights, V)

推理优化技术

  • KV Cache：把算过的 Key/Value 矩阵缓存下来，省得重复算，是长上下文的地基。
  • 量化（Quantization）：把 FP16 权重压到 INT8 / INT4 / FP8，显存占用砍下来，本地部署必备。
  • PagedAttention：vLLM 的招牌创新，用分页方式管 KV Cache 显存，把吞吐顶上去。
  • 推测解码（Speculative Decoding）：小模型出草稿、大模型来验收，解码能快 2–3 倍。
  • Flash Attention：重排 GPU 显存的访问模式，既加速注意力计算又省显存。

2026 年的落地标配基本是：vLLM + 连续批处理 + Prefix Caching + INT4 量化，端侧走蒸馏小模型。

调用 LLM API

2026 年 OpenAI 兼容端点已是事实标准——OpenAI、DeepSeek、通义、智谱都给兼容接口。Go 侧用 go-openai 一把通吃，模型名和密钥都从环境变量取，别让代码被某家厂商绑死：

// Go 调用任意 OpenAI 兼容 API
package main

import (
    "context"
    "fmt"
    "os"
    "github.com/sashabaranov/go-openai"
)

func main() {
    client := openai.NewClientWithConfig(openai.ClientConfig{
        BaseURL: os.Getenv("LLM_BASE_URL"), // 如 https://api.openai.com/v1 或厂商兼容端点
        APIKey:  os.Getenv("LLM_API_KEY"),
    })
    resp, err := client.CreateChatCompletion(context.Background(),
        openai.ChatCompletionRequest{
            Model: os.Getenv("LLM_MODEL"), // 如 "gpt-5.6"、"deepseek-v4-flash"、"qwen3.8-max"
            Messages: []openai.ChatCompletionMessage{
                {Role: openai.ChatMessageRoleUser, Content: "用一句话解释 Go 的 goroutine"},
            },
            MaxTokens: 100,
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Println(resp.Choices[0].Message.Content)
}
