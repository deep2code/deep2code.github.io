LLM

大语言模型（LLM）技术概览

大语言模型（Large Language Model）是基于 Transformer 架构、使用海量文本数据训练的深度学习模型，具备文本生成、代码编写、逻辑推理、多语言理解等能力。2022 年 ChatGPT 发布标志 LLM 走向大众；到 2025-2026 年，开源模型在推理、代码、数学等核心能力上与闭源旗舰的差距已收窄到 5% 以内，并以接近 1/30 的推理成本成为工程落地的主流选择（2026 年 6 月 DeepSeek V4 输入定价约 $0.14/百万 token，对照头部闭源 API）。

核心架构

现代 LLM 基于 Transformer 的 Decoder-only 架构（2024 年起成为绝对主流），核心机制是自注意力（Self-Attention），配合 Causal mask 保证每个位置只能看到当前位置及之前的 token：

# Self-Attention 简化示意
import torch
import torch.nn.functional as F

def attention(Q, K, V):
    # Scaled Dot-Product Attention
    # Q: query  (batch, seq_len, d_k)
    # K: key    (batch, seq_len, d_k)
    # V: value  (batch, seq_len, d_v)
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    # Causal mask: 只看当前及之前的 token
    mask = torch.tril(torch.ones(scores.size(-2), scores.size(-1)))
    scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = F.softmax(scores, dim=-1)
    return torch.matmul(weights, V)

推理优化技术

  • KV Cache：缓存已计算的 Key/Value 矩阵，避免重复计算，是长上下文的基础。
  • 量化（Quantization）：将 FP16 权重降为 INT8/INT4/FP8，减少显存占用，本地部署必备。
  • PagedAttention：vLLM 的核心创新，分页管理 KV Cache 显存，提高吞吐。
  • 推测解码（Speculative Decoding）：小模型生成草稿、大模型验证，解码提速约 2-3 倍。
  • Flash Attention：重排 GPU 显存访问模式，加速注意力计算并省显存。

2026 年的落地组合基本是：vLLM + 连续批处理 + Prefix Caching + INT4 量化，端侧则用蒸馏小模型。

调用 LLM API

2026 年 OpenAI 兼容端点已是事实标准——OpenAI、DeepSeek、通义、智谱等均提供兼容接口。Go 侧用 go-openai 一把通吃，模型名与密钥都从环境变量取，避免代码被具体厂商绑定：

// Go 调用任意 OpenAI 兼容 API
package main

import (
    "context"
    "fmt"
    "os"
    "github.com/sashabaranov/go-openai"
)

func main() {
    client := openai.NewClientWithConfig(openai.ClientConfig{
        BaseURL: os.Getenv("LLM_BASE_URL"), // 如 https://api.openai.com/v1 或厂商兼容端点
        APIKey:  os.Getenv("LLM_API_KEY"),
    })
    resp, err := client.CreateChatCompletion(context.Background(),
        openai.ChatCompletionRequest{
            Model: os.Getenv("LLM_MODEL"), // 如 "gpt-5.6"、"deepseek-v4-flash"、"qwen3.8-max"
            Messages: []openai.ChatCompletionMessage{
                {Role: openai.ChatMessageRoleUser, Content: "用一句话解释 Go 的 goroutine"},
            },
            MaxTokens: 100,
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Println(resp.Choices[0].Message.Content)
}
