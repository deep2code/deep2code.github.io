Go 入门：从你遇到的问题出发

🏷️ Go 入门

你要写个高性能的后端服务，并发量很大，用 Python 扛不住。或者你想写个单文件部署的工具，不用装一堆依赖。

这篇不讲理论，就讲你真的会遇到的问题，以及 Go 怎么帮你解决。

场景一：Python 写的服务，并发一高就扛不住了

你遇到的问题

你用 Python 写了个接口服务，平时还好，大促的时候并发量上来了，Python 因为 GIL 的限制，CPU 跑不满，请求开始超时。你想换个性能更好的语言。

Go 怎么解决？Go 天生支持高并发，goroutine 轻量级协程，一个程序能同时跑几万个 goroutine，CPU 跑满没问题。性能比 Python 高 10 倍以上。

package main

import (
    "fmt"
    "net/http"
)

func hello(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello, World!")
}

func main() {
    http.HandleFunc("/", hello)
    http.ListenAndServe(":8080", nil)
}

就这么简单，一个高性能的 HTTP 服务就写好了。编译完是单个二进制文件，扔到服务器上直接跑，不用装 Python，不用装依赖。

场景二：部署个 Python 服务，要装一堆依赖

你遇到的问题

你写了个 Python 脚本，要部署到服务器上，得先装 Python 版本，再装 pip，再装一堆依赖，版本还经常冲突。部署一次折腾半天。

Go 怎么解决？Go 编译完是单个二进制文件，没有任何依赖。你本地编译完，把这个文件扔到服务器上，直接跑就行。

# 本地编译
go build -o myapp main.go

# 扔到服务器上直接跑
./myapp

现在部署就是传一个文件的事，1 分钟搞定。不用装环境，不用装依赖。

场景三：想写个命令行工具，自动处理重复工作

你遇到的问题

你每天要重复做一些操作：备份数据库、清理日志、同步文件。你想写个命令行工具，一键搞定。用 Python 写也行，但部署要装环境。

Go 怎么解决？写命令行工具特别方便，编译完单个文件，发给同事直接就能用，不用装任何东西。

package main

import (
    "fmt"
    "os"
)

func main() {
    if len(os.Args) < 2 {
        fmt.Println("用法: mytool backup")
        return
    }

    command := os.Args[1]
    switch command {
    case "backup":
        fmt.Println("开始备份数据库...")
    case "clean":
        fmt.Println("开始清理日志...")
    default:
        fmt.Println("未知命令:", command)
    }
}

编译完就是一个 mytool 文件，双击就能跑，发给同事直接用。

Go 核心概念通俗理解
包（Package）代码组织：把相关的代码放在一个包里
函数（func）一段可复用的代码
结构体（struct）自定义数据类型，把几个字段打包在一起
接口（interface）定义行为，不用关心具体实现
goroutine轻量级协程，写并发特别简单
channelgoroutine 之间通信的管道
新手最容易踩的坑
  • 错误处理一定要写：Go 是显式错误处理，不要忽略返回的 error。
  • 不要忽略 nil：指针没初始化就是 nil，直接用会 panic。
  • goroutine 泄漏：起了 goroutine 一定要能退出，不然内存越占越多。
  • 切片和数组不一样：切片是动态长度的，数组是固定长度的，别搞混了。
