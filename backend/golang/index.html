Go 入门：从你遇到的问题出发

🏷️ Go

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Go怎么帮你解决。

flowchart LR A[Go] --> B[后端开发] A --> C[云原生] A --> D[高并发服务]

1. Go 为什么这么火

你遇到的问题

听说 Go 很火，为什么？

怎么解决？简单、性能高、并发好，云原生（K8s/Docker）都是 Go 写的。

2. 和 Python 比有什么好

你遇到的问题

Go 比 Python 好在哪？

怎么解决？性能高，编译成一个二进制文件，部署简单，并发好。

3. 新手怎么开始

你遇到的问题

想学习 Go，不知道从哪下手。

怎么解决？先学基础语法，再学 Gin 写个小接口。

Go 特点

特点说明
简单语法简单，上手快
性能高接近 C 的性能
并发goroutine 轻量并发
部署一个二进制文件
新手最容易踩的坑
  • 新手先学基础不要上来就学框架，先把语法和 goroutine 搞懂。
  • 用 go modGo 1.11+ 自带 go mod，不要用 GOPATH。
