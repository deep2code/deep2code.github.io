tRPC 入门

tRPC 解决什么问题

传统全栈开发最大的痛点：前端调后端接口，类型不共享。后端改了字段名，前端不知道，运行时才报错。要么写 API 文档，要么用 codegen 自动生成，都很麻烦。

tRPC 让你直接在前端调用后端的函数，类型自动共享，编译时就知道有没有错。

方案类型安全需要文档学习成本适合场景
REST + TS手动维护✅ 需要低对外 API
GraphQL自动Schema 即文档高复杂查询、对外
tRPC自动共享❌ 不需要中内部全栈应用

一个完整例子

// server/trpc.ts - 后端
import { initTRPC } from '@trpc/server'
const t = initTRPC.create()

export const router = t.router({
  getUser: t.procedure
    .input((val: unknown) => {
      if (typeof val === 'string') return val
      throw new Error('Invalid input')
    })
    .query(({ input }) => {
      return { id: input, name: '张三' }
    }),
})

export type AppRouter = typeof router
// client.ts - 前端
import { createTRPCProxyClient, httpBatchLink } from '@trpc/client'
import type { AppRouter } from './server/trpc'

const client = createTRPCProxyClient({
  links: [httpBatchLink({ url: 'http://localhost:3000/trpc' })]
})

// 类型安全！
const user = await client.getUser.query('1')
user.name // ✅ 自动补全
user.nonExistent // ❌ 编译错误
