tRPC 入门：从你遇到的问题出发

🏷️ tRPC

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及tRPC怎么帮你解决。

flowchart LR A[后端定义] --> B[前端调用] B --> C[类型自动同步] C --> D[不用手写 API 文档]

1. 前后端类型不一致

你遇到的问题

前后端接口改了，前端不知道，经常出 bug。

怎么解决？用 tRPC，前后端类型自动同步，改完后端前端自动有提示。

2. tRPC 是什么

你遇到的问题

tRPC 是什么？

怎么解决？TypeScript RPC，前后端用同一套类型，不用手写 API 文档。

3. 和 REST 区别

你遇到的问题

tRPC 和 REST 区别？

怎么解决？REST 要手写 API 文档、类型定义；tRPC 自动生成。

对比

方案类型同步开发效率
REST + OpenAPI手动生成中
GraphQL自动高
tRPC全自动最高（TS 全栈）
新手最容易踩的坑
  • TS 全栈项目用前后端都是 TypeScript 的项目，强烈推荐 tRPC。
  • 跨语言不用如果有 Python/Go 后端，还是用 REST/GraphQL。
