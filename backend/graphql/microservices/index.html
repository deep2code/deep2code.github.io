GraphQL 微服务：从你遇到的问题出发

🏷️ GraphQL 微服务

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及GraphQL 微服务怎么帮你解决。

flowchart TB A[前端] --> B[GraphQL Gateway] B --> C[用户服务] B --> D[订单服务] B --> E[商品服务]

1. 微服务前端要调很多接口

你遇到的问题

微服务前端要调十几个服务，太麻烦。

怎么解决？用 GraphQL Gateway，聚合所有微服务，前端一个端点搞定。

2. GraphQL Gateway 是什么

你遇到的问题

GraphQL Gateway 是什么？

怎么解决？聚合多个微服务的 GraphQL Schema，对外暴露一个统一端点。

3. 常用工具

你遇到的问题

GraphQL 微服务用什么工具？

怎么解决？Apollo Federation，最流行的 GraphQL 微服务方案。
