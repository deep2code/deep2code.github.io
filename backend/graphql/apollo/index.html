Apollo Server：从你遇到的问题出发

🏷️ Apollo

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Apollo怎么帮你解决。

flowchart TB A[Node.js] --> B[Apollo Server] B --> C[GraphQL Schema] B --> D[Resolver] B --> E[接前端请求]

1. Node.js 怎么做 GraphQL

你遇到的问题

你用 Node.js，想做 GraphQL 服务，用什么？

怎么解决？Apollo Server 是最常用的 GraphQL 服务端框架。

2. 和 Express 怎么结合

你遇到的问题

我已经有 Express 服务了，怎么加 GraphQL？

怎么解决？Apollo 可以直接挂在 Express 上，一个端口同时提供 REST 和 GraphQL。

3. 新手怎么开始

你遇到的问题

不知道怎么上手 Apollo。

怎么解决？先定义 Schema，再写 Resolver，跑个简单的查询试试。

核心概念

概念说明
Schema定义数据类型和查询
Resolver定义每个查询怎么取数据
TypeDefs类型定义
新手最容易踩的坑
  • 先跑通 Hello World不要一上来就做复杂的，先跑个最简单的查询。
  • 用 Playground 调试Apollo 自带 Playground，方便调试查询。
