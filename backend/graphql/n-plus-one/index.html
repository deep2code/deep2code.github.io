GraphQL N+1 问题：从你遇到的问题出发

🏷️ N+1

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及N+1怎么帮你解决。

flowchart TB A[查 N 个文章] --> B[每个文章查作者] B --> C[N+1 次查询] C --> D[慢死了]

1. GraphQL 查询很慢

你遇到的问题

你写的 GraphQL 查询，看起来简单，实际执行很慢。

怎么解决？大概率是 N+1 问题，查列表再逐个查关联对象。

2. 什么是 N+1 问题

你遇到的问题

听说 GraphQL 有 N+1 问题，什么意思？

怎么解决？查 N 条数据，每条再查一次关联，总共 N+1 次查询。

3. 怎么解决

你遇到的问题

知道问题了，怎么解决？

怎么解决？用 DataLoader 批量加载，一次查所有关联数据。

解决方案

方案说明
DataLoader批量加载，一次查完
SQL 批量查写 SQL 批量查关联
新手最容易踩的坑
  • 一定要用 DataLoader不用 DataLoader 肯定会有 N+1 问题。
  • 看 SQL 日志打开 SQL 日志，看是不是真的 N+1。
