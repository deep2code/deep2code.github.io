GraphQL 入门：从你遇到的问题出发

🏷️ GraphQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及GraphQL怎么帮你解决。

flowchart TB A[REST API] --> B[GraphQL] B --> C[按需取数据] C --> D[一个端点]

1. REST 接口太多

你遇到的问题

前端要什么数据就要写一个 REST 接口，太多了。

怎么解决？用 GraphQL，一个端点，前端要什么数据自己选。

2. GraphQL 是什么

你遇到的问题

GraphQL 是什么？

怎么解决？API 查询语言，前端按需取数据，不用后端改接口。

3. 和 REST 区别

你遇到的问题

GraphQL 和 REST 区别？

怎么解决？REST 多个端点固定返回，GraphQL 一个端点按需查。

对比

对比RESTGraphQL
端点多个一个
数据固定返回按需选
学习成本简单中等
新手最容易踩的坑
  • 简单项目用 REST简单项目用 REST 就够，不要上来就 GraphQL。
  • 复杂项目用 GraphQL数据关系复杂的项目用 GraphQL 好。
