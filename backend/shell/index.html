Shell 脚本：从你遇到的问题出发

🏷️ Shell

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Shell怎么帮你解决。

flowchart LR A[重复手动操作] --> B[写成 Shell 脚本] B --> C[一键执行] C --> D[省时间不出错]

1. 每次部署要敲一堆命令

你遇到的问题

你部署要先 cd、再 build、再传服务器、再重启，每次敲半天。

怎么解决？写成 Shell 脚本，一条命令完成所有操作。

2. 批量操作太麻烦

你遇到的问题

你要改 100 个服务器的配置，一台台 SSH 上去改。

怎么解决？写个脚本，自动批量改完所有服务器。

3. 定时任务怎么写

你遇到的问题

你要每天凌晨备份数据库，手动做肯定忘。

怎么解决？写个备份脚本，用 crontab 定时跑。

常用 Shell 命令

命令用途
ls列文件
cd切目录
grep搜索内容
find找文件
xargs批量处理
新手最容易踩的坑
  • 脚本要加错误处理脚本开头加 set -e，出错就停，不要继续往下跑。
  • 不要写太复杂的脚本Shell 适合简单任务，复杂任务用 Python。
