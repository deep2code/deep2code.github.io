Spring Cloud：从你遇到的问题出发

🏷️ Spring Cloud

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Spring Cloud怎么帮你解决。

flowchart TB A[Spring Cloud] --> B[注册中心 Nacos] A --> C[配置中心] A --> D[网关] A --> E[熔断]

1. Java 微服务怎么搭

你遇到的问题

你用 Java 做微服务，不知道用什么技术栈。

怎么解决？Spring Cloud 一整套，注册中心、配置中心、网关、熔断都有。

2. 和 Dubbo 比哪个好

你遇到的问题

Spring Cloud 和 Dubbo 选哪个？

怎么解决？Spring Cloud 全家桶，生态全；Dubbo 轻量，RPC 快。

3. 新手怎么开始

你遇到的问题

Spring Cloud 组件太多了，不知道从哪下手。

怎么解决？先从 Nacos + 网关开始，跑通服务注册发现，再加其他。

常用组件

组件用途
Nacos注册中心 + 配置中心
GatewayAPI 网关
OpenFeign服务调用
Sentinel熔断限流
新手最容易踩的坑
  • 不要一次全上先把核心的注册中心、网关跑起来，其他按需加。
  • 版本要对齐Spring Cloud 和 Spring Boot 版本要对应，不然兼容问题很多。
