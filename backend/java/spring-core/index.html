Spring 核心：从你遇到的问题出发

🏷️ Spring

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Spring怎么帮你解决。

flowchart TB A[Spring 容器] --> B[IoC 控制反转] A --> C[DI 依赖注入] A --> D[AOP 面向切面]

1. Spring 为什么这么火

你遇到的问题

Java 为什么都用 Spring？

怎么解决？解决了 Java 企业开发的麻烦，IoC、AOP 这些功能，不用自己写一堆。

2. 什么是 IoC

你遇到的问题

一直听说 IoC，不知道是什么。

怎么解决？控制反转，对象不用自己 new，交给 Spring 容器管理。

3. AOP 有什么用

你遇到的问题

AOP 是干什么的？

怎么解决？把日志、权限这些通用逻辑抽出来，不用每个业务代码都写。

Spring 核心

概念说明
IoC控制反转，对象交给容器管理
DI依赖注入，自动给对象注入依赖
AOP面向切面，通用逻辑抽出来
新手最容易踩的坑
  • 先会用再懂原理先把 Spring Boot 用起来，再回头看 IoC、AOP 原理。
  • 不要记太多常用的注解会用就行，其他的查文档。
