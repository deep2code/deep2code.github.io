JVM 调优入门：从你遇到的问题出发

🏷️ JVM 调优

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及JVM 调优怎么帮你解决。

flowchart TB A[JVM] --> B[堆内存] B --> C[GC] C --> D[调优]

1. Java 程序 OOM

你遇到的问题

Java 服务跑着跑着就 OOM 了。

怎么解决？先看 GC 日志，调堆大小，选合适 GC。

2. JVM 是什么

你遇到的问题

JVM 是什么？

怎么解决？Java 虚拟机，跑 Java 字节码的运行环境。

3. 核心参数

你遇到的问题

JVM 核心调优参数有哪些？

怎么解决？-Xms/-Xmx（堆大小）、-XX:+UseG1GC（GC 选择）。

常用参数

参数说明
-Xms初始堆大小
-Xmx最大堆大小
-XX:+UseG1GC用 G1 垃圾回收器
新手最容易踩的坑
  • 先看日志调优前先看 GC 日志，不要瞎调。
  • G1 最常用Java 11+ 默认用 G1，新手用 G1 就行。
