OAuth2 与 OIDC

OAuth2 是什么

OAuth2 是一个授权框架，让第三方应用可以通过授权的方式访问用户在某个服务上的资源，而不需要用户名密码。

sequenceDiagram participant U as 用户 participant A as 你的应用 participant G as Google U->>A: 点击"用 Google 登录" A->>U: 跳转到 Google 登录页 U->>G: 输入 Google 账号密码 G->>U: 授权确认 G->>A: 重定向带 code A->>G: 用 code 换 access_token G->>A: 返回 access_token A->>G: 用 token 获取用户信息 G->>A: 返回用户信息 A->>U: 登录成功

场景流程说明

OIDC 是什么

OpenID Connect，在 OAuth2 之上加了一层身份认证。OAuth2 解决"授权"，OIDC 解决"认证"。

  • id_token：OIDC 特有，证明用户身份
  • userinfo 端点：获取用户信息
  • 标准 claims：sub、email、name 等标准字段
