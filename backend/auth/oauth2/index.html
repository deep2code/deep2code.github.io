OAuth2 入门：从你遇到的问题出发

🏷️ OAuth2

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及OAuth2怎么帮你解决。

flowchart LR A[第三方登录] --> B[跳授权页] B --> C[用户同意] C --> D[拿 Token]

1. 用微信登录

你遇到的问题

App 要支持微信登录，怎么搞？

怎么解决？用 OAuth2 授权码模式，跳转微信授权，拿 Token。

2. OAuth2 是什么

你遇到的问题

OAuth2 是什么？

怎么解决？授权框架，第三方应用不用密码就能访问用户数据。

3. 授权码模式是什么

你遇到的问题

OAuth2 最常用的授权码模式是什么？

怎么解决？跳转授权页 → 用户同意 → 拿授权码 → 换 Token。

授权模式

模式用途
授权码最常用（Web 应用）
客户端凭证服务端之间调用
隐式老的 SPA 用
新手最容易踩的坑
  • 第三方登录用授权码模式微信/QQ 登录都用授权码模式。
  • Token 要存好AccessToken 和 RefreshToken 要安全存储。
