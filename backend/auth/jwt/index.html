JWT 实战

💡 你想搞懂这个技术到底是干嘛的，什么时候该用它，什么时候不该用。不想上来就背一堆概念。

JWT 是什么

JSON Web Token，一种紧凑的 URL 安全的表示方法，用来在双方之间安全地传输信息。

Access + Refresh Token

// 登录
POST /auth/login
{
  "email": "user@example.com",
  "password": "password123"
}

// 返回
{
  "accessToken": "eyJhbGci...",  // 短期，15分钟
  "refreshToken": "eyJhbGci..."  // 长期，7天
}

// 刷新 token
POST /auth/refresh
{
  "refreshToken": "eyJhbGci..."
}

// 返回新的 accessToken
Token有效期存储位置用途
Access Token15 分钟内存调用 API
Refresh Token7 天HttpOnly Cookie刷新 Access Token

安全注意事项

坑：JWT 是 base64 编码，不是加密！不要在 payload 里存密码、身份证号等敏感信息。
  • 不要存在 localStorage：XSS 攻击会偷走
  • Refresh Token 存 HttpOnly Cookie：JS 读不到，防 XSS
  • 设置短过期时间：Access Token 15 分钟就够
  • 支持吊销：登出时把 Refresh Token 加入黑名单
