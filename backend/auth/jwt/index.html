JWT：从你遇到的问题出发

🏷️ JWT

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及JWT怎么帮你解决。

flowchart LR A[登录成功] --> B[生成 JWT] B --> C[返回给客户端] C --> D[后续请求带 JWT] D --> E[服务端验证 JWT]

1. 服务端存 Session 太麻烦

你遇到的问题

你要把登录状态存在服务端，多台服务器还要共享 Session。

怎么解决？JWT 把用户信息存在 Token 里，服务端不用存 Session。

2. 多服务怎么共享登录

你遇到的问题

用户服务登录了，订单服务怎么知道用户是谁？

怎么解决？JWT 自带用户信息，每个服务自己验证就行，不用共享。

3. Token 过期了怎么办

你遇到的问题

Token 被人偷了怎么办？

怎么解决？JWT 设短有效期，用 Refresh Token 刷新。

JWT 结构

部分说明
Header类型和算法
Payload用户信息和过期时间
Signature签名，防篡改
新手最容易踩的坑
  • 敏感信息不要放 PayloadPayload 是 Base64 编码，不是加密，别放密码。
  • 一定要设过期时间不设过期，Token 泄露了就永远能用。
