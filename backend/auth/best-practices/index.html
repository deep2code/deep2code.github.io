认证授权最佳实践

💡 你想搞懂这个技术到底是干嘛的，什么时候该用它，什么时候不该用。不想上来就背一堆概念。

密码存储

绝对不要：明文存储密码、MD5/SHA1 哈希密码。 
// ✅ 正确：用 bcrypt/argon2
import bcrypt from 'bcrypt'

// 注册
const hashed = await bcrypt.hash(password, 12)

// 登录
const valid = await bcrypt.compare(password, hashed)
方案推荐度说明
bcrypt✅ 推荐自适应，自带盐
argon2✅ 推荐最新，更安全
MD5/SHA1❌ 绝对不要彩虹表秒破
SHA256 无盐❌ 不要彩虹表能破

RBAC 权限模型

// 角色权限
const roles = {
  admin: ['*'],
  editor: ['article:read', 'article:write', 'article:delete'],
  viewer: ['article:read']
}

// 检查权限
function hasPermission(user, permission) {
  const userPermissions = roles[user.role] || []
  return userPermissions.includes('*') || userPermissions.includes(permission)
}

安全加固清单

  • ✅ 密码用 bcrypt/argon2 哈希
  • ✅ HTTPS 全站加密
  • ✅ JWT 短期 + Refresh Token
  • ✅ 登录失败次数限制
  • ✅ 敏感操作二次验证
  • ✅ 定期清理无效 token
  • ✅ 操作日志审计
