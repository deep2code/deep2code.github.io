登录认证：从你遇到的问题出发

🏷️ 登录认证

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及登录认证怎么帮你解决。

flowchart LR A[用户输入账号密码] --> B[服务端验证] B -->|成功| C[返回 Token] C --> D[后续请求带 Token] D --> E[服务端验证 Token] E --> F[返回数据]

1. 每次请求都要带账号密码

你遇到的问题

用户每调一个接口都要输账号密码，体验太差。

怎么解决？登录一次拿到 Token，后面请求都带 Token。

2. Token 泄露了怎么办

你遇到的问题

Token 被人偷了，别人就能冒充用户。

怎么解决？Token 设短有效期，刷新 Token 设长有效期。

3. 多服务共享登录状态

你遇到的问题

用户服务登录了，订单服务怎么知道用户是谁？

怎么解决？用 JWT，服务端不用存 session，Token 自带用户信息。

认证方式对比

方式特点适合
Session服务端存状态单体应用
JWT无状态，自带信息微服务
OAuth2第三方登录微信/谷歌登录
新手最容易踩的坑
  • 密码要加密存永远不要明文存密码，用 bcrypt 哈希。
  • HTTPS 必须用HTTP 传 Token 等于明文。
