认证入门：从你遇到的问题出发

🏷️ 认证

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及认证怎么帮你解决。

flowchart TB A[用户登录] --> B[验证账号密码] B --> C[发 Token] C --> D[后续请求带 Token] D --> E[验证 Token]

1. 怎么实现登录认证

你遇到的问题

做网站要登录，不知道怎么弄。

怎么解决？账号密码登录，验证通过发 Token，后续请求带 Token 验证。

2. Session 和 JWT 区别

你遇到的问题

认证用 Session 还是 JWT？

怎么解决？Session 存在服务端，JWT 存在客户端，现在前后端分离常用 JWT。

3. OAuth2 是什么

你遇到的问题

听说微信/QQ 登录用 OAuth2，是什么？

怎么解决？开放授权协议，第三方登录用的，不用把密码给第三方。

认证方式

方式适合
Session传统服务端渲染
JWT前后端分离
OAuth2第三方登录
新手最容易踩的坑
  • 密码要加密存不要明文存密码，用 bcrypt 哈希。
  • Token 要设过期不要发永久 Token，设短过期时间，用 refresh token。
