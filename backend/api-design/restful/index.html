RESTful API：从你遇到的问题出发

🏷️ RESTful

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及RESTful怎么帮你解决。

flowchart LR A[GET /users] --> B[查列表] A[GET /users/1] --> C[查单个] A[POST /users] --> D[新建] A[PUT /users/1] --> E[修改] A[DELETE /users/1] --> F[删除]

1. API 设计不统一

你遇到的问题

你一个接口叫 /getUser，另一个叫 /userList，前端看得头大。

怎么解决？RESTful 风格，URL 用名词，方法表示操作。

2. 不知道用哪个 HTTP 方法

你遇到的问题

什么时候用 GET，什么时候用 POST？

怎么解决？GET 查、POST 新建、PUT 修改、DELETE 删除。

3. 状态码怎么用

你遇到的问题

返回 200 还是 400？

怎么解决？200 成功、400 参数错、401 未登录、500 服务器错。

RESTful 规范

操作方法URL
查列表GET/users
查单个GET/users/1
新建POST/users
修改PUT/users/1
删除DELETE/users/1
新手最容易踩的坑
  • URL 用名词不用动词用 /users 不要用 /getUsers。
  • 返回格式统一code、message、data 三个字段。
