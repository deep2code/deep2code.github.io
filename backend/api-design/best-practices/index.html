API 设计最佳实践

安全最佳实践

  • HTTPS：全站 HTTPS，不要用 HTTP
  • 认证授权：JWT/OAuth2，不要自己造轮子
  • 输入校验：所有输入都要校验，不要信任前端
  • 输出过滤：不要泄露敏感信息（密码哈希、内部 ID）
  • CORS：配置白名单，不要用 *
  • 限流：防止暴力破解、爬虫

幂等性

POST 创建接口可能因为网络重试导致重复创建。解决：

  • 幂等键：客户端生成唯一 ID，服务端去重
  • 唯一约束：数据库加唯一索引
  • PUT 天然幂等：更新操作天然幂等

性能最佳实践

问题解决方案
列表接口慢分页 + 索引 + 缓存
频繁查询加 Redis 缓存
批量操作提供批量接口，避免 N+1
大文件下载用 CDN，不要走后端

版本兼容策略

  • 新增字段：向后兼容，直接加
  • 删除字段：先标记 deprecated，过几个版本再删
  • 修改字段类型：新建字段，旧字段保留
  • 不兼容变更：升大版本号，旧版本保留一段时间
