API 设计入门：从你遇到的问题出发

🏷️ API 设计

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及API 设计怎么帮你解决。

flowchart TB A[API 设计] --> B[RESTful] B --> C[命名规范] C --> D[错误码]

1. API 命名乱

你遇到的问题

API 接口名乱七八糟，前端不知道怎么调用。

怎么解决？按 RESTful 规范命名，用名词、HTTP 方法表达操作。

2. API 设计是什么

你遇到的问题

API 设计是什么？

怎么解决？设计接口的规范，让接口好调用、好维护。

3. RESTful 是什么

你遇到的问题

RESTful 是什么？

怎么解决？一种 API 设计风格，用 URL 表示资源，HTTP 方法表示操作。

HTTP 方法

方法操作
GET查询
POST创建
PUT更新
DELETE删除
新手最容易踩的坑
  • URL 用名词URL 用名词，不要用动词。
  • 版本号API 要带版本号，方便升级。
