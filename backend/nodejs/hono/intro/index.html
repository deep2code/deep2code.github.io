Hono 入门

Hono 是什么

Hono 是一个轻量级的 Web 框架，日语里 "火焰" 的意思。只有 14KB，没有依赖，支持所有 JavaScript 运行时：Node.js、Bun、Deno、Cloudflare Workers、Vercel Edge。

框架大小多运行时Edge 支持性能
Hono14KB✅ 全支持✅ 原生极高
Express200KB+仅 Node❌ 不支持中等
Fastify80KB+仅 Node❌ 不支持高
Koa50KB+仅 Node❌ 不支持中等

第一个 Hono 应用

import { Hono } from 'hono'

const app = new Hono()

app.get('/', (c) => c.text('Hello Hono!'))
app.get('/users/:id', (c) => {
  const id = c.req.param('id')
  return c.json({ id, name: '张三' })
})

app.post('/users', async (c) => {
  const body = await c.req.json()
  return c.json({ id: 1, ...body }, 201)
})

export default app

路由分组

const users = new Hono()
  .get('/', (c) => c.json([...]))
  .get('/:id', (c) => c.json({ ... }))
  .post('/', (c) => c.json({ ... }, 201))

const api = new Hono()
  .route('/users', users)
  .get('/health', (c) => c.json({ status: 'ok' }))

app.route('/api', api)
