Edge 部署

💡 你之前用过一点，但只知道皮毛，遇到复杂问题就懵了。你想从原理上搞明白，而不是只会复制粘贴配置。

什么是 Edge 计算

Edge 计算就是把代码部署到离用户最近的边缘节点，减少延迟。传统应用部署在单个服务器，全球用户访问都要到这个服务器；Edge 应用部署在几百个节点，用户访问最近的节点。

平台冷启动位置限制
Cloudflare Workers~5ms300+ 节点CPU 时间有限
Vercel Edge~10ms全球 18 区域不支持原生 API
Deno Deploy~5ms35+ 节点类似

部署到 Cloudflare Workers

// index.ts
import { Hono } from 'hono'
const app = new Hono()

app.get('/', (c) => c.text('Hello Edge!'))

export default app
# wrangler.toml
name = "my-hono-app"
compatibility_date = "2026-01-01"

# 部署
npx wrangler deploy

Edge 应用最佳实践

  • 无状态：不要在内存存数据，用 KV/D1/Durable Objects
  • 快请求：CPU 时间有限，不要做重计算
  • 就近数据库：用边缘数据库（Neon、PlanetScale）
  • 缓存：尽量用 Cache API 缓存响应
