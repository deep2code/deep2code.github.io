Node.js 入门：从你遇到的问题出发

🏷️ Node.js

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Node.js怎么帮你解决。

flowchart LR A[JavaScript] --> B[Node.js 运行时] B --> C[后端开发] B --> D[工具链]

1. Node.js 是什么

你遇到的问题

听说 Node.js 能让 JS 跑在服务器上？

怎么解决？Chrome V8 引擎做的 JS 运行时，让 JS 能写后端。

2. 用 Node.js 写后端好吗

你遇到的问题

Node.js 写后端有什么好？

怎么解决？前后端都用 JS，全栈，开发快，IO 密集场景性能好。

3. 新手怎么开始

你遇到的问题

想学习 Node.js，不知道从哪下手。

怎么解决？先学 npm，再学 Express 写个小接口。

Node.js 特点

特点说明
JS 全栈前后端都用 JS
事件驱动IO 密集性能好
生态大npm 包最多
异步非阻塞 IO
新手最容易踩的坑
  • CPU 密集不要用 NodeNode 单线程，CPU 密集会卡，适合 IO 密集。
  • 用 LTS 版本不要用最新版，用 LTS 长期支持版。
