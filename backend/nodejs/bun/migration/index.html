从 Node.js 迁移

迁移兼容性

Bun 90% 兼容 Node.js API。大部分 Express/Koa 项目可以直接跑。

场景兼容性说明
Express/Koa✅ 完全兼容直接 bun run 即可
npm 包✅ 大部分兼容原生模块可能有问题
fs/path/http✅ 完全兼容标准库 API 一致
worker_threads⚠️ 部分兼容用 Bun.spawn 替代
原生 C++ 模块⚠️ 需重新编译可能不支持

迁移步骤

# 1. 安装依赖
bun install

# 2. 尝试运行
bun run index.js

# 3. 修复问题（主要是原生模块）
# 4. 跑测试
bun test

# 5. 生产部署
bun run --prod index.js

生产部署

FROM oven/bun:latest
WORKDIR /app
COPY package.json bun.lockb ./
RUN bun install --frozen-lockfile
COPY . .
EXPOSE 3000
CMD ["bun", "run", "index.ts"]
注意：生产环境先跑完整测试套件，特别是数据库连接、文件 IO、第三方 SDK 这些容易出兼容问题的地方。
