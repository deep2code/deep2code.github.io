Bun 入门

Bun 是什么

Bun 是一个全新的 JavaScript 运行时，基于 Zig 编写，内置了打包器、转译器、包管理器、测试运行器。目标是替代 Node.js，速度快 3-5 倍。

特性Node.js 22Bun 1.x
启动速度100%3-5 倍快
npm install慢20 倍快
内置工具无（需第三方）打包/测试/转译全内置
TypeScript需要转译原生支持
ESM/CJS混用原生支持 ESM

安装与第一个项目

# 安装
curl -fsSL https://bun.sh/install | bash

# 初始化项目
bun init

# 运行
bun run index.ts

# 安装依赖
bun install express

内置工具链

Bun 把 Node 生态需要单独安装的工具全部内置了：

  • bun install：替代 npm/yarn/pnpm，快 20 倍
  • bun build：替代 webpack/vite，快速打包
  • bun test：替代 jest/vitest，零配置
  • bun --watch：替代 nodemon，自动重启
# 一键搞定
bun install
bun run dev
bun test
bun build --target=bun ./index.ts --outdir ./dist
