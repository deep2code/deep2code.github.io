集成测试：从你遇到的问题出发

🏷️ 集成测试

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及集成测试怎么帮你解决。

flowchart LR A[单元测试] --> B[集成测试] B --> C[接口测试] C --> D[全链路测试]

1. 单元测试都过了，放一起就坏了

你遇到的问题

每个模块单测都过了，连起来跑就出错。

怎么解决？写集成测试，测模块之间的接口。

2. 接口测试怎么做

你遇到的问题

你想测你的 API 接口对不对。

怎么解决？用 Postman 或者写自动化测试脚本，发请求看返回对不对。

3. 单元测试和集成测试区别

你遇到的问题

都是测试，有什么不一样？

怎么解决？单测测单个函数，集成测试测多个模块连起来。

测试分类

类型测什么
单元测试单个函数/类
集成测试模块之间
接口测试API 接口
E2E 测试整个流程
新手最容易踩的坑
  • 先写接口测试接口测试性价比最高，先把核心接口测了。
  • 测试要独立每个测试用例独立，不要互相依赖。
