测试：从你遇到的问题出发

🏷️ 测试

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及测试怎么帮你解决。

flowchart LR A[写代码] --> B[写单元测试] B --> C[跑测试] C -->|通过| D[提交代码] C -->|失败| E[改 bug]

1. 改了一个功能，其他地方坏了

你遇到的问题

你改了登录逻辑，结果注册也坏了，不知道。

怎么解决？写单元测试，改完跑一遍就知道哪坏了。

2. 上线前手动测太麻烦

你遇到的问题

每次上线要手动点一遍所有功能，半天就过去了。

怎么解决？自动化测试，一键跑完所有用例。

3. 不知道代码有没有用

你遇到的问题

你不知道改的代码有没有被执行到。

怎么解决？测试覆盖率工具，看哪些代码没被测到。

测试类型

类型测什么速度
单元测试单个函数/类快
集成测试模块之间中
E2E 测试整个流程慢
新手最容易踩的坑
  • 先测核心逻辑不要追求 100% 覆盖率，先测核心业务逻辑。
  • 测试要快单元测试要毫秒级，不然没人愿意跑。
