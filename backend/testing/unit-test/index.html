单元测试入门：从你遇到的问题出发

🏷️ 单元测试

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及单元测试怎么帮你解决。

flowchart TB A[写函数] --> B[写测试] B --> C[跑测试] C --> D{通过?} D -->|是| E[提交] D -->|否| F[改代码]

1. 改代码怕改坏

你遇到的问题

改了一个工具函数，怕影响其他地方。

怎么解决？写单元测试，改完跑测试，确保没改坏。

2. 单元测试是什么

你遇到的问题

单元测试是什么？

怎么解决？对最小单元（函数/类）做测试，验证输入输出对不对。

3. 怎么开始写

你遇到的问题

怎么开始写单元测试？

怎么解决？先给核心业务函数写，用 pytest（Python）/JUnit（Java）/Go test（Go）。

  • 先测核心逻辑不要追求 100% 覆盖，先测核心业务逻辑。
