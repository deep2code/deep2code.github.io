Code Review 看什么

看什么例子
正确性逻辑对不对？边界情况考虑了吗？
性能有没有 N+1 查询？有没有缓存？
安全有没有 SQL 注入？有没有权限校验？
可维护性命名清晰吗？函数太长吗？注释够吗？

什么时候重构

原则：不是没时间才不重构，是越不重构以后越没时间。每次加新功能时，顺手把坏味道修一下。
