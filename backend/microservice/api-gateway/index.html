API 网关实战：从你遇到的问题出发

🏷️ API 网关

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及API 网关怎么帮你解决。

flowchart TB A[客户端] --> B[网关] B --> C[鉴权] B --> D[限流] B --> E[路由]

1. 客户端要调多个服务

你遇到的问题

前端要调用户、订单、商品好几个服务，每个都要配跨域、鉴权。

怎么解决？加个 API 网关，统一入口，鉴权、路由、限流都在网关做。

2. 网关做什么

你遇到的问题

API 网关主要做什么？

怎么解决？路由转发、鉴权、限流、熔断、日志、协议转换。

3. 常用网关

你遇到的问题

常用 API 网关有哪些？

怎么解决？Kong、Spring Cloud Gateway、Nginx。

核心功能

功能说明
路由请求转发到对应服务
鉴权统一验证 Token
限流防止流量太大
熔断服务挂了降级
新手最容易踩的坑
  • 网关要高可用网关是单点，一定要部署多实例高可用。
  • 网关不要太重网关只做通用逻辑，业务逻辑不要放网关。
