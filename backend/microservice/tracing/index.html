链路追踪入门：从你遇到的问题出发

🏷️ 链路追踪

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及链路追踪怎么帮你解决。

flowchart TB A[入口] --> B[订单服务] B --> C[库存服务] C --> D[支付服务] D --> E[DB]

1. 接口慢找不到原因

你遇到的问题

一个接口响应要 2 秒，不知道慢在哪个服务。

怎么解决？做链路追踪，一个请求串起所有服务，看每一步耗时。

2. 链路追踪是什么

你遇到的问题

链路追踪是什么？

怎么解决？跟踪一个请求经过哪些服务，每一步耗时多少，快速定位慢的地方。

3. 常用工具

你遇到的问题

常用链路追踪工具有哪些？

怎么解决？Jaeger、Zipkin、OpenTelemetry。云厂商有 APM。

核心概念

概念说明
Trace一次完整请求
Span一次服务调用
Trace ID链路唯一 ID
新手最容易踩的坑
  • 一定要带 Trace ID所有日志一定要带 Trace ID，能串起来。
  • 采样要配生产环境采样率不要 100%，不然数据量太大。
