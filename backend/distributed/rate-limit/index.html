限流算法

算法原理优缺点
固定窗口每个窗口计数简单，临界点可能突刺
滑动窗口滑动窗口计数平滑，实现稍复杂
漏桶固定速率流出平滑，无法应对突发
令牌桶固定速率放令牌允许突发，最常用
 
// 令牌桶限流伪代码
class RateLimiter {
  constructor(rate, capacity) {
    this.rate = rate        // 每秒放多少令牌
    this.capacity = capacity // 桶容量
    this.tokens = capacity
    this.lastTime = Date.now()
  }
  
  tryAcquire() {
    // 补充令牌
    const now = Date.now()
    this.tokens = Math.min(
      this.capacity,
      this.tokens + (now - this.lastTime) / 1000 * this.rate
    )
    this.lastTime = now
    
    if (this.tokens >= 1) {
      this.tokens--
      return true
    }
    return false
  }
}
