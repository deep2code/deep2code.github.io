限流实战：从你遇到的问题出发

🏷️ 限流

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及限流怎么帮你解决。

flowchart TB A[请求进来] --> B{限流判断} B -->|通过| C[处理请求] B -->|拒绝| D[返回 429]

1. 突然流量打挂

你遇到的问题

活动突然来一波流量，接口直接被打挂。

怎么解决？加限流，超过阈值的请求直接拒绝，保护后端。

2. 限流算法选哪个

你遇到的问题

常用限流算法有哪些？

怎么解决？计数器、漏桶、令牌桶。

3. 单机限流不够

你遇到的问题

多实例部署，单机限流不准怎么办？

怎么解决？用 Redis + Lua 做分布式限流。

算法对比

算法特点适合
固定窗口简单低要求
滑动窗口平滑一般场景
漏桶匀速保护下游
令牌桶允许突发大多数场景
新手最容易踩的坑
  • 限流要友好被限流了返回 429 + 提示，不要直接 500。
  • 关键接口才限流不是所有接口都要限流，核心接口限流就行。
