幂等性与重试

为什么需要幂等

网络不可靠，请求可能超时。客户端重试就会重复调用。后端必须保证幂等：同一个请求执行一次和执行多次效果一样。

操作天然幂等？说明
GET 查询✅不修改数据
PUT 更新✅全量覆盖
DELETE 删除✅删多次结果一样
POST 创建❌每次创建新的

幂等实现方案

方案实现适用场景
唯一索引数据库加唯一约束创建操作
幂等键客户端传唯一 ID所有写操作
状态机状态流转约束订单状态
乐观锁版本号更新操作

重试策略

// 指数退避重试
async function retry(fn, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn()
    } catch (e) {
      if (i === maxRetries - 1) throw e
      // 指数退避：1s, 2s, 4s
      await sleep(Math.pow(2, i) * 1000)
    }
  }
}
注意：重试只对幂等操作做。非幂等操作重试前要先确认幂等。
