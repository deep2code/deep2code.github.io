分布式入门：从你遇到的问题出发

🏷️ 分布式

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及分布式怎么帮你解决。

flowchart TB A[分布式系统] --> B[CAP 定理] B --> C[分布式事务] C --> D[一致性] D --> E[高可用]

1. 为什么要分布式

你遇到的问题

一个服务器扛不住了，为什么要拆分布式？

怎么解决？单机性能到顶了，多台服务器一起扛，提高性能和可用性。

2. CAP 定理是什么

你遇到的问题

听说分布式有 CAP 定理，什么意思？

怎么解决？一致性、可用性、分区容忍性，三个最多满足两个。

3. 分布式难在哪

你遇到的问题

为什么说分布式系统很难？

怎么解决？网络不可靠、节点会挂、数据一致性难保证。

CAP 三个

说明
C 一致性所有节点数据同时一致
A 可用性每个请求都有响应
P 分区容忍网络分区了还能跑
新手最容易踩的坑
  • 小项目不要搞分布式小项目单机就够，分布式复杂度高很多。
  • 不要追求强一致大部分场景最终一致就够，强一致代价大。
