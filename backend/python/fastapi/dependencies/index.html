依赖注入与中间件

依赖注入是 FastAPI 的灵魂

很多人用 FastAPI 只知道路由，不知道依赖注入才是它的核心。数据库连接、认证、权限、分页参数，全部可以用依赖注入解决。

from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

# 依赖：获取当前用户
async def get_current_user(token: str = Depends(oauth2_scheme)):
    user = decode_token(token)
    if not user:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="无效的认证凭证"
        )
    return user

# 依赖：数据库会话
async def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

# 路由中直接使用
@app.get("/me/")
async def read_me(
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db)
):
    return current_user

依赖的层级与复用

依赖可以嵌套。比如 get_current_user 依赖 oauth2_scheme，get_admin_user 又依赖 get_current_user 并检查权限。

依赖类型使用场景作用范围
路径操作依赖单个接口的鉴权函数级
路由器依赖一组接口共用鉴权Router 级
全局依赖所有接口都需要的中间件应用级

中间件

@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    duration = time.time() - start
    response.headers["X-Process-Time"] = str(duration)
    return response

中间件和依赖的区别：中间件是请求级的，依赖是声明式的、可注入参数的。能用依赖就用依赖，更灵活。
