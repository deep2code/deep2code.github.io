FastAPI 入门

为什么选 FastAPI

2026 年做 Python API，FastAPI 几乎是默认选择。Django 太重，Flask 太裸，FastAPI 刚好卡在中间：有类型提示、自动文档、原生异步，性能接近 Node.js。

框架性能类型安全异步适用场景
FastAPI极高原生支持原生支持API 服务、微服务
Django中等弱部分全栈应用、后台管理
Flask中等无手动轻量服务、原型
Tornado高无原生长连接、WebSocket

第一个 FastAPI 应用

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="用户服务")

class User(BaseModel):
    name: str
    email: str
    age: int | None = None

@app.get("/users/{user_id}")
async def get_user(user_id: int):
    return {"id": user_id, "name": "张三"}

@app.post("/users/")
async def create_user(user: User):
    return {"id": 1, **user.dict()}

启动后自动生成 /docs Swagger UI 和 /redoc 文档，不用手写任何文档。

核心特性

  • 类型提示驱动：参数校验、序列化、文档全部自动生成
  • 原生异步：基于 Starlette，async/await 一等公民
  • 依赖注入：内置 DI 系统，数据库连接、认证都能注入
  • 自动文档：OpenAPI 3.0 规范，Swagger UI 开箱即用
