生产部署与最佳实践

生产部署方案

# 1. 用 Gunicorn 管理 Uvicorn worker
pip install gunicorn uvicorn[standard]

gunicorn app:app \
  -w 4 \
  -k uvicorn.workers.UvicornWorker \
  -b 0.0.0.0:8000 \
  --timeout 120 \
  --access-logfile -
配置推荐值说明
worker 数2*CPU+1不要超过 CPU 核心数太多
worker 类UvicornWorker异步 worker
超时120s长接口要调大

Docker 部署

FROM python:3.12-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["gunicorn", "app:app", "-w", "4", "-k", "uvicorn.workers.UvicornWorker", "-b", "0.0.0.0:8000"]

配置管理

from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    database_url: str
    redis_url: str
    secret_key: str
    debug: bool = False
    
    class Config:
        env_file = ".env"

settings = Settings()
