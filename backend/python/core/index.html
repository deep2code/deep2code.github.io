Python 实战：从你遇到的问题出发

🏷️ Python 入门

你想写个脚本自动整理文件夹，把下载文件夹里的图片、文档、安装包自动分类到不同文件夹。不知道从哪开始？

或者：你从前端转后端，不知道 Python 有哪些常用的东西要学，看了一堆教程还是不知道怎么写项目。

这些问题，这篇文章都能帮你。这篇不讲理论，就讲你真的会用到的 Python 知识，以及常见的坑。

场景一：下载文件夹乱成一团，想自动整理

你遇到的问题

你的下载文件夹里有几百个文件，图片、文档、安装包混在一起，找个文件要翻半天。你想：能不能写个脚本，自动把图片放到图片文件夹，文档放到文档文件夹？

Python 怎么解决？用 os 和 shutil 模块，几行代码就搞定。

import os
import shutil

# 下载文件夹路径
download_dir = '/Users/xxx/Downloads'

# 不同类型的文件放不同文件夹
file_types = {
    '图片': ['.jpg', '.png', '.gif', '.webp'],
    '文档': ['.pdf', '.doc', '.docx', '.txt', '.md'],
    '安装包': ['.dmg', '.exe', '.pkg'],
}

# 遍历所有文件
for filename in os.listdir(download_dir):
    file_path = os.path.join(download_dir, filename)
    
    # 跳过文件夹
    if os.path.isdir(file_path):
        continue
    
    # 获取文件后缀
    ext = os.path.splitext(filename)[1].lower()
    
    # 分类
    for folder, extensions in file_types.items():
        if ext in extensions:
            target_dir = os.path.join(download_dir, folder)
            # 目标文件夹不存在就创建
            os.makedirs(target_dir, exist_ok=True)
            # 移动文件
            shutil.move(file_path, os.path.join(target_dir, filename))
            print(f'移动 {filename} 到 {folder}')
            break

现在跑一下这个脚本，你的下载文件夹瞬间就整整齐齐了。以后每次下载完跑一下就行。

场景二：几百张图片要批量重命名

你遇到的问题

你拍了 100 张照片，名字都是 IMG_20240101_001.jpg、IMG_20240101_002.jpg... 你想改成"旅行照片_001.jpg"、"旅行照片_002.jpg"，一个个手动改要改到死。

Python 怎么解决？用 os.rename 循环改就行。

import os

photo_dir = '/Users/xxx/Pictures/旅行照片'

for i, filename in enumerate(os.listdir(photo_dir), start=1):
    old_path = os.path.join(photo_dir, filename)
    
    # 跳过文件夹
    if os.path.isdir(old_path):
        continue
    
    # 新名字
    ext = os.path.splitext(filename)[1]
    new_name = f'旅行照片_{i:03d}{ext}'
    new_path = os.path.join(photo_dir, new_name)
    
    os.rename(old_path, new_path)
    print(f'{filename} → {new_name}')

现在 100 张图片一秒钟就改完了。

场景三：想爬取网页上的信息，不用手动复制粘贴

你遇到的问题

你想把某个网站上的 100 篇文章标题都爬下来，手动复制要复制一天。你想写个脚本自动爬。

Python 怎么解决？用 requests 和 BeautifulSoup。

import requests
from bs4 import BeautifulSoup

# 请求网页
url = 'https://example.com/articles'
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')

# 找到所有文章标题
titles = soup.find_all('h2', class_='article-title')

# 打印出来
for title in titles:
    print(title.text.strip())
常用标准库什么时候用
os操作文件、文件夹
shutil复制、移动文件
json处理 JSON 数据
datetime处理时间、日期
re正则表达式，处理字符串
requests请求网页、调接口
新手最容易踩的坑
  • 缩进一定要对齐：Python 是靠缩进区分代码块的，缩进错了直接报错。
  • 不要用中文变量名：虽然 Python 3 支持，但团队协作的时候会出各种问题。
  • 路径要用绝对路径或者 os.path.join：不要硬编码 / 和 \，跨平台会出问题。
  • 虚拟环境一定要用：不要直接用系统 Python，依赖装多了迟早乱掉。
