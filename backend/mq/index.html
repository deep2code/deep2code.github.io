消息队列入门：从你遇到的问题出发

🏷️ MQ

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及MQ怎么帮你解决。

flowchart TB A[生产者] --> B[MQ] B --> C[消费者] C --> D[异步处理]

1. 同步调用太慢

你遇到的问题

下单要扣库存、加积分、发通知，同步做用户要等 3 秒。

怎么解决？用 MQ，下单后发消息，后续步骤异步做，用户秒返回。

2. MQ 是什么

你遇到的问题

消息队列是什么？

怎么解决？在进程间传消息的中间件，解耦、异步、削峰。

3. 常用 MQ

你遇到的问题

常用 MQ 有哪些？

怎么解决？Kafka、RabbitMQ、RocketMQ。

常用 MQ

MQ特点
Kafka高吞吐，日志/大数据
RabbitMQ功能全，路由灵活
RocketMQ阿里开源，事务消息
新手最容易踩的坑
  • 不要乱用 MQ简单同步调用不要上 MQ，增加复杂度。
  • 消息要幂等消费者一定要做幂等，重复消费不会出问题。
