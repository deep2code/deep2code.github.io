API 接口优化：从你遇到的问题出发

🏷️ API 优化

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及API 优化怎么帮你解决。

flowchart TB A[接口慢] --> B[查 SQL] B --> C[加缓存] C --> D[异步] D --> E[批量]

1. 接口响应太慢

你遇到的问题

一个查询接口响应要 2 秒，用户等不及。

怎么解决？做 API 性能优化：优化 SQL、加缓存、异步处理、批量查询。

2. 慢在哪

你遇到的问题

怎么找接口慢在哪？

怎么解决？看慢查询日志，看每一步耗时，先定位再优化。

3. 常用优化手段

你遇到的问题

常用 API 优化手段有哪些？

怎么解决？加缓存、SQL 优化、减少 DB 查询、异步、批量合并。

优化手段

手段说明
缓存热点数据放 Redis
SQL 优化加索引、避免慢查询
异步非实时操作异步做
批量多次请求合并成一次
新手最容易踩的坑
  • 先定位再优化不要上来就优化，先看慢在哪。
  • 加缓存注意一致性加缓存要考虑数据更新后缓存失效。
