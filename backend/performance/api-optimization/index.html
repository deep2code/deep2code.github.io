接口性能优化

接口慢了怎么排查

步骤方法工具
1. 定位瓶颈看耗时分布pprof / 火焰图
2. 查 SQL慢查询日志EXPLAIN / 慢日志
3. 查缓存缓存命中率Redis info
4. 查依赖下游服务耗时链路追踪

常见优化手段

手段效果适用场景
加缓存减少 DB 查询读多写少
异步化接口快速返回非关键流程
批量操作减少 RTT批量查询/插入
连接池减少建连开销DB / RPC
压缩减少传输量大响应体

性能指标

  • 延迟：P50 / P95 / P99（不是平均值）
  • 吞吐量：QPS / TPS
  • 并发数：同时处理的请求数
  • 错误率：失败请求占比
原则：先测量，再优化。不要凭感觉优化，先找到真正的瓶颈在哪。
