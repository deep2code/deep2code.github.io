gRPC 实战：从你遇到的问题出发

🏷️ gRPC

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及gRPC怎么帮你解决。

flowchart TB A[.proto 文件] --> B[生成代码] B --> C[服务端] B --> D[客户端] C --> E[HTTP/2 调用]

1. 微服务调用太慢

你遇到的问题

微服务之间用 JSON HTTP 调用，太慢，占带宽。

怎么解决？用 gRPC，基于 HTTP/2 + Protobuf，二进制传输，快很多。

2. gRPC 是什么

你遇到的问题

gRPC 是什么？

怎么解决？Google 开源的 RPC 框架，用 Protobuf 定义接口，跨语言调用。

3. 什么时候用

你遇到的问题

什么时候该用 gRPC？

怎么解决？微服务之间内部调用要高性能时用。对外 API 还是用 REST。

对比

对比REST HTTPgRPC
协议HTTP/1.1HTTP/2
数据格式JSON（文本）Protobuf（二进制）
性能一般高
新手最容易踩的坑
  • 内部调用用 gRPC微服务内部调用用 gRPC，快很多。
  • 对外 API 不用对外给前端的 API 还是用 REST/JSON，gRPC 浏览器支持不好。
