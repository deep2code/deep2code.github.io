创建型模式

单例模式

全局只有一个实例。比如配置管理器、连接池。

var (
    instance *Config
    once     sync.Once
)

func GetConfig() *Config {
    once.Do(func() {
        instance = &Config{...}
    })
    return instance
}

工厂模式

创建对象不直接 new，用工厂来创建。方便扩展。

class PaymentFactory {
    static create(type) {
        switch(type) {
            case 'alipay': return new Alipay()
            case 'wechat': return new WechatPay()
            default: throw new Error('unknown type')
        }
    }
}

const pay = PaymentFactory.create('alipay')

建造者模式

一步步构建复杂对象。比如 SQL 查询构建器。

const query = new QueryBuilder()
    .table('users')
    .where('age', '>', 18)
    .orderBy('name', 'asc')
    .limit(10)
    .build()

什么时候用

模式适用场景
单例全局唯一资源
工厂多种实现，运行时选
建造者复杂对象，多步构建
