结构型模式

💡 你想搞懂这个技术到底是干嘛的，什么时候该用它，什么时候不该用。不想上来就背一堆概念。

适配器模式

把不兼容的接口转成兼容的。比如对接第三方 API。

// 第三方接口
class ThirdPartyAPI {
    fetchUser(id) { ... }
}

// 适配器
class UserAdapter {
    constructor() {
        this.api = new ThirdPartyAPI()
    }
    
    getUser(id) {
        const data = this.api.fetchUser(id)
        return {
            id: data.userId,
            name: data.userName
        }
    }
}

装饰器模式

不修改原代码，动态加功能。比如日志、缓存、限流。

def log_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        result = func(*args, **kwargs)
        print(f"返回 {result}")
        return result
    return wrapper

@log_decorator
def get_user(id):
    return User.get(id)

代理模式

控制对象访问。比如 RPC 代理、虚拟代理。

外观模式

封装复杂子系统，提供简单接口。比如一键部署。
