Kafka 性能优化：从你遇到的问题出发

🏷️ Kafka 性能优化

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Kafka 性能优化怎么帮你解决。

flowchart TB A[Kafka 优化] --> B[Producer] B --> C[Broker] C --> D[Consumer]

1. 消息发送太慢

你遇到的问题

Kafka 发消息吞吐量上不去。

怎么解决？从 Producer、Broker、Consumer 三个方向优化。

2. Producer 怎么优化

你遇到的问题

Producer 怎么调优？

怎么解决？批量发送、压缩、异步发送、提高 batch.size。

3. Consumer 太慢

你遇到的问题

消费太慢跟不上生产速度。

怎么解决？增加分区数、提高并发、批量拉取。

优化要点

位置优化项说明
Producer批量发送攒一批再发，减少网络请求
Producer压缩压缩消息体，减少网络传输
Broker分区数分区越多并行度越高
Consumer并发多线程消费，提高速度
新手最容易踩的坑
  • 不要盲目加分区分区太多也会增加开销，一般按吞吐量估算。
  • 先测再优化用压测工具测一下，看瓶颈在哪再优化。
