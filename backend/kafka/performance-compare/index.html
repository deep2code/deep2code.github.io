Kafka 性能：从你遇到的问题出发

🏷️ Kafka 性能

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Kafka 性能怎么帮你解决。

flowchart TB A[Kafka 快] --> B[顺序写磁盘] B --> C[零拷贝] C --> D[批量处理]

1. 为什么 Kafka 这么快

你遇到的问题

为什么 Kafka 吞吐量比其他 MQ 高很多？

怎么解决？顺序写磁盘、零拷贝、批量处理，这三个是核心。

2. 怎么调优 Kafka

你遇到的问题

Kafka 性能怎么调优？

怎么解决？批量发送、压缩、加分区。

3. 消息丢了怎么办

你遇到的问题

怎么保证 Kafka 不丢消息？

怎么解决？生产者 ack=all，副本数 >= 2，手动提交 offset。

Kafka 快的原因

原因说明
顺序写磁盘比随机写快很多
零拷贝减少数据拷贝
批量处理批量发送消费
新手最容易踩的坑
  • 不要一条一条发批量发送性能好很多。
  • ack=all生产要配 ack=all，确保不丢消息。
