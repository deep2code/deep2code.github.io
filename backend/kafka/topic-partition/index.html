Kafka 分区入门：从你遇到的问题出发

🏷️ Kafka 分区

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Kafka 分区怎么帮你解决。

flowchart TB A[Topic] --> B[Partition 0] A --> C[Partition 1] A --> D[Partition 2]

1. Kafka 怎么并行

你遇到的问题

Kafka 怎么提高吞吐量？

怎么解决？加 Partition，分区越多，并行度越高，消费越快。

2. Partition 是什么

你遇到的问题

Kafka Partition 是什么？

怎么解决？Topic 分区分成多个 Partition，并行处理，提高吞吐。

3. 分区数怎么定

你遇到的问题

分区数设多少合适？

怎么解决？根据消费者数量定，一般分区数 >= 消费者数，不要太多。

要点

要点说明
分区并行多分区并行消费
顺序同一个 Partition 内有序
副本每个分区有副本，防丢
新手最容易踩的坑
  • 分区不要太多分区数太多会增加开销，够用就行。
  • Key 决定分区带 Key 的消息，同一个 Key 会到同一个分区。
