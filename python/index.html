安装与虚拟环境

# 源码编译安装（官网 python.org 下载源码包解压后）
# --enable-optimizations 会启用 PGO 等优化，编译时间更长但运行时更快
./configure --enable-optimizations
make -j$(nproc)
sudo make altinstall  # 用 altinstall 而非 install：不会覆盖系统自带 python，避免搞坏依赖旧版本的系统工具

# 虚拟环境：解决不同项目依赖版本冲突
python3 -m venv tutorial-env

# Windows 激活虚拟环境
tutorial-env\Scripts\activate.bat

# macOS/Linux 激活虚拟环境
source tutorial-env/bin/activate

# 2026 年更推荐直接用 uv 管理虚拟环境（见下文工具链）

安装 pip

# 查看 pip 是否安装，现在一般都已自带（brew、官方安装包均包含）
python3 -m pip --version

# 手动安装（一般不用）
python3 -m ensurepip --default-pip

# 升级 pip
python3 -m pip install --upgrade pip

# 查看某个包的依赖关系（Requires / Required-by）
pip show pkg_name

# 查看包的依赖树（需要 pipdeptree 包）
pip install pipdeptree
pipdeptree -p pkg_name

# 永久切换国内清华源
pip3 config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 换回默认官方源
pip3 config unset global.index-url

# 临时指定源安装（也可用阿里云：https://mirrors.aliyun.com/pypi/simple）
pip3 install django -i https://pypi.tuna.tsinghua.edu.cn/simple

WSGI 与 ASGI

graph LR subgraph WSGI 同步 C1[客户端] --> W1[WSGI Server
gunicorn] W1 --> A1[WSGI App
Django/Flask] A1 --> W1 W1 --> C1 end subgraph ASGI 异步 C2[客户端] --> W2[ASGI Server
uvicorn] W2 --> A2[ASGI App
FastAPI] A2 -->|async| W2 W2 --> C2 end

WSGI/ASGI 是 Python Web 应用（应用层）与 Web 服务器（协议层）之间的接口契约：服务器解析请求、构造环境信息，调用应用对象；应用处理完返回响应给服务器写回客户端。

  • WSGI ——同步 Web 应用接口

    • python-web-app 实现 WSGI 接口，作为请求 handler
    • python-web-server（如 gunicorn）解析请求、整理环境信息
    • 服务器加载 app 并调用其 WSGI 接口处理请求，app 返回结果
    • 服务器写回响应给用户
def application(environ, start_response):
    start_response('200 OK', [('Content-Type', 'text/plain')])
    return [b'Greetings universe']

  • ASGI ——异步 Web 应用接口

    • 在 WSGI 基础上支持 asyncio 机制
    • 解决 WSGI 难以支持 WebSocket 等长连接的问题
    • 执行流程与 WSGI 类似，由事件循环驱动
async def application(scope, receive, send):
    event = await receive()
    ...
    await send({"type": "websocket.send", ...})

2026 年：FastAPI + uvicorn 是 ASGI 最主流组合；httpx 成为 async HTTP 客户端首选。

Wheel（轮子）

wheel 是 Python 新的发行标准，替代传统 egg。wheel 是一个 zip 压缩文件（把 .whl 后缀换成 .zip 即可解压查看）。优点：

  • 纯 Python 与 C 扩展包安装更快（无需现场编译）
  • 避免安装时执行任意代码（不跑 setup.py）
  • C 扩展安装不需要目标机器有编译工具链
  • 更好的缓存，利于 CI/CD 复用
  • 安装时生成与解释器匹配的 .pyc，跨平台更一致
# 制作 wheel 安装包
python setup.py bdist_wheel
# 或
pip wheel --wheel-dir=/root/whl ./

类型注解（Type Hints）

  • Python 3.5（PEP 484）引入函数类型注解；3.6（PEP 526）引入变量注解。
  • 语法：变量后加 : 类型；函数返回值用 -> 类型。
  • PEP 8 格式：冒号后跟一个空格；箭头左右各留一个空格。
  • 注解本质是元数据，运行时不影响逻辑（可用 typing.get_type_hints 读取）。
  • 2026 重要演进 ：Python 3.14 起 PEP 649 使注解默认惰性求值，不再在定义时立即计算注解表达式——大幅减少启动开销并消除循环导入问题（旧写法需 from __future__ import annotations）。

Python 2026 现状与版本选型

Python 3.14（2025 年 10 月发布）

  • 自由线程（free-threaded）转正 ：PEP 703 / PEP 779，3.14 起官方支持无 GIL 构建（需显式安装 free-threaded 版本或 --disable-gil 编译），多线程可真正利用多核；默认发行版仍保留 GIL。
  • 注解惰性求值（PEP 649） ：注解默认不在定义时求值，启动更快、循环导入问题缓解。
  • 增量垃圾回收 ：长请求/长连接服务 GC 停顿从几十毫秒级降为多次小步进。
  • JIT 持续改进 ：3.13 引入的 copy-and-patch JIT 在 3.14 进一步稳定。

Python 3.13（2024 年 10 月发布）

  • 实验性 JIT ：基于 copy-and-patch，热点函数动态编译。
  • 自由线程构建（PEP 703） ：no-GIL 实验模式。
  • 改进的交互式 REPL ：多行编辑、语法高亮、历史浏览。
  • typing 增强 ：TypeVar 默认值、ReadOnly、typing.TypeIs 等。

Python 3.12（2023 年 10 月发布）

  • @override 装饰器 ：显式标记方法重写，类型检查器验证父类方法存在。 
    from typing import override

class Base:
    def process(self, data: str) -> None: ...

class Derived(Base):
    @override
    def process(self, data: str) -> None:
        ...
  • TypeVar 默认值 ：T = TypeVar("T", default=str)
  • tomllib ：标准库内置 TOML 解析。 
    import tomllib
with open("config.toml", "rb") as f:
    config = tomllib.load(f)
  • pathlib 增强 ：Path.walk() 等。
  • f-string 改进 ：支持嵌套引号、多行表达式、反斜杠。
  • asyncio.TaskGroup ：结构化并发。 
    import asyncio

async def main():
    async with asyncio.TaskGroup() as tg:
        task1 = tg.create_task(fetch("url1"))
        task2 = tg.create_task(fetch("url2"))
    print(task1.result(), task2.result())
