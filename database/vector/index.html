向量数据库：从你遇到的问题出发

🏷️ 向量数据库

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及向量数据库怎么帮你解决。

flowchart LR A[文本/图片] --> B[Embedding 模型] B --> C[向量] C --> D[向量数据库] D --> E[相似度搜索]

1. 语义搜索怎么做

你遇到的问题

用户搜"怎么改密码"，要能匹配到"修改登录密码"，不是只匹配关键词。

怎么解决？把文本转成向量，向量距离近的就是语义相似的。

2. RAG 知识库怎么实现

你遇到的问题

你有一堆文档，想让 AI 基于你的文档回答问题。

怎么解决？把文档切成块存向量库，用户提问时搜相关块，喂给 LLM。

3. 用什么向量数据库

你遇到的问题

听说有 Pinecone、Milvus、pgvector，选哪个？

怎么解决？小项目用 pgvector（PostgreSQL 插件），大项目用 Milvus。

向量数据库对比

数据库特点适合
pgvectorPG 插件小项目、已有 PG
Milvus开源、功能强中大型项目
Pinecone云服务不想自己运维
新手最容易踩的坑
  • 先从 pgvector 开始不要上来就部署 Milvus，pgvector 足够小项目用了。
  • 向量维度要注意维度越高越占空间，用 1536 维就够了，不要盲目加高。
