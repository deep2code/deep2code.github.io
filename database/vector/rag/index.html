RAG 入门：从你遇到的问题出发

🏷️ RAG

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及RAG怎么帮你解决。

flowchart TB A[文档] --> B[切块向量化] B --> C[存入向量库] C --> D[用户提问] D --> E[检索相关片段] E --> F[LLM 生成回答]

1. 大模型不知道私有数据

你遇到的问题

大模型不知道公司内部文档，问它答不上来。

怎么解决？用 RAG，把私有文档向量化存起来，提问时检索相关内容喂给大模型。

2. RAG 是什么

你遇到的问题

RAG 是什么？

怎么解决？Retrieval-Augmented Generation，检索增强生成，先检索相关内容，再让 LLM 基于内容回答。

3. 怎么做

你遇到的问题

怎么做 RAG？

怎么解决？文档切块 → 向量化 → 存向量库 → 提问时检索 → 拼 Prompt → LLM 生成。

流程

步骤说明
1. 切块把文档切成小块
2. 向量化用 Embedding 模型转成向量
3. 检索按相似度找相关块
4. 生成LLM 基于检索内容回答
新手最容易踩的坑
  • 切块大小要合适切块太大太啰嗦，太小上下文不够，一般 500-1000 字一块。
  • Embedding 模型要选好Embedding 模型效果决定检索质量。
