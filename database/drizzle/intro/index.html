Drizzle ORM 入门

Drizzle 是什么

Drizzle 是一个轻量级 TypeScript ORM，特点是贴近原生 SQL，不做"魔法"。你写的查询长什么样，生成的 SQL 就长什么样。

特性PrismaDrizzle ORM
类型安全✅✅
SQL 透明度低（黑盒）高（所见即所得）
包大小大极小（几 KB）
学习成本中低（会 SQL 就会）
Edge 支持差原生支持
Migrationprisma migratedrizzle-kit

第一个 Drizzle 项目

npm i drizzle-orm
npm i -D drizzle-kit

# 初始化
npx drizzle-kit init
// db/schema.ts
import { pgTable, serial, text, integer } from 'drizzle-orm/pg-core'

export const users = pgTable('users', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  email: text('email').notNull().unique(),
  age: integer('age'),
})

// db/index.ts
import { drizzle } from 'drizzle-orm/postgres-js'
import postgres from 'postgres'

const client = postgres('postgresql://user:pass@localhost:5432/db')
export const db = drizzle(client, { schema: { users } })
