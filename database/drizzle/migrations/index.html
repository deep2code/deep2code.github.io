Migration 与生产部署

Migration 工具

Drizzle 用 drizzle-kit 做迁移，类似 Prisma Migrate 但更轻量。

# 生成迁移（schema 变更后）
npx drizzle-kit generate

# 应用迁移
npx drizzle-kit migrate

# 打开 Studio 管理数据
npx drizzle-kit studio

工作流

# 1. 修改 schema.ts
# 2. 生成迁移文件
npx drizzle-kit generate

# 3. 检查生成的 SQL
ls drizzle/

# 4. 应用到开发库
npx drizzle-kit migrate

# 5. 提交迁移文件到 Git
git add drizzle/
git commit -m "add users table"

# 6. CI/CD 自动应用迁移

生产最佳实践

  • 迁移文件提交 Git：团队成员和 CI 都用同一套迁移
  • 生产迁移先备份：大改动先备份数据库
  • 避免破坏性变更：删列、改类型要分步做
  • 连接池：生产环境用连接池，不要每个请求新建连接

为什么选 Drizzle

场景推荐
追求类型安全 + SQL 透明✅ Drizzle
Edge 部署✅ Drizzle（轻量）
团队都是 SQL 高手✅ Drizzle
想要更"高级"的抽象选 Prisma
