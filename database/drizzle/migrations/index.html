Drizzle 迁移：从你遇到的问题出发

🏷️ Drizzle 迁移

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Drizzle 迁移怎么帮你解决。

flowchart LR A[改表结构] --> B[drizzle-kit generate] B --> C[生成迁移文件] C --> D[migrate 执行]

1. 改了表结构怎么同步

你遇到的问题

改了 Drizzle 的 schema，数据库表怎么同步？

怎么解决？用 drizzle-kit generate 生成迁移文件，再执行迁移。

2. 怎么生成迁移

你遇到的问题

drizzle-kit 怎么用？

怎么解决？npm 装 drizzle-kit，配置好，跑 generate 生成 SQL。

3. 怎么回滚

你遇到的问题

迁移出问题了怎么回滚？

怎么解决？drizzle-kit 也支持回滚迁移。

常用命令

命令用途
generate生成迁移
migrate执行迁移
push直接推到数据库（开发用）
新手最容易踩的坑
  • 生产用迁移生产环境不要用 push，用生成的迁移文件。
  • 迁移文件提交 Git迁移文件要提交 Git，团队共享。
