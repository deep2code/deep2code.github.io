数据库：从你遇到的问题出发

🏷️ 数据库总览

你做项目要存数据，不知道该用哪个数据库：业务数据用 MySQL？热点数据用 Redis？搜索用 ES？统计分析用 ClickHouse？

这篇不讲理论，就按你遇到的真实问题，给你列出来每个数据库是解决什么问题的，你按需选就行。

🗄️ 业务数据存哪里？

用户数据、订单数据，要事务、要增删改查，用关系型数据库。

怎么选数据库？看这张表

你的场景选什么数据库
存用户、订单、交易数据，要事务MySQL / PostgreSQL
热点数据、缓存、排行榜、限流Redis
全文搜索、商品筛选Elasticsearch
大数据量统计分析、日志报表ClickHouse
JSON 结构灵活、内容类数据MongoDB
新手避坑
  • 不要一上来就用一堆数据库：小项目一个 MySQL 就够了，不要为了用而用 Redis、ES 这些。
  • 业务数据还是要存 MySQL：Redis、ES 都是缓存和辅助，重要数据一定要持久化到 MySQL。
  • 不要把 Redis 当数据库：Redis 是内存数据库，断电就没了，不能存重要业务数据。
