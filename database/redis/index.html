Redis 实战：从你遇到的问题出发

🏷️ Redis

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Redis怎么帮你解决。

flowchart TB A[Redis] --> B[缓存] B --> C[分布式锁] C --> D[排行榜] D --> E[计数器]

1. 数据库扛不住了

你遇到的问题

查询直接打 MySQL，QPS 高了数据库扛不住。

怎么解决？前面架 Redis 当缓存，查询快十倍。

2. Redis 能干什么

你遇到的问题

Redis 不只是缓存，还能干什么？

怎么解决？缓存、分布式锁、排行榜、计数器、消息队列。

3. 常用数据结构

你遇到的问题

Redis 常用数据结构有哪些？

怎么解决？String、Hash、List、Set、ZSet，这五个最常用。

常用数据结构

结构用途
String缓存/计数器
Hash存对象
List队列/栈
Set去重/交集
ZSet排行榜
新手最容易踩的坑
  • 不要存大 keyRedis 单 key 不要超过 10KB，太大了影响性能。
  • 缓存要设过期缓存一定要设过期时间，不要永久存。
