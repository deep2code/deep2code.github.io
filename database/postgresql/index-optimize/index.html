PG 索引优化：从你遇到的问题出发

🏷️ PG 索引优化

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PG 索引优化怎么帮你解决。

flowchart TB A[查询慢] --> B[explain 看执行计划] B --> C{全表扫?} C -->|是| D[加索引] C -->|否| E[看索引效率]

1. 查询慢，不知道为什么

你遇到的问题

一条 SQL 跑 10 秒，不知道为什么慢。

怎么解决？用 explain analyze 看执行计划，找瓶颈。

2. 建了索引还是慢

你遇到的问题

明明建了索引，查询还是不走。

怎么解决？看是不是索引列类型不匹配，或者函数导致索引失效。

3. 索引建了一堆，写变慢

你遇到的问题

索引建了 10 个，insert update 变慢。

怎么解决？删掉没用的索引，只留查询真正用到的。

常用索引

索引场景
B-Tree等值、范围、排序
GIN全文搜索、数组
BRIN大表时间列
