PostgreSQL 主从同步：从你遇到的问题出发

🏷️ PostgreSQL 主从

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PostgreSQL 主从怎么帮你解决。

flowchart TB A[主库] --> B[写操作] A --> C[同步] C --> D[从库] D --> E[读操作]

1. 数据库读压力大

你遇到的问题

数据库读请求太多，主库扛不住。

怎么解决？做主从复制，主库写，从库读，分担压力。

2. 主从同步是什么

你遇到的问题

主从复制是什么？

怎么解决？主库把数据变更同步到从库，从库和主库数据一致。

3. 怎么搭

你遇到的问题

PostgreSQL 怎么搭主从？

怎么解决？主库配 wal_level，从库配 recovery.conf，连接主库。

模式

模式说明
流复制实时同步，常用
逻辑复制按表/数据同步
新手最容易踩的坑
  • 主从有延迟主从同步不是实时的，有延迟，强一致要求的读要走主库。
  • 从库不能写从库默认只能读，不能写。
