PostgreSQL 安装：从你遇到的问题出发

🏷️ PG 安装

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PG 安装怎么帮你解决。

flowchart LR A[安装 PG] --> B[Docker 方式] B --> C[apt 方式] C --> D[源码编译]

1. 怎么装 PostgreSQL

你遇到的问题

想本地装个 PostgreSQL 学习，怎么装？

怎么解决？最简单用 Docker 一条命令启动，不用装本地。

2. Docker 装 PG

你遇到的问题

用 Docker 怎么装 PG？

怎么解决？docker run 一条命令，指定端口和密码就行。

3. 怎么连接

你遇到的问题

装完怎么连接？

怎么解决？用 psql 命令行，或者 DBeaver 图形化工具连接。

安装方式

方式适合
Docker学习/测试（最推荐）
apt/yum生产服务器
源码编译需要自定义编译参数
新手最容易踩的坑
  • 新手用 Docker新手学习用 Docker 最方便，不用管依赖。
  • 记得改密码默认密码不安全，生产环境一定要改。
