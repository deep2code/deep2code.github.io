PostgreSQL 安装：从你遇到的问题出发

🏷️ PG 安装

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PG 安装怎么帮你解决。

flowchart LR A[安装 PG] --> B[启动服务] B --> C[创建用户/库] C --> D[连接测试]

1. 怎么装 PostgreSQL

你遇到的问题

想本地装个 PostgreSQL 学习，不知道怎么装。

怎么解决？Mac 用 brew install postgresql，Ubuntu 用 apt install postgresql。

2. 装完怎么连

你遇到的问题

装完了怎么连上去？

怎么解决？用 psql 命令行，或者用 DBeaver 可视化工具。

3. 默认密码是什么

你遇到的问题

装完不知道默认密码是什么。

怎么解决？默认 postgres 用户没有密码，本地连接不用密码。

常用命令

操作命令
启动服务brew services start postgresql
连接psql -U postgres
创建库CREATE DATABASE xxx;
新手最容易踩的坑
  • 新手用 Docker 装不想搞环境，docker run 一条命令最快。
  • 用可视化工具新手不要只用命令行，用 DBeaver 看数据方便。
