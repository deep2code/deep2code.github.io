PostgreSQL 入门：从你遇到的问题出发

🏷️ PostgreSQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PostgreSQL怎么帮你解决。

flowchart TB A[PostgreSQL] --> B[开源] B --> C[功能强大] C --> D[适合复杂查询]

1. MySQL 和 PG 选哪个

你遇到的问题

做项目选 MySQL 还是 PostgreSQL？

怎么解决？简单业务 MySQL 够，复杂查询、JSON、GIS 选 PG。

2. PG 有什么优势

你遇到的问题

PostgreSQL 比 MySQL 强在哪？

怎么解决？标准 SQL 支持好、复杂查询强、JSON 支持好、扩展丰富。

3. 新手怎么开始

你遇到的问题

想学习 PG，怎么开始？

怎么解决？装个 PostgreSQL，建个表，写几个查询试试。
