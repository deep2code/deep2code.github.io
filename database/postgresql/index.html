PostgreSQL 入门：从你遇到的问题出发

🏷️ PostgreSQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PostgreSQL怎么帮你解决。

flowchart TB A[PostgreSQL] --> B[关系型数据库] B --> C[复杂查询] B --> D[JSON 支持] B --> E[扩展丰富]

1. PostgreSQL 和 MySQL 选哪个

你遇到的问题

听说 PostgreSQL 很强大，和 MySQL 比哪个好？

怎么解决？互联网业务用 MySQL，复杂查询/地理/JSON/扩展用 PostgreSQL。

2. PG 有什么特色

你遇到的问题

PostgreSQL 比 MySQL 多什么？

怎么解决？支持复杂 SQL、窗口函数、JSONB、GIS 地理、扩展插件。

3. 新手怎么开始

你遇到的问题

想学习 PostgreSQL，不知道从哪下手。

怎么解决？装个 PG，用 psql 跑几个命令，跑通再说。

PG vs MySQL

对比PostgreSQLMySQL
复杂查询强中等
JSON 支持jsonb 很强一般
扩展丰富少
性能复杂查询快简单读写快
新手最容易踩的坑
  • 复杂业务选 PG需要复杂查询、JSON、GIS 的话选 PG。
  • 互联网传统业务选 MySQL大部分互联网项目 MySQL 生态更成熟。
