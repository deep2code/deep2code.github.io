PG 数据类型：从你遇到的问题出发

🏷️ PG 数据类型

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PG 数据类型怎么帮你解决。

flowchart TB A[PG 数据类型] --> B[数值] B --> C[字符串] C --> D[时间] D --> E[JSON]

1. 选什么类型

你遇到的问题

设计表不知道选什么数据类型。

怎么解决？常用的：int 整数、varchar 字符串、timestamp 时间、jsonb JSON。

2. varchar 和 text 区别

你遇到的问题

varchar 和 text 有什么区别？

怎么解决？PG 里没区别，text 更灵活，直接用 text 就行。

3. JSON 类型怎么选

你遇到的问题

json 和 jsonb 选哪个？

怎么解决？选 jsonb，支持索引，查询快。

常用类型

类型用途
int/bigint整数
varchar/text字符串
timestamp时间
jsonbJSON（推荐）
新手最容易踩的坑
  • 用 jsonb 不用 jsonjsonb 支持索引，性能好很多。
  • 时间用 timestamptz带时区的时间，避免时区问题。
