PostgreSQL 入门：从你遇到的问题出发

🏷️ PostgreSQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及PostgreSQL怎么帮你解决。

flowchart TB A[应用] --> B[PostgreSQL] B --> C[(稳定可靠)] B --> D[功能强大]

1. MySQL 和 PG 选哪个

你遇到的问题

都是关系型数据库，选哪个？

怎么解决？看需求，PG 功能强，MySQL 生态好，大部分场景都够用。

2. PG 有什么优势

你遇到的问题

为什么很多人推荐 PG？

怎么解决？开源、稳定、功能全，支持复杂查询、JSON、扩展。

3. 新手怎么开始学 PG

你遇到的问题

不知道从哪下手。

怎么解决？先装 PG，建库建表，写简单 SQL，和 MySQL 差不多。

PG 特点

特点说明
开源免费没有 Oracle 那种付费限制
功能全支持复杂 SQL、JSON、数组
稳定很多大厂生产用
新手最容易踩的坑
  • 新手先学基础先把 SQL 基础学会，再看高级特性。
  • 不要和 MySQL 比语法大部分语法差不多，个别不一样查文档就行。
