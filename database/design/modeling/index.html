数据库建模

三范式

范式要求说明
1NF字段原子性每个字段不可再分
2NF消除部分依赖非主键字段完全依赖主键
3NF消除传递依赖非主键字段不依赖其他非主键

什么时候反范式

实际业务中，为了性能，经常反范式：

  • 冗余字段：订单表存商品名称，不用每次关联查询
  • 汇总表：每天统计数据存一张表
  • 宽表：把关联字段都拼一起，查询快
原则：先按范式设计，遇到性能问题再反范式。不要一开始就过度设计。

表设计原则

  • 主键：用自增 ID 或雪花 ID，不要用业务字段做主键
  • 字段类型：能用 int 就不要用 bigint，能用 varchar(50) 就不要用 varchar(255)
  • 时间字段：创建时间、更新时间必备
  • 软删除：用 deleted 字段标记，不要真删
  • 预留字段：预留几个 ext 字段，方便扩展
