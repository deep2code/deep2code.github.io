索引设计原则

索引设计原则

原则说明
区分度高的列放左边性别这种低区分度列别放最左
常用查询字段加索引WHERE/ORDER BY/GROUP BY
覆盖索引查询字段都在索引里，不用回表
不要过度索引索引越多写入越慢

覆盖索引

-- 有联合索引 (name, age)
SELECT name, age FROM users WHERE name = '张三';
-- ✅ 覆盖索引，直接从索引拿数据，不用回表

索引下推（ICP）

MySQL 5.6 引入，在索引遍历过程中，先过滤掉不符合条件的记录，减少回表次数。

常见坑

  • 索引列做函数运算 → 索引失效
  • 隐式类型转换 → 索引失效
  • Like '%xxx' → 索引失效
  • OR 两边有一个没索引 → 索引失效
