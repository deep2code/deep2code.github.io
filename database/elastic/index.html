Elasticsearch 入门：从你遇到的问题出发

🏷️ Elasticsearch

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及Elasticsearch怎么帮你解决。

flowchart TB A[Elasticsearch] --> B[全文搜索] B --> C[日志分析] C --> D[数据分析]

1. 怎么实现全文搜索

你遇到的问题

网站要做搜索功能，MySQL like 查询太慢。

怎么解决？用 Elasticsearch，专门做全文搜索，快很多。

2. ES 是什么

你遇到的问题

Elasticsearch（ES）是什么？

怎么解决？分布式搜索分析引擎，全文搜索、日志分析、数据分析。

3. 和 MySQL 区别

你遇到的问题

ES 和 MySQL 区别？

怎么解决？MySQL 是事务数据库，ES 是搜索引擎，做搜索和日志分析。

ES 用途

用途说明
全文搜索网站搜索功能
日志分析日志存 ES 搜索
数据分析聚合分析数据
新手最容易踩的坑
  • 不要存事务数据ES 不是数据库，不要存订单交易数据。
  • 内存要够ES 很吃内存，至少给 4G 内存。
