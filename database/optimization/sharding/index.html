分库分表入门：从你遇到的问题出发

🏷️ 分库分表

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及分库分表怎么帮你解决。

flowchart TB A[单库单表] --> B[数据量太大] B --> C[垂直拆分] C --> D[水平拆分] D --> E[中间件]

1. 单表数据太大

你遇到的问题

一张表几亿行，查询越来越慢。

怎么解决？做分库分表，把数据拆到多个库多个表里。

2. 垂直 vs 水平

你遇到的问题

分库分表有哪几种？

怎么解决？垂直拆分（按业务拆库）、水平拆分（按数据拆表）。

3. 用什么中间件

你遇到的问题

分库分表要用什么中间件？

怎么解决？ShardingSphere、MyCat。

拆分方式

方式说明适合
垂直拆库按业务拆成多个库业务边界清晰
垂直拆表大表拆成多个小表字段太多
水平拆表按 ID 拆到多个表数据量太大
新手最容易踩的坑
  • 先不要急着分单表千万级数据还能扛，不要上来就分库分表。
  • 主键要处理分库分表后主键不能自增了，用雪花算法。
