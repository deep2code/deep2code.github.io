分库分表与读写分离

什么时候需要分库分表

指标阈值
单表数据量超过 1000 万行
单表大小超过 10GB
QPS超过 5000
写入延迟明显变慢
原则：能不分就不分，分了之后复杂度上一个量级。先优化索引、加缓存，真扛不住再分。

分片策略

策略方式优缺点
范围分片按 ID/时间范围简单，可能热点
哈希分片按 ID 哈希均匀，扩容麻烦
查表分片映射表灵活，多一层

读写分离

主库：写
  ↓ 主从复制
从库 1：读
从库 2：读
从库 3：读
  • 主库：处理写操作
  • 从库：处理读操作，多个从库分摊读压力
  • 复制延迟：主从同步有延迟，刚写的数据可能读不到
