CK 对比：从你遇到的问题出发

🏷️ CK 对比

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CK 对比怎么帮你解决。

flowchart TB A[OLAP 数据库] --> B[ClickHouse] B --> C[Druid] C --> D[Pinot]

1. 选哪个 OLAP 数据库

你遇到的问题

做大数据分析，选 ClickHouse 还是 Druid？

怎么解决？简单分析选 CK，运维简单、性能好；实时高并发选 Druid/Pinot。

2. CK 和 ES 区别

你遇到的问题

ClickHouse 和 Elasticsearch 都能做分析，选哪个？

怎么解决？分析聚合选 CK，全文搜索选 ES。

3. CK 和 Greenplum

你遇到的问题

CK 和 Greenplum 选哪个？

怎么解决？CK 查询快很多，现在新项目基本选 CK。
