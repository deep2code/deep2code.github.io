CK 表导入：从你遇到的问题出发

🏷️ CK 数据导入

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CK 数据导入怎么帮你解决。

flowchart LR A[CSV/数据] --> B[ClickHouse 导入] B --> C[批量插入] C --> D[秒级完成]

1. 怎么把数据导入 CK

你遇到的问题

有个 10G CSV 文件，怎么导入 ClickHouse？

怎么解决？用 clickhouse-client 批量导入，一条命令搞定。

2. 为什么不要一条一条插

你遇到的问题

为什么 CK 不能一条一条插数据？

怎么解决？CK 是列存批量写，一条一条插性能差很多。

3. 怎么从 MySQL 同步

你遇到的问题

怎么把 MySQL 数据同步到 CK？

怎么解决？用 DataX、Flink CDC 工具同步。

导入方式

方式说明
批量 INSERT最简单，适合小数据
clickhouse-local命令行导入
DataX/Flink大数据量同步
新手最容易踩的坑
  • 批量导入CK 一定要批量导入，不要一条一条插。
  • 先小批量试先拿一小部分数据试，没问题再全量导。
