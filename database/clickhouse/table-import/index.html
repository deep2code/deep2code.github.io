CK 数据导入导出：从你遇到的问题出发

🏷️ CK 导入

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及CK 导入怎么帮你解决。

flowchart LR A[CSV/JSON] --> B[ClickHouse] B --> C[快速导入] B --> D[导出文件]

1. 怎么把 CSV 导入 CK

你遇到的问题

你有一个 CSV 文件，想导入到 ClickHouse。

怎么解决？用 INSERT FROM INFILE 一条命令导入。

2. 怎么快速导入大量数据

你遇到的问题

几十万行数据怎么快速导入？

怎么解决？批量导入，用 INSERT 批量插，不要一条一条插。

3. 怎么把数据导出成文件

你遇到的问题

想把 CK 里的数据导成 CSV 文件。

怎么解决？用 SELECT INTO OUTFILE 导出。

常用命令

操作命令
导入 CSVINSERT INTO xxx FROM INFILE 'xxx.csv' FORMAT CSV
导出 CSVSELECT * FROM xxx INTO OUTFILE 'xxx.csv' FORMAT CSV
新手最容易踩的坑
  • 批量导入不要一条一条插，批量插快很多。
  • 注意格式导入前确认格式，CSV 还是 JSON，别搞错了。
