MySQL 入门：从你遇到的问题出发

🏷️ MySQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及MySQL怎么帮你解决。

flowchart TB A[MySQL] --> B[连接] B --> C[查询优化] C --> D[索引] D --> E[事务]

1. 查询太慢

你遇到的问题

一个 SQL 跑好几秒，接口超时。

怎么解决？先 explain 看执行计划，加索引优化。

2. 索引怎么加

你遇到的问题

索引怎么设计？

怎么解决？高频查询字段加索引，联合索引注意最左前缀。

3. 事务是什么

你遇到的问题

事务是什么？

怎么解决？ACID：原子性、一致性、隔离性、持久性。

核心概念

概念说明
索引加速查询的数据结构
事务一组操作要么全成功要么全失败
锁并发控制，防止数据不一致
MVCC多版本并发控制，读写不阻塞
新手最容易踩的坑
  • 不要 SELECT *只查需要的字段，减少数据传输。
  • 索引不是越多越好索引太多写会变慢，按需加。
