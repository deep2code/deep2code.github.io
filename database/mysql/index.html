MySQL：从你遇到的问题出发

🏷️ MySQL

这篇不讲理论，就讲你做项目时会遇到的真实问题，以及MySQL怎么帮你解决。

flowchart LR A[应用] --> B[MySQL] B --> C[(业务数据)] B --> D[事务保证一致性]

1. 业务数据存哪里

你遇到的问题

你要存用户、订单、交易数据，要保证数据不丢、一致。

怎么解决？MySQL 是最常用的关系型数据库，稳定可靠。

2. 要保证数据一致

你遇到的问题

转账要扣钱加钱一起成功，不能一个成功一个失败。

怎么解决？MySQL 事务保证 ACID，要么全成功要么全失败。

3. 查询越来越慢

你遇到的问题

数据量大了，查询越来越慢。

怎么解决？加索引、优化 SQL，分库分表。

新手最容易踩的坑
  • 一定要加索引查数据的 WHERE 条件要加索引，不然全表扫描很慢。
  • 不要 SELECT *只查需要的字段，减少网络传输。
