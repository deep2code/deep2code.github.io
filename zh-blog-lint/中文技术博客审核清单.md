# 中文技术博客审核清单

## 一、口语化检查

- [ ] 避免过于正式的书面语
- [ ] 用"我"分享经验，而不是"我们"或"笔者"
- [ ] 句子简短有力，不绕弯子
- [ ] 像和朋友聊天一样自然

## 二、数字表述

- [ ] 数字用阿拉伯数字，不用中文数字
- [ ] 版本号、性能数据准确
- [ ] 时间范围清晰
- [ ] 比例、数量有具体数字

## 三、术语规范

- [ ] 技术术语前后一致
- [ ] 英文术语用中文解释（首次出现时）
- [ ] 避免生造术语
- [ ] 专有名词大小写正确

## 四、绝对表述

- [ ] 避免"一定"、"必须"、"永远"、"绝对"
- [ ] 用"建议"、"通常"、"一般来说"
- [ ] 留有例外情况
- [ ] 避免过度承诺

## 五、被动语态

- [ ] 少用被动句
- [ ] 多用主动句
- [ ] 明确主语是谁
- [ ] 避免"被...所..."句式

## 六、黑话检查

- [ ] 避免行业黑话和缩写
- [ ] 缩写首次出现要解释
- [ ] 避免网络流行语
- [ ] 避免英文夹杂过多

## 七、结构检查

- [ ] 标题层级清晰
- [ ] 段落不长（不超过5行）
- [ ] 代码块有说明文字
- [ ] 有总结或踩坑提醒

## 八、AI 味检查

- [ ] 没有"首先、其次、最后"
- [ ] 没有"综上所述"、"值得注意的是"
- [ ] 没有"随着...的发展"
- [ ] 有真实经验和场景
- [ ] 有个人观点和判断
