工具推荐

编辑器

  • Typora：即时预览，跨平台
  • Obsidian：双链笔记，插件生态
  • VS Code：Markdown All in One 插件
  • Notion：块编辑器，可导出
  • Obsidian：本地优先，Markdown 存储

转换工具

  • Pandoc：文档格式转换
  • Markdeep：Markdown 转 HTML
  • MDX：Markdown + React
  • docsify：文档站点生成
  • Docusaurus：文档框架

预览工具

  • Markdown Preview Plus：VS Code 预览
  • Markdown Viewer：浏览器插件
  • Mume：VS Code Markdown 预览

最佳实践

风格指南

  • 标题层级连续，避免跳跃
  • 代码块标注语言
  • 链接使用描述性文字
  • 表格保持简洁
  • 图片使用相对路径或 CDN

可移植性

  • 避免依赖特定工具的扩展
  • 图片本地化或使用稳定 CDN
  • 使用标准语法
  • 重要内容不依赖图表
