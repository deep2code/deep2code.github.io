核心观点

  • 自托管（Self-Hosted）软件收集与对比：AI 编程插件、代码托管、文档等
  • 文末 2024-2026 更新持续补充新选手
  • 适合数据自控、逃不开私有化部署的场景

  • 选型顺序：先看维护活跃度与社区，再看功能完备度

域名解析

  1. 修改 hosts

    vim /etc/hosts

#配置mydomain.site的dns为本机
#如果域名有备案,可以跳过此步,直接增加域名的A记录
127.0.0.1 mydomain.site

  2. 申请域名证书

    现在基本都走 HTTPS。个人项目申请免费证书就行；生产环境建议用收费证书或带商业支持的服务。免费申请证书的途径：

    • freessl 网站
    • letsencrypt 网站
    • 阿里云 SSL 证书服务
    • 又拍云 SSL 证书服务
    • 七牛云免费 SSL 证书
    • 百度云 SSL 证书服务
    • 腾讯云 SSL 证书服务
    • 华为云 SSL 证书管理 SCM

配置Nginx

  1. 安装 nginx

    brew install nginx
# 如果遇到不能启动，尝试启动sudo brew services start nginx
brew services start nginx
    • nginx 源码安装，点这里
    • 其他方式安装，看这里

  2. 修改配置文件

...
server {
        listen       443 ssl;  # 新版 nginx 可用独立指令 http2 on; 启用 HTTP/2
        server_name  mydomain.site;

        #mydomain.site.pem/mydomain.site.key
        #就是申请域名证书后,网站提供的相关文件
        ssl_certificate      ssl/mydomain.site.pem;
        ssl_certificate_key  ssl/mydomain.site.key;

        ssl_session_cache    shared:SSL:1m;
        ssl_session_timeout  5m;

        ssl_ciphers  HIGH:!aNULL:!MD5;  # TLS 1.3 使用内置套件，此行为旧式写法
        ssl_prefer_server_ciphers  on;  # TLS 1.3 忽略此设置

        location / {
            #直接转发gogs目录
            proxy_pass http://xx.xx.xx.xx:3000;
        }
    }
...

配置gogs

  1. 安装 gogs

    wget https://dl.gogs.io/$VERSION/gogs_$VERSION_$OS_$ARCH.tar.gz
tar -zxvf gogs_$VERSION_$OS_$ARCH.tar.gz
cd gogs_$VERSION_$OS_$ARCH
    • 其他方式安装，看这里
    • Gogs 近年维护节奏放缓；看重活跃更新可以优先考虑 Gitea（界面和 Git 协议兼容，迁移成本低）

  2. 修改配置

    [server]
DOMAIN           = mydomain.site
HTTP_PORT        = 3000
; 旧版本是修改 ROOT_URL
EXTERNAL_URL     = https://mydomain.site/

  3. 运行

    #后台守护进程运行
nohup ./gogs web &   # 生产建议改用 systemd 托管，支持开机自启与崩溃重启

  4. 创建仓库（可以导入其他 repos，快速创建）

    #假设用户名为what,仓库名为up,仓库必须为公开,则仓库地址:
https://mydomain.site/what/up.git

git使用

#git下载
git clone https://mydomain.site/what/up.git

#增加代码及其他
....

#提交代码
git push

golang使用

  1. 设置私域名，不走代理

    go env -w GOPRIVATE=mydomain.site

  2. 代码使用

    package main

import (
    "fmt"

    "mydomain.site/what/up"
)

func main() {
    fmt.Println(up.Add(10, 10))
    fmt.Println(up.Power(10, 10))
}
