Mermaid 2026：11.x 原生集成

版本线 2026

Mermaid 自 2024-11 发布 v11.0.0 的渲染引擎重构后，2026 年稳定推进到 v11.12.x：

版本时间关键变化
v11.0.02024-11渲染引擎重构：可自定义布局算法与视觉样式；新增 packet 数据包图；langium 解析器；ESBuild 产物替代 UMD
v11.x 线2025-2026架构图（architecture-beta）、象限图、时序图 actor 类、Git 图自底向上方向等持续迭代
v11.12.x2026-08当前最新稳定线（VS Code 1.121 内置支持所引用的版本）
  • 思维导图（Mindmap）与架构图（Architecture）继续完善。
  • 交互式图表（点击事件）与 ELK 布局引擎仍是高级布局首选。

VS Code 1.121：Mermaid 原生支持

2026-05 VS Code 正式内置 Mermaid 渲染：

  • 内置 Markdown 预览：```mermaid 代码块直接渲染，无需任何扩展；支持 ::: 围栏形式。
  • 扩展合并：vscode-markdown-mermaid 扩展于 2026-05-21 标记 deprecated，功能并入 VS Code 1.121 本体；低版本 VS Code 仍可装该扩展（内置 Mermaid 11.12.0）。
  • 交互：图表支持缩放、平移；鼠标悬停/聚焦出现导航控件；图标字体支持 MDI 与 Iconify logos（如架构图中的 user(mdi:account)）。
  • notebook 支持：Markdown 单元格中的 mermaid 代码块同样可用。
```mermaid
graph TD
    A[需求] --> B{评审}
    B -->|通过| C[编码]
    B -->|驳回| A
```

2026 生态工具

工具用途
mermaid.live官方在线编辑器，实时预览 + 分享链接
mermaid.ink把图表转成图片：/img/*、/svg/*、/pdf/* 端点，支持 JPEG/PNG/WebP/SVG，README 插图首选
mermaid.ai官方商业平台：项目化组织、版本化、团队协作（Mermaid Chart Inc）
Office 插件Word/PowerPoint 插件：文档内直接创建、插入、一键同步更新图表
VS Code1.121+ 内置渲染；低版本用 vscode-markdown-mermaid

Markdown 生态（Typora、Obsidian、GitBook、Jupyter 等）均已内置 Mermaid 渲染，「文本即图表」仍是文档协作的默认姿势。
