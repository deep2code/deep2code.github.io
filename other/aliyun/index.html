阿里云专有网络

  • 专有网络（VPC）是你独有的云上虚拟网络，可以把云资源部署在自定义的专有网络里。
  • 云资源不能直接部署在专有网络本身上，必须归属到专有网络里的某个交换机（子网）。
  • 目前 IPv6 需要在专有网络里手动开启（创建 VPC 时可以选双栈）

阿里云ECS配置ipv6

  • VPC 和 ECS 支持双栈后，ECS 会分到 IPv6 地址；如果部署在 ECS 上的系统要主动访问公网 IPv6 系统，得配合 IPv6 网关用

  • 开通 IPv6 网关后，通过配置 IPv6 网关规则，允许 VPC 内指定 IPv6 地址访问公网，指定的 IPv6 ECS 就能主动访问公网了

  • 如果不配 IPv6 网关规则，默认 ECS 分到的 IPv6 地址只能在 VPC 内部通信

  • 安全组规则里，源 "::/0" 表示允许 IPv6，源 "0.0.0.0/0" 表示允许 IPv4；要支持双栈，同一端口得开放两条规则

阿里云更新（2024-2026）

阿里云的主要变化：

  • 通义千问（Qwen）：Qwen2.5（2024-09）之后 Qwen3 全面开源（Apache-2.0，支持混合推理），2026 年和 DeepSeek 并列国产开源模型第一梯队；
  • 百炼平台：Qwen 系列模型的托管 API 和 Agent 编排入口，已是阿里云 AI 应用开发的默认起点；
  • 通义灵码：AI 编程助手深度集成进 IDEA / VSCode 和云效流水线，是写代码和 Code Review 的日常工具；
  • 价格战：2024 年起大模型 API 多次大幅降价，Qwen 调用成本一年内降了一个数量级，老客户续费值得重新问价；
  • PAI：机器学习平台，覆盖训练、部署和 MLOps，仍是 ToB 客户的主力选择。
