常用命令

  • ddp-交换上下行-光标在上行，其与下行交换
  • :$ 跳转到最后一行
  • :1 跳转到第一行

查找字符串

  • /hello 向后查找 "hello",键入 "n" 继续下一个，键入 "shift+n"(大写 N) 向上回查
  • ?hello 向前查找上一个 "hello",键入 "n" 继续上一个，键入 "shift+n"(大写 N) 向下回查
  • /<printf> 精确匹配整个单词 printf:< 是单词开头边界，> 是单词末尾边界；正则里需要转义时写成 \< \>

复制粘贴

  • 复制一行，我们只要把光标移动到想复制的那一行，按yy，就是两次y键，
  • 粘贴，把光标移动到你想粘贴的那一行，按p键即可。
  • 复制多行，把光标移动到想复制多行的开头，想要向下复制几行，就按nyy，比如我想从这一行开始复制5行，就按5yy

插件管理器-vim-plug

  • vim-plug 是 vim 下的插件管理器， 可以帮我们统一管理后续的所有插件， 后续的安装插件全部由此工具完成 类似的插件管理工具还有 Vundle, 相较而言 vim-plug 支持异步且效率非常高， 具体选择交由读者自己

  • 安装

curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
  • 配置声明
vim .vimrc

:set term=builtin_ansi
:set encoding=utf-8
:set nocompatible
:set nu
:set hlsearch
:syn on
call plug#begin()
Plug 'preservim/nerdtree'
Plug 'jiangmiao/auto-pairs'
Plug 'vim-airline/vim-airline'
Plug 'vim-airline/vim-airline-themes'
Plug 'morhetz/gruvbox'
Plug 'frazrepo/vim-rainbow'
Plug 'chiel92/vim-autoformat'
Plug 'vim-scripts/bash-support.vim'
Plug 'zaach/jsonlint'
Plug 'plasticboy/vim-markdown'
Plug 'psf/black'
Plug 'fatih/vim-go'
Plug 'sheerun/vim-polyglot'
call plug#end()
  • 激活安装-相应插件
$ vim        #打开vim
:PlugStatus  #查看插件状态
:PlugInstall #安装之前在配置文件中声明的插件
  • 优秀插件网站(https://github.com/vim-awesome/vim-awesome)

在 ~/.vimrc 里补下面几行，解决中文乱码以及方向键只能在末尾行移动的问题：

:set encoding=utf-8

Neovim 2026：OOTB 与「Batteries Included」

0.12「OOTB」：开箱即用之年（2025-12 发布）

Neovim 0.12 的目标是让默认配置直接可用，减少插件铺装：

  • 内置插件管理器 vim.pack：里程碑变化，为后续「Batteries Included」铺路，逐步缓解插件依赖第三方管理器的问题。
  • 默认状态栏升级：自带 diagnostics 与 LSP progress，开箱即显示诊断与进度。
  • LSP 大增强：新增 11+ 能力支持，新增 :lsp 命令，默认提供常用 keymap，enable/start/stop 行为更可控。
  • UI 远程能力：:UI connect / :restart，可连接运行中的 Neovim 实例。
  • Prompt buffer 增强：多行输入、粘贴、undo/redo；「Press ENTER」提示大幅收敛。

0.13「Batteries Included」：开发中路线图

Neovim 官方 Roadmap 将 0.13 定义为「自带电池的一年」，核心方向是可见性、标准库与多光标编辑：

  • Multicursor（多光标）：原生多光标编辑，对标主流编辑器体验。
  • vim.async：任务抽象层、结构化并发，插件不再各自造轮子。
  • CmdAtom 事件：可订阅任意「用户操作」，插件生态的统一事件源。
  • 文件变更检测：OS watcher 驱动的 autoread，外部改动自动感知。
  • dir.lua 目录浏览器：替代 netrw 的现代文件浏览。
  • Image API（vim.ui.img）：终端内嵌图像渲染（kitty 协议等）。
  • packspec / pkg.json：包规范与远程 ssh 支持，向 1.0 迈进。

0.13 尚在开发中（可在 nightly 体验），当前稳定版仍是 0.12 线。

LazyVim 16.0：配置发行版的演进

LazyVim（基于 lazy.nvim 的现代化配置发行版）2026-06-02 发布 v16.0.0，要求 Neovim ≥ 0.11.2。它依然是新手最快上手的路径：

  • 按需加载：仅打开对应文件类型才加载相关插件，86 插件配置启动可压到 400ms 左右。
  • 依赖管理：自动处理插件依赖与版本冲突，无需手动编译。
  • 性能可视化：内置 profiling，直观看到每个插件的加载耗时。
  • 2026 生态现状：LSP + Treesitter + 50 个插件的完整配置内存占用 < 120MB，启动 < 50ms（SSD），已是完整 IDE 体验。
