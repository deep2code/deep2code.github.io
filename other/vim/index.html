查找字符串

  • /hello 向后查找 "hello"，键入 "n" 继续下一个，键入 "shift+n"（大写 N）向上回查
  • ?hello 向前查找上一个 "hello"，键入 "n" 继续上一个，键入 "shift+n"（大写 N）向下回查
  • /<printf> 精确匹配整个单词 printf：< 是单词开头边界，> 是单词末尾边界；正则里需要转义时写成 \< \>

复制粘贴

  • 复制一行，只要把光标移到想复制的那一行，按 yy，就是按两次 y 键
  • 粘贴，把光标移到想粘贴的那一行，按 p 键就行。
  • 复制多行，把光标移到想复制多行的开头，想向下复制几行就按 nyy，比如想从这一行开始复制 5 行，就按 5yy

Vim/Neovim 架构与编辑原理深度解析

模态编辑：Vim 的核心哲学

Vim 是模态编辑器（Modal Editor），不同模式下按键有不同含义：

  6 种主要模式：

  1. Normal（普通模式，默认）
     - 按键是命令，不是输入文本
     - 用于移动、删除、复制、粘贴、搜索
     - 这是 Vim 的"home"模式，操作完应回到此模式
     - 其他模式按  回到 Normal
     
  2. Insert（插入模式）
     - 按键直接输入文本
     - 进入方式：i（当前字符前）、a（当前字符后）、o（下一行）
     - 类似普通编辑器，但功能更少
     - 应该尽量少待在 Insert 模式（效率低）
     
  3. Visual（可视模式）
     - 选择文本区域
     - 进入方式：v（字符选择）、V（行选择）、（块选择）
     - 选择后可以对选区执行命令（d删除、y复制、>缩进）
     
  4. Visual Block（可视块模式）
     -  进入，选择矩形区域
     - 强大功能：列编辑（同时修改多行的同一列）
     - 示例： 选择多行 → I 输入注释 →  批量注释
     
  5. Command-line（命令行模式）
     - : 进入，底部输入 Ex 命令
     - 用于保存、退出、搜索替换、设置选项
     - 示例：:w 保存、:q 退出、:s/foo/bar/g 替换
     
  6. Terminal（终端模式，Neovim）
     - :terminal 打开内置终端
     -  回到 Normal 模式
     - 可以在终端缓冲区中用 Vim 命令操作输出

  操作符 + 动作 = 命令（Operator + Motion）：
  Vim 的语法结构：
  - 操作符（Operator）：d(删除)、y(复制)、c(修改)、>(缩进)、gU(大写)
  - 动作（Motion）：w(下一个词)、$(行尾)、gg(文件首)、/(搜索)
  - 文本对象（Text Object）：iw(词)、it(标签内)、ip(段落)
  
  组合示例：
  - dw = 删除一个词（d + w）
  - d$ = 删除到行尾（d + $）
  - diw = 删除当前词（d + iw，不包含空格）
  - yip = 复制当前段落（y + ip）
  - ci" = 修改引号内内容（c + i"）
  - gU2w = 后面两个词大写（gU + 2w）
  
  数字前缀：
  - 3dd = 删除 3 行
  - 5yy = 复制 5 行
  - 2w = 前进 2 个词
  - 10j = 向下 10 行

  为什么模态编辑更快？
  - 不需要移动手到方向键/鼠标
  - 命令是组合式的，学习一次可无限组合
  - 文本对象精确操作（di" 比双击选中引号内容快）
  - 重复操作（. 命令重复上次修改）

缓冲区、窗口、标签页架构

Vim 的多文件管理三层架构：

  1. Buffer（缓冲区）
     - 内存中打开的文件
     - 一个文件对应一个 Buffer
     - Buffer 可以不显示（隐藏）
     - :ls 列出所有缓冲区
     - :b  切换缓冲区
     - :bd 删除缓冲区
     - 状态：%（当前）、#（交替）、a（活动）、h（隐藏）、+（已修改）
     
  2. Window（窗口）
     - Buffer 的视口（显示区域）
     - 一个 Buffer 可以在多个 Window 中显示
     - 一个 Window 只显示一个 Buffer
     - :sp 水平分割、:vsp 垂直分割
     - w 切换窗口、h/j/k/l 方向切换
     - = 平均大小、_ 最大化高度、| 最大化宽度
     - :q 关闭窗口（不关闭 Buffer）
     
  3. Tabpage（标签页）
     - 窗口布局的集合
     - 每个 Tabpage 可以有自己的窗口布局
     - :tabnew 新建标签页、:tabclose 关闭
     - gt 下一个标签页、gT 上一个标签页
     - 注意：Vim 的 Tab 不同于浏览器 Tab，它是布局集合

  关系图：
  Tabpage 1
  ├── Window 1 → Buffer A (main.go)
  └── Window 2 → Buffer B (utils.go)
  
  Tabpage 2
  ├── Window 1 → Buffer C (README.md)
  ├── Window 2 → Buffer A (main.go)  ← 同一 Buffer 可在多窗口显示
  └── Window 3 → Buffer D (config.yaml)

  隐藏缓冲区（Hidden Buffer）：
  - :set hidden 允许切换缓冲区时不保存（隐藏已修改的缓冲区）
  - 没有 hidden 时，切换修改过的缓冲区会报错
  - 现代配置默认开启 hidden
  - :qa! 强制退出所有（放弃修改）
  - :wa 保存所有缓冲区

  缓冲区列表操作：
  - :bnext / :bprev 下一个/上一个缓冲区
  - :bfirst / :blast 第一个/最后一个
  - :b  按编号切换
  - :b  按名称模糊匹配
  - :bufdo  对所有缓冲区执行命令

  最佳实践：
  - 用缓冲区管理文件，而不是标签页
  - 标签页用于不同的工作布局（如编码 vs 测试）
  - 窗口用于同时查看多个文件（如代码 + 测试）
  - 插件：fzf/telescope 快速切换缓冲区

文本对象与高级移动

文本对象（Text Objects）是 Vim 最强大的特性之一：

  内置文本对象：

  1. 词（Word）
     - aw：一个词（包含周围空格）
     - iw：一个词（不包含空格）
     - 示例：diw 删除当前词，ciw 修改当前词
     
  2. 句子（Sentence）
     - as：一个句子（包含空格）
     - is：一个句子（不包含空格）
     - 句子定义：以 . ! ? 结尾，后跟空格或换行
     
  3. 段落（Paragraph）
     - ap：一个段落（包含空行）
     - ip：一个段落（不包含空行）
     - 段落定义：空行分隔的文本块
     
  4. 引号（Quotes）
     - a" / i"：双引号
     - a' / i'：单引号
     - a` / i`：反引号
     - 示例：ci" 修改引号内内容，da" 删除引号及内容
     
  5. 括号（Brackets）
     - ab / ib：圆括号 ()
     - aB / iB：花括号 {}
     - a[ / i[：方括号 []
     - a< / i<：尖括号 <>
     - 示例：ci( 修改括号内内容，daB 删除代码块
     
  6. 标签（Tags，HTML/XML）
     - at：一个标签（包含标签本身）
     - it：标签内内容
     - 示例：cit 修改标签内内容，dat 删除整个标签
     
  7. 函数/类（需要插件或 textobj-user）
     - af / if：函数
     - ac / ic：类
     - 需要 vim-textobj-function 等插件

  文本对象的威力：
  - 精确操作，不需要手动选择
  - 嵌套感知：di( 会找到匹配的右括号
  - 可重复：. 命令重复上次文本对象操作
  - 组合：d + i + " = 删除引号内内容

  高级移动（Motion）：

  1. f/F/t/T（行内查找）
     - f{char}：跳到下一个 char
     - F{char}：跳到上一个 char
     - t{char}：跳到下一个 char 的前一个字符
     - T{char}：跳到上一个 char 的后一个字符
     - ; 重复上次查找，, 反向重复
     - 示例：df, 删除到逗号，ct= 修改到等号
     
  2. / 和 ?（搜索）
     - /{pattern}：向下搜索
     - ?{pattern}：向上搜索
     - n 下一个，N 上一个
     - * 搜索当前词，# 反向搜索当前词
     - 操作符 + 搜索：d/foo 删除到 foo
     
  3. %（匹配括号）
     - 跳到匹配的括号 () {} []
     - 也可以匹配 if/endif、begin/end（需要 matchit 插件）
     
  4. 标记（Mark）
     - m{a-z}：设置小写标记（当前文件）
     - m{A-Z}：设置大写标记（跨文件）
     - '{mark}：跳到标记行
     - `{mark}：跳到标记精确位置
     - ``：回到上次跳转位置
     - 特殊标记：'.（上次修改行）、'.（上次修改位置）、'<（选区首）

  5. 跳转列表（Jump List）
     - ：上一个跳转位置
     - ：下一个跳转位置
     - :jumps 查看跳转列表
     - 记录所有"大跳转"（gg、G、/、n、%等）

Vim/Neovim 常见陷阱与最佳实践

  • 陷阱1：长时间停在 Insert 模式 → 操作完立即按 回 Normal 模式；用 jj 或 jk 映射快速退出（inoremap jj ）
  • 陷阱2：用方向键移动 → 强制自己用 hjkl，把方向键映射为空；开始慢，长期效率高
  • 陷阱3：不使用文本对象 → 学习 iw/it/ip/i" 等文本对象，比手动选择快得多；di" 比双击选中引号内容快
  • 陷阱4：重复操作不用 . → . 命令重复上次修改，是 Vim 最强大的命令之一；学会构造可重复的操作（如 ciw）
  • 陷阱5：配置文件过长 → 用 Lazy.nvim 管理插件，按需加载；配置模块化（lua/plugins/、lua/config/）；不要复制别人的整个配置
  • 陷阱6：插件装太多 → 每个插件都有性能开销；只装真正需要的；用 :checkhealth 检查插件状态；启动时间 < 50ms 为佳
  • 陷阱7：不理解 Buffer vs Window → Buffer 是文件，Window 是视口；关闭窗口不关闭缓冲区；用 :ls 查看缓冲区，:b 切换
  • 陷阱8：不学习 Ex 命令 → :s 替换、:g 全局命令、:normal 批量执行、:argdo 多文件操作；掌握 Ex 命令是 Vim 进阶的关键

  • 按需加载：只打开对应文件类型才加载相关插件，86 插件配置启动可以压到 400ms 左右。
  • 依赖管理：自动处理插件依赖和版本冲突，不用手动编译。
  • 性能可视化：内置 profiling，直观看到每个插件的加载耗时。
  • 2026 生态现状：LSP + Treesitter + 50 个插件的完整配置内存占用 < 120MB，启动 < 50ms（SSD），已经是完整 IDE 体验。
