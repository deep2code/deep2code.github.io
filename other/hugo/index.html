简介

  • Hugo 是用 Go 语言实现的静态网站生成器官网
  • 用户用 Markdown 编辑内容，主题 / 插件负责展示，Hugo 把两者编译成纯静态站点
  • Hugo 靠 shortcode 扩展内容能力（把一段模板封装成可复用的语法块）
  • 用最新的 mermaid.js 替换 Hugo-theme-learn 主题自带的 mermaid.js，就能用上最新的 mermaid 功能
  • config.toml 里 "home = ["HTML", "RSS", "JSON"]" 会产生 index.json 索引，不要删

本地运行官网

git clone https://github.com/gohugoio/hugoDocs.git

cd hugoDocs

hugo -D server

默认访问http://localhost:1313/

出现类似下面的报错，可以在 hugoDocs 的 config.toml 里加 timeout = 100000（单位 ms，默认 30s 不够用时按需放大）。

根因：hugo 生成网站耗时超出了默认 timeout 限制。

Error building site: ".../hugoDocs/content/en/troubleshooting/faq.md:1:1": timed out initializing value. You may have a circular loop in a shortcode, or your site may have resources that take longer to build than the `timeout` limit in your Hugo config file.

Hugo 2026：0.15x 时代的 SSG

版本节奏：0.14x → 0.15x

Hugo 保持高频发布（大约每 1-2 周一个小版本），2026 年已进入 0.15x 线，最新 0.159.x（2026-08）：

阶段代表版本关键变化
0.14xv0.148.2Selenium 官方文档等大型站点推荐基线；0.14 中标记 deprecated 的 API
0.15xv0.152.2 → v0.159.x移除 0.14 弃用项：getJson→getJSON、getCsv→getCSV、safeHtml→safeHTML、BaseUrl→BaseURL、Recent→Pages 等；deploy 版本支持 go install -tags withdeploy（全新）
  • 构建要求：从源码安装需要 Go 1.26.0+；deploy edition 从 v0.159.2 起可以用 -tags withdeploy 编译，替代旧部署方式。
  • 函数命名规范化：0.15x 起旧驼峰拼写全部移除，老模板升级时按上表替换就行。

2026 生态观察

  • 迁移潮：一批大型站点从 Hugo 迁往 Astro / Starlight（比如 2026 年多个知名开源项目的文档站迁移），编译器级性能 vs 组件化生态的分化成了主流。
  • Docsy 0.15.0（2026-05）：Google Docsy 主题大版本发布，支持 LLMS 输出和 llms.txt（站点为 AI 代理提供可读清单），开源文档站标配能力成形。
  • AI 可读性：llms.txt 成了 2026 静态站的标配，Hugo 站点可以在模板里直接输出。
  • 主题生态：PaperMod、Blowfish 等现代主题仍活跃；Hugo Modules 是主流依赖方式。
# 安装 Hugo（macOS）
brew install hugo

# 创建站点
hugo new site mysite
cd mysite
git init
git submodule add https://github.com/adityatelange/hugo-PaperMod themes/PaperMod
echo "theme = 'PaperMod'" >> hugo.toml
hugo server -D

静态站选型：Hugo 还值得用吗

2026 年的静态站生态已经分层，选型取决于站点形态：

需求推荐说明
海量内容、要求构建极快HugoGo 编译，数万页毫秒级构建，模板能力强
文档站 + 组件化 UIAstro / Starlight组件生态 + 内容岛，官方文档站主流迁移方向
全栈 React/SSGNext.jsSSG + SSR + 服务端逻辑一体
极简博客（AI 时代轻量维护）Hugo / Zola / 纯静态单二进制、无 Node 依赖，重建秒级完成

本博客就是用「纯静态生成 + 本地直开双兼容」方案；Hugo 在单二进制部署和构建速度上依旧没有对手。
