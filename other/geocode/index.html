地理编码

地理编码

地理编码是指将地址或地名等位置描述转换为经纬度坐标的过程.

出于国家安全考虑，公布出来的坐标信息一般是经过加偏的.

逆地理编码

逆地理编码可将经纬度坐标转换为详细,标准的地址信息.

常用接口

  1. 高德地图开放平台

  2. 百度地图开放平台

  3. google中国

  4. 阿里云-云市场

地理编码更新

推荐使用百度地图 API 或高德地图 API 进行地理编码。详见 baidu-ai-map 技能。
