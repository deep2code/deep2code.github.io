地理编码

地理编码

地理编码是指将地址或地名等位置描述转换为经纬度坐标的过程.

出于国家安全考虑，公布出来的坐标信息一般是经过加偏的.

逆地理编码

逆地理编码可将经纬度坐标转换为详细,标准的地址信息.

常用接口

  1. 高德地图开放平台

  2. 百度地图开放平台

  3. google中国

  4. 阿里云-云市场

地理编码更新

推荐使用百度地图 API 或高德地图 API 进行地理编码。详见 baidu-ai-map 技能。

2026 服务现状：三家额度与商用授权

截至 2026 年 8 月的概况：

  • 高德：Web 服务端 API（地理编码 / 逆地理编码）按开发者身份给免费月配额——普通个人约 5,000–150,000 次/月、认证个人 50,000–300,000 次/月、企业 500,000–3,000,000 次/月；逆地理编码个人约 6,000 次/日。学习与原型场景基本够用；
  • 百度：免费额度较保守，个人约 2,000 次/日（不同接口略有差异）；
  • 腾讯位置服务：地理编码 / 逆地理编码 / 批量处理齐备，社区测评解析质量与 100ms 内延迟表现好，适合高并发场景；
  • 三项商用基础授权 2026 年行情统一为 5 万/年，产品上线商用前需购买授权证书，否则应用市场审核与采购合规过不去。

坐标系换算与批量注意

三家坐标不同：高德、腾讯返回 GCJ02（火星坐标），百度返回 BD09，GPS 设备与 Google 用 WGS84。跨服务商对比时先换算，常用内核（WGS84 ⇄ GCJ02）如下：

const (
    pi = 3.1415926535897932384626
    a  = 6378245.0
    ee = 0.00669342162296594323
)

func inChina(lng, lat float64) bool {
    return lng > 73.66 && lng < 135.05 && lat > 3.86 && lat < 53.55
}

func transformLat(x, y float64) float64 {
    ret := -100.0 + 2.0*x + 3.0*y + 0.2*y*y + 0.1*x*y
    ret += 0.2*math.Sqrt(math.Abs(x))
    ret += (20.0*math.Sin(6.0*x*pi)+20.0*math.Sin(2.0*x*pi)) * 2.0 / 3.0
    ret += (20.0*math.Sin(y*pi)+40.0*math.Sin(y/3.0*pi)) * 2.0 / 3.0
    ret += (160.0*math.Sin(y/12.0*pi)+320.0*math.Sin(y*pi/30.0)) * 2.0 / 3.0
    return ret
}

func transformLon(x, y float64) float64 {
    ret := 300.0 + x + 2.0*y + 0.1*x*x + 0.1*x*y
    ret += 0.1*math.Sqrt(math.Abs(x))
    ret += (20.0*math.Sin(6.0*x*pi)+20.0*math.Sin(2.0*x*pi)) * 2.0 / 3.0
    ret += (20.0*math.Sin(x*pi)+40.0*math.Sin(x/3.0*pi)) * 2.0 / 3.0
    ret += (150.0*math.Sin(x/12.0*pi)+300.0*math.Sin(x/30.0*pi)) * 2.0 / 3.0
    return ret
}

// WGS84 -> GCJ02
func wgs84ToGCJ02(lng, lat float64) (float64, float64) {
    if !inChina(lng, lat) {
        return lng, lat
    }
    dLat := transformLat(lng-105.0, lat-35.0)
    dLng := transformLon(lng-105.0, lat-35.0)
    radLat := lat / 180.0 * pi
    magic := math.Sin(radLat)
    magic = 1 - ee*magic*magic
    sqrtMagic := math.Sqrt(magic)
    dLat = (dLat * 180.0) / ((a * (1 - ee)) / (magic * sqrtMagic) * pi)
    dLng = (dLng * 180.0) / (a / sqrtMagic * math.Cos(radLat) * pi)
    return lng + dLng, lat + dLat
}

// GCJ02 -> WGS84（一次迭代近似）
func gcj02ToWGS84(lng, lat float64) (float64, float64) {
    glng, glat := wgs84ToGCJ02(lng, lat)
    return lng*2 - glng, lat*2 - glat
}

批量处理注意三点：按配额限速（建议自己加 time.Sleep 或 token bucket）、结果缓存（同一地址命中率通常很高）、以及内网或离线兜底方案（自部署 OpenStreetMap Nominatim / PostGIS + 行政区数据）。坐标系换算代码为通用公式，可在不依赖地图 SDK 的场景直接复用。
