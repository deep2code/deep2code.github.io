简介

简介

  • 官网 GitHub

  • Harbor 最初由 VMware 开源，是企业级 Docker Registry 项目，目标是帮助用户快速搭建可用的私有镜像仓库服务；2022 年捐赠给 CNCF，现由独立社区维护。

  • Harbor 以 Docker 公司开源的 Registry 为基础，提供了图形管理 UI、角色访问控制（RBAC）、AD/LDAP 集成、审计日志（Audit Logging）等企业级能力，并原生支持中文。

  • Harbor 的每个组件都以 Docker 容器形式构建，用 Docker compose 统一部署；部署模板位于 harbor/Docker-compose.yml。

  • 官方最低要求 2 核 4G，生产环境推荐 4 核 8G 及以上。

Harbor 更新

Harbor 持续演进：

  • v2.9+：OCI 镜像支持增强
  • Signature：Sigstore 签名集成
  • Proxy Cache：代理缓存企业镜像
  • Tag Retention：自动清理镜像策略

安装部署

环境要求

  • Docker：20.10+
  • Docker Compose：v1.29+ / v2.0+
  • 硬件：最低 2 核 4G，推荐 4 核 8G
  • 存储：至少 40GB 可用空间

在线安装（推荐）

# 下载安装包
wget https://github.com/goharbor/harbor/releases/download/v2.10.0/harbor-offline-installer-v2.10.0.tgz

# 解压
tar -xzf harbor-offline-installer-v2.10.0.tgz
cd harbor

# 配置
cp harbor.yml.tmpl harbor.yml
# 编辑 harbor.yml 配置域名、端口、密码等

# 安装
sudo ./install.sh --with-trivy --with-chartmuseum

离线安装

# 适用于内网环境
# 需要提前下载镜像
docker load -i harbor.v2.10.0.tar.gz

# 导入镜像脚本
docker load -i harbor.*.tar.gz

# 启动
docker-compose up -d

Docker Compose 部署

# docker-compose.yml 示例
version: '3.8'

services:
  harbor-portal:
    image: goharbor/harbor-portal:v2.10.0
    container_name: harbor-portal
    networks:
      - harbor

  harbor-core:
    image: goharbor/harbor-core:v2.10.0
    environment:
      - HARBOR_DB_HOST=harbor-db
      - HARBOR_DB_PASSWORD=changeme
    networks:
      - harbor

  harbor-db:
    image: goharbor/harbor-db:v2.10.0
    environment:
      - POSTGRES_PASSWORD=changeme
    networks:
      - harbor

  redis:
    image: goharbor/redis:v2.10.0
    networks:
      - harbor

  registry:
    image: goharbor/registry:v2.10.0
    networks:
      - harbor

networks:
  harbor:
    driver: bridge

使用指南

登录 Harbor

# 登录
docker login your-harbor.com
# 输入用户名: admin
# 输入密码: Harbor12345

# 退出登录
docker logout your-harbor.com

推送和拉取镜像

# 标记镜像
docker tag myapp:latest your-harbor.com/library/myapp:latest

# 推送镜像
docker push your-harbor.com/library/myapp:latest

# 拉取镜像
docker pull your-harbor.com/library/myapp:latest

# 推送到特定项目
docker tag myapp:latest your-harbor.com/myproject/myapp:v1.0
docker push your-harbor.com/myproject/myapp:v1.0

Helm Chart 仓库

# 启用 Chart 仓库
# 在 harbor.yml 中设置 chart_repository_enabled: true

# 添加 Harbor 作为 Helm 源
helm repo add harbor https://your-harbor.com/chartrepo/library --username=admin --password=Harbor12345

# 搜索 Chart
helm search repo harbor/

# 推送 Chart
helm package mychart/
helm push mychart-1.0.0.tgz harbor://library/

配置管理

harbor.yml 关键配置

# 基本配置
hostname: harbor.yourdomain.com
http:
  port: 80
https:
  port: 443
  certificate: /path/to/cert.pem
  private_key: /path/to/key.pem

# Harbor 管理员密码
harbor_admin_password: Harbor12345

# 数据库配置
database:
  password: harbor_db_password
  max_idle_conns: 50
  max_open_conns: 100

# 存储配置
storage_service:
  # 使用文件系统
  filesystem:
    rootdirectory: /data/registry
  # 或使用 S3
  # s3:
  #   bucket: harbor-registry
  #   region: us-west-2

# 启用组件
with_trivy: true
with_chartmuseum: true
with_notary: true
with_clair: true

# 外部数据库（可选）
# external_database:
#   harbor:
#     host: db_host
#     port: 5432
#     db_name: harbor
#     username: harbor
#     password: password

# 外部 Redis（可选）
# external_redis:
#   host: redis_host
#   port: 6379
#   password: password

配置 TLS 证书

# 使用 Let's Encrypt 自动签发
# 在 harbor.yml 中配置
hostname: harbor.yourdomain.com
https:
  letsencrypt:
    directory_url: https://acme-v02.api.letsencrypt.org/directory
    account_email: admin@yourdomain.com

# 或手动配置
# 1. 获取证书
# 2. 转换为 .pem 格式
# 3. 配置 harbor.yml
# 4. 重新部署
./install.sh --with-notary

安全配置

角色访问控制

  • 管理员：完全访问权限
  • 项目管理员：项目管理、成员管理
  • 开发者：推送/拉取镜像
  • 访客：只读拉取
  • 镜像仓库维护人员：删除镜像

镜像扫描

# 启用 Trivy 扫描
# 默认情况下，Harbor 会自动扫描推送的镜像

# 手动扫描
# 1. 登录 Harbor Web UI
# 2. 选择项目 -> 镜像
# 3. 点击扫描按钮

# API 调用
curl -X POST "https://harbor/api/v2.0/projects/myproject/repositories/myrepo/artifacts/myimage:tag/scan"   -H "Authorization: Bearer $TOKEN"

镜像签名

# 启用 Notary 后可对镜像签名
# 1. 在 Harbor UI 中启用 Notary
# 2. 签名镜像
docker trust sign your-harbor.com/myproject/myimage:v1

# 验证签名
docker trust verify your-harbor.com/myproject/myimage:v1

运维管理

备份与恢复

# 备份
# 1. 备份数据库
docker exec -it harbor-db pg_dump -U postgres harbor > harbor_db.sql

# 2. 备份镜像存储
tar -czf harbor_registry.tar.gz /data/registry

# 3. 备份配置文件
cp harbor.yml harbor.yml.bak

# 恢复
# 1. 恢复数据库
docker exec -i harbor-db psql -U postgres harbor < harbor_db.sql

# 2. 恢复镜像存储
tar -xzf harbor_registry.tar.gz -C /

# 3. 重启 Harbor
docker-compose down
docker-compose up -d

升级指南

# 1. 停止 Harbor
cd harbor
docker-compose down

# 2. 备份数据
cp -r /data backup_data
cp harbor.yml harbor.yml.backup

# 3. 下载新版本
wget https://github.com/goharbor/harbor/releases/download/v2.10.0/harbor-offline-installer-v2.10.0.tgz

# 4. 解压并配置
tar -xzf harbor-offline-installer-v2.10.0.tgz
cp harbor.yml.backup harbor/harbor.yml

# 5. 执行升级
cd harbor
./install.sh --with-trivy --with-chartmuseum

健康检查

# 检查 Harbor 状态
docker-compose ps

# 检查日志
docker-compose logs -f harbor-core

# 检查端口
netstat -tlnp | grep 80

# API 健康检查
curl -k https://localhost/api/v2.0/health

# 清理过期镜像
# 在 Harbor UI 中配置保留策略
# 或使用 GC 命令
docker exec -it harbor-registry registry garbage-collect /etc/registry/config.yml
