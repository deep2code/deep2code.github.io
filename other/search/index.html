搜索技巧

AI 导读一分钟导读，先掌握全文主干。▼

核心观点

  • 覆盖搜索引擎原理与常见开源引擎容量对比
  • 涵盖 Solr/Lucene/Meili/TypeSense/Elasticsearch 等选型维度
  • 文末 2024-2026 更新对齐搜索生态变化

关键结论与取舍

  • 先定数据规模与场景，再在轻量与重量引擎间选择
  • 十万级以内单机全文搜索用轻量引擎性价比更高
适合谁读做站内搜索或搜索服务的后端工程师 读完可获得搜索引擎原理、引擎对比与选型清单

搜索技巧就是在搜索关键字时，配合一些通配符，帮自己快速定位到想要的结果

搜索技巧常常作为 SEO（Search Engine Optimization）技术学习的一部分

SEO：是一种通过了解搜索引擎，来提高目标网站在有关搜索引擎里排名的方式

intitle标题

keyword intitle:标题关键字

intext内容

keyword intext:内容关键字

site站内(还可以查看网站的收录情况)

keyword site:cnblogs.com
duckduckgo site:zhihu.com

inurl链接

keyword inurl:video

限定时间段

keyword 2022..2022

info 介绍

info:zhihu.com

cache 搜索引擎关于某项关键字的缓存

graph TB DOC[文档

cache:keyword

双引号/书括号，禁止拆分

"keyword"《keyword》

Filetype过滤文件类型

keyword:pdf

减号，排除关键词

# python -广告 -推广
keyword -keyword2

模糊匹配

keyword*keyword

define 关键词定义

define:keyword

link 搜索与某个网址有关联的其他网址

keyword link:xxx.com
