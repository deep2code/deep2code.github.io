搜索技巧就是在搜索关键字时，配合一些通配符，帮助快速定位到想要的结果

搜索技巧常常作为 SEO(Search Engine Optimization)技术学习的一部分

SEO : 是一种通过了解搜索引擎，以及提高目的网站在有关搜索引擎内排名的方式

intitle 标题

keyword intitle:标题关键字

intext 内容

keyword intext:内容关键字

site 站内(还可以查看网站的收录情况)

keyword site:cnblogs.com
duckduckgo site:zhihu.com

inurl 链接

keyword inurl:blog
keyword inurl:java

搜索技术更新

搜索领域的变化：

  • AI 搜索：Perplexity、Arc Search、ChatGPT 搜索正在改变传统搜索
  • 语义搜索：向量搜索 + 关键词搜索结合
  • 开发者搜索：DevDocs、Stack Overflow AI 辅助

高级搜索技巧

搜索运算符

  • AND：两个关键词同时出现
  • OR：至少一个关键词出现
  • -：排除关键词
  • ""：精确匹配
  • *：通配符
  • ..：数值范围

实际示例

# 排除特定结果
python tutorial -advertising -promotion

# 精确短语
"how to install python" windows

# 文件类型搜索
filetype:pdf python tutorial
filetype:doc kubernetes guide

# 站内搜索
site:github.com python tutorial
site:medium.com kubernetes

# 价格/数值范围
laptop $500..$1000
python version 3.8..3.12

# 最近结果
python tutorial after:2024-01-01
kubernetes guide before:2025-01-01

搜索引擎选择

通用搜索

  • Google：全球最大，广告多但结果准确
  • Bing：微软系，集成 Copilot AI
  • DuckDuckGo：隐私优先，无追踪
  • Baidu：中文搜索首选

开发者搜索

  • DevDocs：聚合文档搜索
  • Stack Overflow：技术问答
  • GitHub：代码搜索
  • MDN：Web 技术文档

AI 搜索

  • Perplexity：AI 驱动的问答搜索
  • Arc Search：浏览器内置 AI 搜索
  • ChatGPT Search：OpenAI 的搜索产品
  • Gemini：Google 的 AI 搜索

SEO 基础

页面 SEO

  • Title：包含关键词，60 字符内
  • Meta Description：总结页面，160 字符内
  • H1-H6：层级结构清晰
  • Alt Text：图片添加描述
  • URL：简洁含关键词

技术 SEO

  • Site Map：XML 站点地图
  • Robots.txt：爬虫规则
  • Canonical：避免重复内容
  • Core Web Vitals：LCP/INP/CLS
  • 移动友好：响应式设计

SEO 工具

  • Google Search Console：搜索表现监控
  • Google Analytics：流量分析
  • Ahrefs：外链分析
  • Screaming Frog：技术 SEO 审计
