GitHub

GitHub 国内开发者必备指南

GitHub 是全球最大代码托管平台，对国内开发者而言，有几个功能是必须掌握的。

GitHub Pages - 免费静态网站托管

免费托管静态网站，支持自定义域名，绑定后自动开启 HTTPS。

  • 个人主页：创建 username.GitHub.io 仓库，README.md 即网站首页
  • 项目主页：任意仓库开启 Pages，访问 username.GitHub.io/repo
  • 自定义域名：仓库根目录添加 CNAME 文件，解析 CNAME 记录即可
# 推送后自动部署
git push origin main
# 访问 https://username.github.io

GitHub Actions - 自动化工作流

免费额度：每月 2000 分钟（公共仓库无限），足以应对个人项目。

  • 持续集成：代码提交自动运行测试
  • 自动部署：PR 合并后自动部署到服务器
  • 定时任务：Cron 语法定时执行
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run tests
        run: |
          npm install
          npm test

GitHub Copilot - AI 编程助手

2026 年已覆盖 46% 的代码，平均提升开发速度 55%。

  • 代码补全：自动根据上下文补全代码
  • 对话问答：Ctrl+I 打开聊天，解释代码、生成注释
  • 单元测试：选中的代码一键生成测试用例
  • 学生免费：.edu 邮箱认证后免费使用
# 输入函数名，Copilot 自动补全
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

GitHub CLI - 命令行工具

gh 命令替代网页操作，效率提升明显。

# 安装
brew install gh

# 登录
gh auth login

# 创建 PR
gh pr create --title "fix bug" --body "description"

# 查看 PR 状态
gh pr view 123

# 克隆仓库
gh repo clone owner/repo

Issues 妙用

不只是 Bug 跟踪，Issues 是项目管理利器。

  • 模板：创建 .GitHub/ISSUE_TEMPLATE.md，规范化提交
  • 标签：用颜色标签分类：bug、feature、enhancement
  • 项目看板：Projects 功能管理任务流
  • AI 辅助：Copilot 可自动建议 Issue 标签和分配

国内访问加速

GitHub 国内访问经常抽风，推荐方案：

  • ghproxy 镜像：HTTPS://ghproxy.com/ + 原始 URL
  • 代理工具：Clash、Surge 等代理工具
  • FastGithub（已停更），建议自备代理
  • 修改 hosts：查 IP 后手动添加（临时方案）
# 代理加速 clone
git clone https://ghproxy.com/https://github.com/owner/repo.git

# 或使用 gh proxy
gh config set git_protocol https
gh proxy set https://127.0.0.1:7890
