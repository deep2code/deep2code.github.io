pages服务

  1. User / Organization Pages 个人或公司站点

    1. 创建 username.github.io 仓库
    2. 仓库设置自定义域名，项目下面会自动增加 CNAME 文件
    3. 域名解析增加相应的 CNAME 记录

  2. Project Pages 项目站点

    1. gh-pages 分支用于构建和发布；
    2. 如果 user/org pages 用了独立域名，那托管在账户下的所有 project pages 会用相同域名重定向，除非 project pages 用了自己的独立域名； 如果没有用独立域名，project pages 会通过子路径的形式提供服务https://username.github.io/projectname ；

配套网站-Netlify

  • 用最快的方法构建最快的网站

当用 GitHub 把网站项目文件夹里的所有东西上传完毕后，就可以打开 Netlify 并授权它访问 GitHub 仓库。 Netlify 读取完你的网站所属仓库时，会自动识别你用的静态网页生成器，然后只要点击部署并发布，网站就会在 Netlify 被构建并发布。

  • 能够托管服务，免费 CDN

  • 能够绑定自定义域名

  • 能够启用免费的 TLS 证书，启用 HTTPS

  • 支持自动构建

  • 提供 Webhooks 和 API

Copilot：从编辑器走向 Agent

  • Copilot app（agent-native 桌面体验）：Microsoft Build 2026（2026-06-02）官方发布，Agent 以开发者习惯的方式直接工作；自定义 Copilot Agents 已覆盖可观测性、IaC、安全等场景。
  • 会话远程控制 GA（2026-05-18）：在 VS Code / CLI 里开起的 Copilot 会话，可以转到 github.com 或手机端继续，本地任务随处可续。
  • Copilot CLI 1.0.68（2026-07-02）：终端里的 agentic 编码助手；内置 GitHub MCP server，支持自定义 MCP 扩展；可以在 Actions 中以程序化模式跑（配合 GitHub Agentic Workflows，默认用 GITHUB_TOKEN 认证、自带护栏）。
  • 新 embedding 模型：Copilot 定位代码和理解仓库的能力明显增强，代码检索准确率进一步提升。

2026-03-26 官方发布 Actions 2026 安全路线图，核心是 workflow 级依赖锁定 ：

  • workflow YAML 新增 dependencies: 段，把直接 + 传递依赖全部锁定到 commit SHA——相当于 Workflow 版的 go.mod + go.sum ，完整可复现、可审计。
  • 效果：每次执行都跑「被 review 过」的精确版本；依赖更新以 PR diff 呈现；哈希不匹配在 job 运行前 fail-fast 拦截；composite action 的嵌套依赖不再被隐藏。
  • 公开预览预计 3-6 个月内、GA 约 6 个月内落地，建议提前规划升级节奏。

配合 actions/attest （工件签名 attestation，in-toto 格式）和 Actions 核心架构重建（2025-12 起性能 / 可靠性升级），CI/CD 供应链正从「引用可变 tag」走向「可审计、可复现」。

gh CLI 2.9x：读仓库、skills、Copilot

  • v2.95.0（2026-06-17）：新增 gh repo read-file / gh repo read-dir ——不 clone 直接读取远程仓库文件和目录，支持 --ref 指定分支 / tag / commit、支持 --json /--jq /--template ，对 AI agent 和自动化脚本非常友好。
  • v2.96.0（2026-07-02）：当前最新稳定版。
  • gh skills（v2.90.0+）：gh skill install 让 AI 技能变成可安装、可组合的软件包，支持作用域、子目录定位（--subpath）和交互式列表。
  • gh copilot 子命令：直接在终端进入 Copilot CLI，支持 /init 初始化仓库指令；Copilot CLI 1.0.x 稳定迭代中。
# gh CLI 常用命令（2026）
gh pr create --title "feat: add X" --body "description"
gh pr merge --squash --delete-branch
gh issue list --assignee @me
gh run watch  # 监控 Actions 运行

# 不 clone 直接读远程仓库（v2.95+，preview）
gh repo read-file README.md --repo cli/cli
gh repo read-dir script --repo cli/cli

# 安装 AI 技能包（v2.90+）
gh skill install github/awesome-copilot --skill code-reviewer
