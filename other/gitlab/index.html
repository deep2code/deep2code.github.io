  • Docker 部署 GitLab 完整流程，内存最低 2GB、越高越稳

安装私有部署(内存最低2GB,机器配置越高越好，否则会有各种问题)

# 下载安装docker
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun

# 启动docker
systemctl start docker

# 创建gitlab home
mkdir /srv/gitlab
# 导出环境变量 vim .bash_profile
export GITLAB_HOME=/srv/gitlab

# docker跑起来,采用社区版,自带常见服务足够了
# 生产建议把 :latest 换成具体版本号(如 gitlab-jh:18.11.3);宿主 80/443 被占用时需改端口映射
docker run --detach \
  --hostname gitlab.example.com \
  # 域名访问需在 /etc/gitlab/gitlab.rb 配好 external_url 后容器内 reconfigure
  --publish 443:443 --publish 80:80 --publish 8090:22 \
  --name gitlab \
  --restart always \
  --volume $GITLAB_HOME/config:/etc/gitlab \
  --volume $GITLAB_HOME/logs:/var/log/gitlab \
  --volume $GITLAB_HOME/data:/var/opt/gitlab \
  --shm-size 256m \
  registry.gitlab.cn/omnibus/gitlab-jh:latest

# 初始化过程可能需要很长时间。 您可以通过以下方式跟踪此过程,查看日志
docker logs -f gitlab

# 获取默认初始化密码,用户名是root
docker exec -it gitlab grep 'Password:' /etc/gitlab/initial_root_password

GitLab 更新（2026）：18.8 Agent Platform 与 19.0

旧小节停在 GitLab 16-17 的 Duo 起步期。2026 年的 GitLab 已经进入 18.x / 19.0 时代，AI 形态从「代码助手」升级为可编排的智能体平台，同时经历了一次影响面较大的安全紧急更新。

2026 版本线

版本发布时间里程碑
18.82026-01GitLab Duo Agent Platform 正式 GA
18.9 - 18.112026-02 - 04Agent Platform 能力收口、安全补丁线
19.02026-05大版本发布，同步出 19.0.1 安全补丁

维护策略：GitLab 安全修复只会回移植到当前稳定版及前两个月度版本 ，即 2026-08 时 19.x、18.11、18.10 仍受支持，更早版本需要先升级再谈补丁。

GitLab Duo Agent Platform 正式 GA

2026-01-15，GitLab 宣布 Duo Agent Platform 全面可用，面向 Premium / Ultimate 客户，覆盖 GitLab.com 和 Self-Managed 部署（Dedicated 在 18.8 发布周期内开放）。它解决的是「AI 提效悖论」——开发者写码提速但评审、安全、合规成了新瓶颈：

  • Agentic Chat——上下文感知的多步推理助手，在 Web UI 和 IDE 里回答复杂问题并自主执行动作，数据来自 issues、MR、流水线、安全发现
  • 多智能体编排——把代码重构、安全扫描、技术调研等常规任务委派给专门的 agent，异步协作而不是线性问答
  • 分层定价——Duo Core（基础 AI）/ Pro / Enterprise 三档，Free 层可以购买 GitLab Credits 按量使用部分 GA 功能；18.10 起才支持和 Enterprise 附加包同用

2026-05-27 紧急安全更新（关键）

2026 年 5 月 27 日 GitLab 发布 CE/EE 紧急安全更新，涉及 19.0.1、18.11.4、18.10.7 三个补丁版，自托管实例务必尽快升级：

风险点说明
CVE-2026-4868（CVSS 8.2 高危）Duo AI 工作流执行器的身份解析缺陷，认证用户可借他人身份触发 Duo 工作流
DoS 与授权缺陷Wiki 组件、GraphQL WorkItem API、流水线与认证端点多处

实操建议：自托管 GitLab 保持≤1 个月补丁滞后；已在 18.8 前版本启用 Agent Platform beta 的，需要按 18.10+ 要求迁移配置。
