安装

# 多半已安装过了,最新版本为5.xx
brew install tesseract

# This formula contains only the "eng", "osd", and "snum" language data files.
# If you need any other supported languages, run `brew install tesseract-lang`

# 本质是下载github所有训练完好的模型数据,放在/opt/homebrew/share/tessdata,供tesseract调用
brew install tesseract-lang

使用

# 获取帮助
tesseract --help-extra

# 告诉tesseract 源文件chinese.png -l 表示中文 stdout输出到标准库
tesseract chinese.png stdout -l chi_sim

# 类似数字识别
tesseract digit.png stdout -l snum

# 类似英文识别
tesseract english.png stdout -l eng

# 单行文本识别率非常不错,多行错误率非常高

OCR 技术更新

Tesseract 仍在维护，但现代 OCR 选择更多：

  • PaddleOCR：百度开源，中文识别强。
  • Surya：基于 Transformer，多语言。
  • 云服务：阿里云/腾讯云/Azure OCR API。

高级使用

识别置信度

# 输出带置信度的结果
tesseract input.png stdout -l chi_sim --psm 6 hocr

# 详细输出到文件
tesseract input.png output txt

图像预处理

OCR 识别率高度依赖图像质量，推荐预处理：

  • 灰度转换：convert input.PNG -colorspace Gray gray.PNG
  • 二值化：convert input.PNG -threshold 128 binary.PNG
  • 去噪声：convert input.PNG -median 3 denoised.PNG
  • 锐化：convert input.PNG -sharpen 1x1 sharpened.PNG

页面分割模式 (PSM)

  • --psm 3：完全自动分割（默认）
  • --psm 4：单列文本
  • --psm 5：单行文本
  • --psm 6：单个单词
  • --psm 11">稀疏文本

准备训练数据

# 创建训练目录

# 准备多个样本图像
# 图像命名规则：fontname.exp0.png, fontname.exp1.png, ...

创建 BOX 文件

# 生成初始 BOX 文件
tesseract eng.training_text.png eng makebox

# 使用 jTessBoxEditor 手动调整 BOX

训练流程

# 1. 生成 tr 文件
combine_tessdata -e eng.traineddata eng.training_files.txt

# 2. 运行训练
tesseract eng.training_text.png eng --psm 0     --traineddata eng/eng.traineddata     lstm.train

# 3. 合并模型
combine_tessdata -o eng.traineddata eng.lstmdata_1

Python 集成

pytesseract 库

import pytesseract
from PIL import Image

# 指定 tesseract 路径
pytesseract.pytesseract.tesseract_cmd = '/usr/local/bin/tesseract'

# 打开图像
img = Image.open('input.png')

# 识别文字
text = pytesseract.image_to_string(img, lang='chi_sim')
print(text)

# 获取置信度
data = pytesseract.image_to_data(img, lang='chi_sim', output_type=pytesseract.Output.DICT)
print(data['conf'])  # 置信度数组

PaddleOCR（推荐）

from paddleocr import PaddleOCR

# 初始化（首次下载模型较慢）
ocr = PaddleOCR(use_angle_cls=True, lang='ch')

# 识别
result = ocr.ocr('input.png', cls=True)

# 打印结果
for line in result:
    print(line[1])  # (文字, 置信度)

OCR 方案对比

方案优点缺点适用场景
Tesseract开源免费、本地运行中文识别一般简单场景、教育
PaddleOCR中文识别强、开源模型较大中文文档、票据
EasyOCRPyTorch 实现、效果好速度较慢深度学习场景
Surya多语言、表格识别较新复杂文档
云服务 API准确率高、功能全收费、需要联网企业级应用
