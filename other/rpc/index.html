RPC 基础

什么是 RPC

RPC（Remote Procedure Call）远程过程调用，是一种让分布式系统中的不同服务可以像调用本地函数一样调用远程服务的通信协议。

工作流程

  1. 调用方：发起本地调用，请求被序列化
  2. 网络传输：通过网络发送到服务提供方
  3. 服务方：接收请求，反序列化并执行
  4. 返回结果：结果序列化后返回给调用方
  5. 调用方：接收结果并反序列化

核心组件

  • Stub：客户端存根，封装网络细节
  • Skeleton：服务端存根，分发请求
  • Protocol：通信协议（HTTP/TCP/UDP）
  • Serializer：序列化/反序列化（JSON/Protobuf）

gRPC 深入

Protocol Buffers

// 定义服务
syntax = "proto3";

package example;

service UserService {
  rpc GetUser (GetUserRequest) returns (User);
  rpc CreateUser (CreateUserRequest) returns (User);
  rpc ListUsers (ListUsersRequest) returns (stream User);
  rpc CreateUserStream (stream CreateUserRequest) returns (CreateUserResponse);
}

message User {
  string id = 1;
  string name = 2;
  string email = 3;
  int32 age = 4;
}

message GetUserRequest {
  string id = 1;
}

流式 RPC

  • Server Streaming：客户端发送请求，服务端流式返回
  • Client Streaming：客户端流式发送，服务端返回单一响应
  • Bidirectional Streaming：双向流式通信

拦截器

// gRPC 服务端拦截器
func unaryInterceptor(ctx context.Context, req interface{},
    info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (interface{}, error) {

    // 前置处理
    log.Printf("Received: %v", req)

    // 调用实际处理函数
    resp, err := handler(ctx, req)

    // 后置处理
    log.Printf("Response: %v", resp)

    return resp, err
}

// 客户端拦截器
func clientInterceptor() grpc.UnaryClientInterceptor {
    return func(ctx context.Context, method string, req, reply interface{},
        cc *grpc.ClientConn, invoker grpc.UnaryInvoker, opts ...grpc.CallOption) error {

        // 前置处理
        start := time.Now()

        // 调用远程服务
        err := invoker(ctx, method, req, reply, cc, opts...)

        // 后置处理
        log.Printf("Call %s took %v", method, time.Since(start))

        return err
    }
}

百度 brpc

核心特性

  • 多协议支持：HTTP、gRPC、Redis、Memcache、Thrift
  • 负载均衡：轮询、随机、一致性哈希
  • 熔断降级：内置熔断器
  • 连接池：高效复用连接

使用示例

// 定义服务
#include 
#include 

class MyService : public brpc::Service {
public:
    void Echo(google::protobuf::RpcController* cntl,
              const EchoRequest* request,
              EchoResponse* response,
              google::protobuf::Closure* done) {
        // 业务逻辑
        response->set_message(request->message());

        // 异步回调
        brpc::ClosureGuard done_guard(done);
    }
};

int main() {
    brpc::Server server;
    MyService service;

    server.AddService(&service, brpc::SERVER_DOESNT_OWN_SERVICE);
    server.Start(8000, brpc::ServerOptions());
    server.RunUntilAskedToQuit();
}

Connect-RPC

Connect 介绍

Connect 是 Buf 推出的新一代 RPC 框架，兼容 gRPC 和 HTTP/JSON：

  • gRPC 兼容：原生支持 gRPC 协议
  • HTTP/JSON：可在浏览器中直接调用
  • 生成代码：支持 Go、TypeScript 等

使用示例

// 定义 Connect 服务
package greetconnect

import (
    "context"
    "fmt"
    "net/http"

    "connectrpc.com/connect"
    "github.com/bufbuild/connect-gen-go/greet/v1/greetv1connect"
    "greetv1 "github.com/bufbuild/connect-go/greet/v1"
)

type GreetServiceHandler struct{}

func (s *GreetServiceHandler) Greet(
    ctx context.Context,
    req *connect.Request[greetv1.GreetRequest],
) (*connect.Response[greetv1.GreetResponse], error) {

    resp := &greetv1.GreetResponse{
        Greeting: fmt.Sprintf("Hello, %s!", req.Msg.Name),
    }

    return connect.NewResponse(resp), nil
}

func main() {
    mux := http.NewServeMux()
    mux.Handle(greetv1connect.NewGreetServiceHandler(&GreetServiceHandler{}))
    http.ListenAndServe(":8080", mux)
}

超时与重试

// 设置超时
ctx, cancel := context.WithTimeout(ctx, 3*time.Second)
defer cancel()

// 设置重试
retryOpts := []grpc.CallOption{
    grpc.WaitForReady(true),
    grpc.RetryPolicy{
        MaxAttempts: 3,
        Backoff:     grpc.BackoffExponential{MaxDelay: 10 * time.Second},
    },
}

resp, err := client.Greet(ctx, req, retryOpts...)

负载均衡

  • 客户端负载均衡：客户端维护服务实例列表
  • 服务端负载均衡：使用 LB 服务（如 Nginx）
  • 一致性哈希：相同请求路由到同一实例

熔断器模式

// 熔断器配置
breaker := gobreaker.NewCircuitBreaker(
    gobreaker.WithName("my-service"),
    gobreaker.WithMaxRequests(3),
    gobreaker.WithInterval(10*time.Second),
    gobreaker.WithTimeout(3*time.Second),
)

result, err := breaker.Execute(func() (interface{}, error) {
    return client.Call(ctx, request)
})
