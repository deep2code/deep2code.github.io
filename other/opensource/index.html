rustdesk-远程桌面

开源的远程桌面软件（Rust 实现，自带加密），TeamViewer/AnyDesk 的免费替代；支持自建中继服务器（hbbs/hbbr），数据完全自控。

网络状态模拟器

用可控的网络异常（丢包、抖动、延迟、带宽限制）测试应用的容错能力，适合演练弱网/断网场景；基于 sidecar 方案，Linux 上最顺滑，macOS 需配 pf 规则。

Rust 生态推荐

桌面应用

  • Tauri：轻量级桌面/移动应用框架，使用 Web 技术栈
  • egui：纯 Rust 实现的即时模式 GUI 库
  • iced：声明式 GUI 框架，类似 Elm 架构

Web 开发

  • Axum：现代 Web 框架，异步运行时
  • Actix-web：高性能 Web 框架
  • Rocket：易用的 Web 框架

命令行工具

  • ripgrep：快速文本搜索，取代 grep
  • bat：带语法高亮的 cat 替代
  • exa：现代 ls 替代
  • fd：快速文件查找
  • starship：跨 Shell 提示符

游戏开发

  • Bevy：数据驱动的游戏引擎
  • ggez：2D 游戏引擎
  • winit：窗口和输入库

数据与监控

开源许可证选择

许可证对比

许可证商业使用修改后必须开源专利授权
MIT✓--
Apache 2.0✓-✓
BSD-3✓--
GPLv3✓✓✓
AGPLv3✓✓（网络服务也算）✓
LGPLv3✓仅链接库✓
MPL 2.0✓仅修改部分✓

选择建议

  • 库/工具：MIT 或 Apache 2.0（宽松）
  • copyleft 强制：GPLv3
  • 网络服务：AGPLv3
  • 企业项目：Apache 2.0 + 专利条款

参与开源贡献

首次贡献步骤

  1. 在 GitHub 上找到感兴趣的项目
  2. 阅读 CONTRIBUTING.md 指南
  3. 从 good first issue 开始
  4. Fork → Clone → 创建分支 → 修改 → PR
  5. 响应代码审查反馈

开源礼仪

  • 提问前先搜索已有 Issue
  • 提供最小复现示例
  • 保持 PR 小而专注
  • 尊重维护者时间
  • 感谢贡献者的工作
