开源软件

AI 导读一分钟导读，先掌握全文主干。▼

核心观点

  • MRDOC 开源文档/知识管理：Markdown + API 文档 + 团队协作，可私有化部署
  • RustDesk 开源远程桌面（Rust 实现，自带加密），可自建中继服务器，数据完全自控
  • 另有网络状态模拟器与 OpenCV 等推荐

关键结论与取舍

  • 远程桌面替代 TeamViewer/AnyDesk 首选 RustDesk 自建
  • 文末 2024-2026 优秀开源软件推荐持续更新
适合谁读寻找可私有化开源方案的个人与团队 读完可获得精选开源工具清单与各自适用场景

mrdoc-觅思文档

  • 功能类似国内的语雀、看云和飞书文档，国外的 GitBook。

开源文档 / 知识管理平台：支持 Markdown、API 文档和团队协作，可以私有化部署。

rustdesk-远程桌面

开源的远程桌面软件（Rust 实现，自带加密），是 TeamViewer / AnyDesk 的免费替代；支持自建中继服务器（hbbs / hbbr），数据完全自己掌控。

网络状态模拟器

用可控的网络异常（丢包、抖动、延迟、带宽限制）测试应用的容错能力，适合演练弱网 / 断网场景；基于 sidecar 方案，Linux 上最顺滑，macOS 需要配 pf 规则。

opencv

计算机视觉的事实标准库：图像处理、人脸 / 物体识别、视频分析；OpenCV 4.x 持续迭代，支持 CUDA / OpenVINO / TFLite 等推理后端。
