机器学习更新（2024-2026）

机器学习领域已被大语言模型（LLM）深刻改变。详见 LLM 页面 和 RAG 页面。

  • PyTorch 2.x：torch.compile 编译模式 + MPS 原生支持，训练与推理全面加速；
  • Hugging Face：模型仓库生态持续演进，transformers、datasets 与 smolagents 等轻量 Agent 库成为 AI 开发默认起点；
  • 本地推理：Ollama、vLLM、llama.cpp 让 7B–70B 开源模型在本机或单卡上即可运行；
  • LLM 微调普及化：PEFT/LoRA 与各云厂商 MaaS 平台让小型团队也能低成本微调大模型（详见 AI 页）；
  • MLOps 常态化：W&B、MLflow 等平台把实验管理、评估与上线变成标准流程。
