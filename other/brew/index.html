官网

  • Homebrew 类似一个软件中心，可以理解成 App Store 或 Google Play 那样的软件商店，只不过 Homebrew 比它们以及 Mac App Store 的资源更丰富，管理也更高效。
  • Homebrew Cask 建在 Homebrew 之上，专门装 GUI 应用，是 Homebrew 的扩展（formula 负责命令行工具，cask 负责 .app 应用）。
  • homebrew——自家酿酒（名字梗）
  • formula——配方（描述怎么装某个软件的 Ruby 脚本）
  • keg——酒桶（单个已安装版本的目录，在 Cellar 下面）
  • Cellar——地窖（/opt/homebrew/Cellar，存放所有已安装版本）

安装命令

# 如果下载很慢，可先配置国内镜像源（见文末）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

常用命令

# 在 .zshrc 文件中添加
# Homebrew 取消自动更新
export HOMEBREW_NO_AUTO_UPDATE=true

# 安装 hugo、nginx、memcached、redis、mongodb-community、mysql、jenkins-lts 等
brew install hugo

# 查看
brew info memcached

# 搜索
brew search redis

# 查看支持的命令
brew commands

# 列出常用帮助
brew help

# 运行后台服务 start restart stop
brew services start nginx

# unbound：验证型、递归、带缓存的 DNS 解析器
brew services start unbound

# unrar 因版权问题从 homebrew-core 移除，只能装第三方 tap
brew install unrar
brew install carlocab/personal/unrar
# 2026 建议：一般解压场景可直接用 brew install unar（支持 rar 等格式，一条命令）

Homebrew 6.0 时代（2026）

Homebrew 6.0：信任机制与性能

2026-06-11 发布 Homebrew 6.0.0，自 5.1.0 以来最要紧的变化：

  • Tap 信任机制（tap trust）：新的安全机制约束第三方 tap 的权限和影响范围，降低供应链风险——安装第三方 tap 时能拿到更明确的信任边界。
  • 默认内部 JSON API 更快更小：默认数据通道升级成新的内部 JSON API，体积更小、解析更快。
  • Linux 沙箱化（sandboxing）：Linux 上的安装操作默认在沙箱里跑，隔离安装副作用。
  • brew bundle 大量改进：bundle 能力明显扩展（含 uv tools 等新形态依赖的声明式支持）。
  • macOS 27 Golden Gate 初步支持：跟上 Apple 新系统线（仅 Apple Silicon）。
  • 默认值改进：由用户调查驱动的默认行为调整和整体性能优化。

日常使用 2026

Apple Silicon 安装前缀仍是 /opt/homebrew；macOS Intel 已进入弃用倒计时（官方博客公布了时间表，Intel Mac 用户建议规划迁移）。常用姿势：

# Apple Silicon (M1/M2/M3/M4)
# Homebrew 安装在 /opt/homebrew

# 常用命令
brew install ripgrep fd bat eza zoxide fzf
brew install --cask raycast orbstack warp zed

# 安装指定大版本（5.1 新增）
brew version-install

# Brewfile 管理依赖
brew bundle dump    # 导出当前安装列表
brew bundle install # 从 Brewfile 安装

# 服务管理（4.x 起强化）
brew services start mysql

# 内置 MCP 服务（4.6 起，供 AI 工具链调用）
brew mcp-server
  • 提交签名已切换：自 2025-02 起官方提交从 PGP 签名切到 SSH 签名，校验 git 历史时改用新密钥。
  • 国内加速：官方源慢时配中科大或清华镜像；换源后得 brew update 生效，提示版本过旧时优先换较新的镜像源。
