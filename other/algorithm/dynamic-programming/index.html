什么是动态规划

DP 是我面试中最怕被问到、也最爱出的题——因为它能筛出"真懂"和"背模板"的人。核心思想一句话：把大问题拆成重叠的小问题，自底向上记录小问题的解，避免重复计算。

和分治的区别在于：分治的子问题不重叠（归并排序），DP 的子问题大量重叠（斐波那契裸递归有指数级重复计算）。能用 DP 的问题必须同时满足：

  • 最优子结构：大问题的最优解由子问题的最优解组合而成。
  • 无后效性：未来的决策只依赖当前状态，不依赖"怎么走到这个状态"的路径。

DP 解题四步法

从斐波那契开始：为什么要记忆化

裸递归求斐波那契：f(n) = f(n-1) + f(n-2)。画递归树你会发现 f(3) 被重复计算了成百上千次，时间复杂度 O(2ⁿ)。加个备忘录（memo）把算过的存起来，每个状态只算一次，直接降到 O(n)：

经典例题 1：最大子数组和

给定整数数组，求连续子数组的最大和。Kadane 算法是 DP 最经典入门：dp[i] 表示以 i 结尾的最大子数组和。转移：要么接在前一段后面，要么从 i 重新开始：

dp[i] = max(nums[i], dp[i-1] + nums[i])
ans = max(dp[i])

package main

import "fmt"

// maxSubArray Kadane 算法：O(n) 时间 O(1) 空间
func maxSubArray(nums []int) int {
    maxEndingHere := nums[0]
    maxSoFar := nums[0]
    for i := 1; i < len(nums); i++ {
        // 要么接在前面，要么从当前元素重新开始
        if maxEndingHere+nums[i] > nums[i] {
            maxEndingHere += nums[i]
        } else {
            maxEndingHere = nums[i]
        }
        if maxEndingHere > maxSoFar {
            maxSoFar = maxEndingHere
        }
    }
    return maxSoFar
}

func main() {
    nums := []int{-2, 1, -3, 4, -1, 2, 1, -5, 4}
    fmt.Println(maxSubArray(nums)) // 6，子数组 [4,-1,2,1]
}

Python 对照：

from typing import List

def max_sub_array(nums: List[int]) -> int:
    max_ending = max_so_far = nums[0]
    for x in nums[1:]:
        max_ending = max(x, max_ending + x)
        max_so_far = max(max_so_far, max_ending)
    return max_so_far

if __name__ == "__main__":
    print(max_sub_array([-2, 1, -3, 4, -1, 2, 1, -5, 4]))  # 6

经典例题 2：0-1 背包问题

背包问题是 DP 二维状态的代表作：给定重量 W 的背包和 n 个物品（重量 w[i]、价值 v[i]），每个物品只能选一次，求能装下的最大价值。定义 dp[i][j] 为前 i 个物品、容量 j 时的最大价值：

dp[i][j] = max(dp[i-1][j],                    # 不选第 i 个
               dp[i-1][j-w[i]] + v[i])        # 选第 i 个

package main

import "fmt"

// knapsack01 0-1 背包：O(n*W) 时间 O(W) 空间（一维滚动优化）
func knapsack01(weights, values []int, capacity int) int {
    n := len(weights)
    dp := make([]int, capacity+1) // dp[j] = 容量 j 时最大价值
    for i := 0; i < n; i++ {
        // 必须倒序遍历，避免同一个物品被重复使用
        for j := capacity; j >= weights[i]; j-- {
            if dp[j-weights[i]]+values[i] > dp[j] {
                dp[j] = dp[j-weights[i]] + values[i]
            }
        }
    }
    return dp[capacity]
}

func main() {
    weights := []int{2, 3, 4, 5}
    values := []int{3, 4, 5, 6}
    fmt.Println(knapsack01(weights, values, 8)) // 10（选重量3+5=价值4+6）
}

Python 对照：

from typing import List

def knapsack01(weights: List[int], values: List[int], capacity: int) -> int:
    n = len(weights)
    dp = [0] * (capacity + 1)
    for i in range(n):
        # 倒序：保证物品 i 只被用一次
        for j in range(capacity, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[capacity]

if __name__ == "__main__":
    print(knapsack01([2, 3, 4, 5], [3, 4, 5, 6], 8))  # 10

关键细节：一维优化时容量必须倒序遍历，否则同一物品会被"多次取用"，退化成完全背包（物品无限件）。这是 0-1 背包和完全背包的分水岭。

解题技巧与最佳实践

💡 我的 DP 学习路线：别一上来就啃背包。我建议按这个顺序刷——爬楼梯（入门）→ 最大子数组和（一维线性）→ 0-1 背包（二维状态）→ 最长递增子序列（子序列模型）→ 编辑距离（二维字符串）。每道题手写三遍：第一遍抄模板，第二遍自己默写，第三遍换个语言重写。

  • 先想暴力递归，再加备忘录：写出最直观的递归解，发现有重复计算就加 memo，然后改成自底向上递推。这是从暴力到 DP 的标准路径。
  • 状态定义决定一切：同样的问题，状态定义不同难度天差地别。"dp[i] 以 i 结尾"通常比"dp[i] 前 i 个"更容易写转移。
  • 空间优化：能滚动就滚动：二维 DP 若只依赖上一行，可用两个一维数组滚动；若只依赖左上、正上、正左，可再优化成一行。背包就是经典例子。
  • 初始化要覆盖所有边界：dp[0] 是什么？无解时填什么（通常填 ∞ 或 -1）？错一个初始化全盘皆输。
  • 背包问题先判断几维：一维修容量就够（价值单一），二维要同时装下"重量+体积"等多个限制。
  • DP 不出来就看数据范围猜复杂度：n≤20 想状态压缩/指数搜索；n≤200 想 O(n³) DP；n≤10⁴ 想 O(n²)；n≤10⁶ 想 O(n) 或 O(n log n)。

常见问题 FAQ

Q1：DP 和分治到底有什么区别？

本质区别在子问题是否重叠。分治（归并排序）子问题互相独立，合并时不重复；DP（斐波那契）子问题大量重叠，必须用备忘录/表格记住。如果你的子问题不重叠，用分治就够了；如果重叠且有最优子结构，用 DP。

Q2：什么时候用自顶向下记忆化，什么时候用自底向上递推？

自顶向下（带 memo 的递归）写法直观、只算需要的状态；自底向上（双层 for 循环）没有递归栈风险、适合空间优化。面试推荐自底向上（更容易做空间压缩、也避免栈溢出）；思路不清晰时先用自顶向下想清楚。

Q3：为什么 0-1 背包一维要倒序，完全背包正序？

一维倒序时，计算 dp[j] 读的是上一轮还没更新的 dp[j-w]，对应"第 i 个物品还没选过"；正序时 dp[j-w] 已经被当前 i 轮更新过，对应"第 i 个物品还能再选一次"。一字之差，问题完全不同。

Q4：DP 状态想不出来怎么办？

三步走：① 从暴力递归开始，明确函数签名 f(...) 返回什么；② 找出递归树中的重复节点，加 memo；③ 把递归改成递推表格。90% 的 DP 题走完这三步就出来了。另外可以参考经典模型：背包、线性 DP（子序列）、区间 DP（矩阵连乘）、状态机 DP（股票买卖）。

总结

DP 是"用空间换时间"的极致：把指数级的暴力搜索压缩到多项式。入门靠斐波那契、爬楼梯、最大子数组这三道题建立直觉；进阶要吃透背包模型和子序列模型。下一篇我们看贪心与回溯。
