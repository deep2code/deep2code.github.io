SVN 命令速查

  1. 下载
svn checkout svn://host/svn/IOS/remote_dir(远端仓库路径) project_dir(本地目录路径) --username 用户名 --password 密码

SVN checkout 简写：SVN co

  1. 添加新文件
svn add file（文件名）
svn add *.php(添加当前目录下所有的php文件)
  1. 提交
svn commit -m "提交说明" file（文件名）
svn ci -m "说明" file
  1. 更新
svn update
svn up
  1. 查看状态
svn status
svn st
  1. 查看日志
svn log -l 5（查看最近5条日志）
svn log file（查看文件的历史修改记录）
  1. 差异比较
svn diff file（本地与仓库的差异）
svn diff -r 10:20 file（版本10与版本20的差异）
  1. 回滚
svn revert file（放弃本地修改）
svn merge -r 20:10 file（回滚到版本10）
  1. 删除
svn delete file
svn del file
svn remove file
  1. 锁定/解锁
svn lock -m "说明" file（锁定文件）
svn unlock file（解锁文件）

SVN 高级操作

分支管理

# 创建分支
svn copy svn://host/project/trunk svn://host/project/branches/feature -m "创建功能分支"

# 切换分支
svn switch svn://host/project/branches/feature

# 合并分支
svn merge svn://host/project/branches/feature

# 合并特定版本
svn merge -r 100:200 svn://host/project/branches/feature

# 解决冲突
svn resolve --accept theirs-full file

钩子脚本

# 常用钩子
# pre-commit: 提交前检查
# post-commit: 提交后通知
# start-commit: 开始提交前检查

# 示例：pre-commit 禁止大文件
#!/bin/bash
REPOS="$1"
TXN="$2"
MAX_SIZE=10485760  # 10MB

svnlook changed -t "$TXN" "$REPOS" | while read path; do
    size=$(svnlook filesize -t "$TXN" "$REPOS" "$path")
    if [ $size -gt $MAX_SIZE ]; then
        echo "File too large: $path" >&2
        exit 1
    fi
done

服务器配置

# svnserve 配置
# /etc/sysconfig/svnserve
# OPTIONS="--daemon --root /var/svn"

# 创建仓库
svnadmin create /var/svn/myproject

# 配置用户权限
# vi /var/svn/myproject/conf/svnserve.conf
[general]
anon-access = read
auth-access = write
password-db = passwd
authz-db = authz

# 配置用户
# vi /var/svn/myproject/conf/passwd
[users]
admin = password123
dev = devpassword

# 配置权限
# vi /var/svn/myproject/conf/authz
[groups]
developers = dev1, dev2

[/]
@developers = rw
admin = rw

最佳实践

仓库布局

/project
  /trunk          # 开发主线
  /branches       # 分支目录
    /release-1.0  # 发布分支
    /feature-xxx  # 功能分支
  /tags           # 标签目录
    /v1.0.0       # 版本标签
    /v1.0.1

工作流程

  1. 每次开发新功能从 trunk 创建分支
  2. 在分支上进行开发，定期从 trunk 同步
  3. 开发完成后合并回 trunk
  4. 发布时从 trunk 创建 tag
  5. 维护发布分支，bugfix 合并到 trunk

忽略文件

# 全局忽略
# ~/.subversion/config
global-ignores = *.o *.lo *.la *.al .libs *.so *.so.[0-9]* *.a *.pyc *.pyo __pycache__ .DS_Store

# 项目级忽略
# 在项目根目录创建 .svnignore
# 或者使用 svn propset
svn propset svn:ignore -F .svnignore .
