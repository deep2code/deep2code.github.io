Stringer

AI 导读一分钟导读，先掌握全文主干。▼

核心观点

  • Stringer 根据枚举常量生成 String() 实现，用 //go:generate 指令接入 go generate
  • 手写映射在枚举常量增删后极易漏同步，生成代码可编译校验
  • 2026 现状：按月发版，支持位掩码与字符枚举等边界用法

关键结论与取舍

  • 常规枚举直接用 Stringer；位掩码需定制 flag，字符枚举走其他方案
  • 生成文件进代码库，配合单元测试锁定行为
适合谁读在 Go 代码里大量使用枚举的工程开发者 读完可获得一段可复制的 go:generate 流程，以及位掩码等边界场景的处理办法

枚举类型手写的 String() 方法既啰嗦又易漏同步：常量一增删，手写的字符串映射就掉队了。stringer 替你把一致、能过编译校验的实现生成好——只要在枚举所在文件写 //go:generate 指令，执行一次 go generate 就收工。

  • main.go 里的示例
//go:generate go tool stringer -type=Pill
type Pill int

const (
 Placebo Pill = iota
 Aspirin
 Ibuprofen
 Paracetamol
 Acetaminophen = Paracetamol
)
  • 跑一下命令
go generate
  • 再看生成的 pill_string.go
import "strconv"

// 这段防止generate之后，修改后没有再次generate,通过编译错误强制提示
func _() {
 // An "invalid array index" compiler error signifies that the constant values have changed.
 // Re-run the stringer command to generate them again.
 var x [1]struct{}
 _ = x[Placebo-0]
 _ = x[Aspirin-1]
 _ = x[Ibuprofen-2]
 _ = x[Paracetamol-3]
}

const _Pill_name = "PlaceboAspirinIbuprofenParacetamol"

var _Pill_index = [...]uint8{0, 7, 14, 23, 34}

func (i Pill) String() string {
 if i < 0 || i >= Pill(len(_Pill_index)-1) {
  return "Pill(" + strconv.FormatInt(int64(i), 10) + ")"
 }
 return _Pill_name[_Pill_index[i]:_Pill_index[i+1]]
}

Go Stringer 更新

stringer 就是给枚举类型自动生成 String() 方法的工具。Go 1.24 起，go tool 指令把工具调用简化成一条内置命令：

# Go 1.24+ go.mod 中声明工具依赖
go get -tool golang.org/x/tools/cmd/stringer
go tool stringer -type=Pill

2026 现状：按月发版与常用 flag

golang.org/x/tools 仍然按月发版，2026 年 8 月推到 v0.49.0（发布于 2026-08-13），stringer 本身很稳，继续跟着工具链演进。常用 flag 划重点：

  • -type：要一次生成多个枚举，逗号分隔即可，例如 go tool stringer -type=Pill,Cap,Color；
  • -output：改默认输出文件名（默认为 t_string.go，t 取第一个类型名的首字母小写）；
  • -trimprefix 和 -linecomment：一个剥掉常量名前缀，一个把行注释（去前置空格）直接当字符串输出；
  • 连 _test 包里的类型也会被生成，产物写到 t_string_test.go。

落地的推荐姿势：//go:generate go tool stringer -type=Pill 放在枚举文件头部，CI 里执行 go generate ./...，工具版本锁进 go.mod 的 tool 段，防止漂移。

边界：位掩码与字符串枚举

下面两点 2024 年如此、2026 年依旧，动笔前先记住：

  • stringer 只认整数底层类型的枚举；位掩码常量（bit patterns）官方文档到现在还挂着「未来说可能支持」——2026 年了仍没兑现，真遇上位掩码只能自己兜底；
  • 同值的多个常量只打印词法排最前的名字（如 Acetaminophen = Paracetamol 只会输出 Paracetamol），想显式控制就上 -linecomment；
  • 底层是字符串的枚举（像 type Status string）stringer 干不了这活，得手动 map[Status]string 或者自造 go:generate 模板来收尾。
