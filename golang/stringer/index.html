Stringer

AI 导读一分钟导读，先掌握全文主干。▼

核心观点

  • Stringer 根据枚举常量生成 String() 实现，用 //go:generate 指令接入 go generate
  • 手写映射在枚举常量增删后极易漏同步，生成代码可编译校验
  • 2026 现状：按月发版，支持位掩码与字符枚举等边界用法

关键结论与取舍

  • 常规枚举直接用 Stringer；位掩码需定制 flag，字符枚举走其他方案
  • 生成文件进代码库，配合单元测试锁定行为
适合谁读在 Go 代码里大量使用枚举的工程开发者 读完可获得一段可复制的 go:generate 流程，以及位掩码等边界场景的处理办法

官方自动生成string

手写枚举的 String() 方法又繁又易漏：常量增删后很容易忘记同步字符串映射。stringer 负责生成一致且可编译校验的实现——在枚举所在文件写 //go:generate 指令，跑一次 go generate 即可。

  • main.go内容
//go:generate go tool stringer -type=Pill
type Pill int

const (
 Placebo Pill = iota
 Aspirin
 Ibuprofen
 Paracetamol
 Acetaminophen = Paracetamol
)
  • 执行命令
go generate
  • 生成的pill_string.go内容
import "strconv"

// 这段防止generate之后，修改后没有再次generate,通过编译错误强制提示
func _() {
 // An "invalid array index" compiler error signifies that the constant values have changed.
 // Re-run the stringer command to generate them again.
 var x [1]struct{}
 _ = x[Placebo-0]
 _ = x[Aspirin-1]
 _ = x[Ibuprofen-2]
 _ = x[Paracetamol-3]
}

const _Pill_name = "PlaceboAspirinIbuprofenParacetamol"

var _Pill_index = [...]uint8{0, 7, 14, 23, 34}

func (i Pill) String() string {
 if i < 0 || i >= Pill(len(_Pill_index)-1) {
  return "Pill(" + strconv.FormatInt(int64(i), 10) + ")"
 }
 return _Pill_name[_Pill_index[i]:_Pill_index[i+1]]
}

Go Stringer 更新

stringer 工具用于自动生成枚举类型的 String() 方法。Go 1.24 的 go tool 指令简化了工具调用：

# Go 1.24+ go.mod 中声明工具依赖
go get -tool golang.org/x/tools/cmd/stringer
go tool stringer -type=Pill

2026 现状：按月发版与常用 flag

golang.org/x/tools 仍在按月发版，2026 年 8 月最新版 v0.49.0（2026-08-13 发布），stringer 功能稳定、继续随工具链演进。常用 flag 要点：

  • -type：逗号分隔多个类型，一次生成多个枚举，如 go tool stringer -type=Pill,Cap,Color；
  • -output：覆盖默认输出文件（默认 t_string.go，t 为第一个类型的首字母小写）；
  • -trimprefix 与 -linecomment：去掉常量名前缀、或直接把行注释（去前置空格）作为字符串输出；
  • 定义在 _test 包中的类型也会生成，输出到 t_string_test.go。

推荐用法：//go:generate go tool stringer -type=Pill 写在枚举所在文件头，CI 里跑 go generate ./...，工具版本锁定在 go.mod 的 tool 段。

边界：位掩码与字符串枚举

两点与 2024 年相比没有变化，写代码前要知道：

  • stringer 只支持整数底层类型的枚举；位掩码常量（bit patterns）官方文档至今仍标注「未来可能支持」——到 2026 年仍未实现，位掩码场景需自行处理；
  • 值相同的多个常量只输出词法上第一个名字（如 Acetaminophen = Paracetamol 会打印 Paracetamol），用 -linecomment 可显式控制；
  • 字符串枚举（如 type Status string）stringer 不处理，需手动 map[Status]string 或自写 go:generate 模板。
