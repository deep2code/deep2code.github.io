核心观点

  • 经典入口：Len/Less/Swap 三方法接口，Sort/Slice/Stable 覆盖常规与稳定排序
  • 1.19 起底层为 pdqsort（快排+堆排+插排混合）
  • 2026 推荐用法：优先 slices 包泛型函数，多字段排序用 1.22+ 的 cmp.Or

关键结论与取舍

  • 新代码用 slices.SortFunc 替代手写 Interface，更短更不易错
  • 稳定排序用 Stable 系，含 cmp.Or 的多字段组合避免多级比较样板

Go 1.21 正式带来 slices 包，泛型化的排序函数比老 sort 包更安全、更顺手：

import "slices"

// 泛型排序
slices.Sort(nums)                    // 升序
slices.SortFunc(nums, func(a, b int) int {
    return b - a                    // 降序
})
slices.SortStable(nums, cmp)        // 稳定排序

// 搜索
idx, found := slices.BinarySearch(nums, 42)

// 其他常用操作
slices.Contains(nums, 42)
slices.Reverse(nums)
slices.Min(nums)
slices.Max(nums)

多字段排序（Go 1.22+ 的 cmp.Or）

import (
    "cmp"
    "slices"
)

// cmp.Or 把多个比较结果串起来:先比 Age,相同再比 Name
slices.SortFunc(users, func(a, b User) int {
    return cmp.Or(
        cmp.Compare(a.Age, b.Age),
        cmp.Compare(a.Name, b.Name),
    )
})
