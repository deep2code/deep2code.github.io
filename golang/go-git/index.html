go-git


package main

import(
    "fmt"
    "github.com/go-git/go-git/v5"
    "github.com/go-git/go-git/v5/plumbing/object"
)
 

func gitWork() {
 r, err := git.PlainOpen("../wubei/wubei")
 if err != nil {
  fmt.Println(err)
  return
 }

 fmt.Println("r", r)

 // ... retrieves the branch pointed by HEAD
 ref, err := r.Head()
 if err != nil {
  fmt.Println(err)
  return
 }

 fmt.Println("ref", ref)

 // ... retrieves the commit history
 cIter, err := r.Log(&git.LogOptions{From: ref.Hash()})
 if err != nil {
  fmt.Println(err)
  return
 }

 var cCount int
 err = cIter.ForEach(func(c *object.Commit) error {
  cCount++
  fmt.Println("Author", c.Author)
  fmt.Println("Message", c.Message)
  return nil
 })
 if err != nil {
  fmt.Println(err)
  return
 }

 fmt.Println("cCount", cCount)
}

go-git 更新

go-git 是纯 Go 的 Git 实现库（Apache-2.0），2026 年仍由个人贡献者活跃维护，并获 GitSight 与 Entire 商业赞助；Keybase、Gitea、Pulumi 及 CNCF 系（Kubernetes Prow、Flux）都在使用。现在的版本格局是「v5 稳定线持续维护 + v6 大版本推进」：v5 最新为 v5.19.2（2026-07），并持续回移植安全修复；v6 已进入 alpha 阶段（v6.0.0-alpha.5，2026-07），属于 API 重构的大版本，生产项目仍应使用 v5 线。

v6 方向与 v5 重点修复

go-git v6 的核心变化是 plumbing/transport 层重构：内置 Git 协议 Wire Protocol v2（默认启用）、支持 git archive over HTTP、send-pack 与多 pack 读取性能优化、HTTP 传输加固（重定向与数据竞争修复）、SHA-256 仓库支持子模块、符号链接路径安全边界、reference 路径穿越拒绝与错误信息凭据脱敏等安全加固；迁移需要按官方 v5→v6 guide 调整 transport 相关 API。v5 线 2026 年主要工作是安全与稳定性回移植（x/crypto、x/net 等依赖安全更新、packfile 解析加固、Windows 下 worktree 修复），日常使用可直接 go get github.com/go-git/go-git/v5@latest 升级。

选型：库调用还是 os/exec

简单 Git 操作（clone、拉取提交信息、批量统计）用 os/exec 调系统 git 依然是最稳路径：零依赖、完全对齐官方行为、天然支持 credential helper。需要嵌入持久化 Git 能力（服务端、自定义存储、内存文件系统、离线分析仓库）时才值得用 go-git——它不依赖外部二进制，且 storage.Storer 接口允许把对象库放在内存或自研后端。注意 go-git 的定位仍是「highly extensible 而非 100% 兼容」：部分 porcelain 操作（如 merge）覆盖不完整，复杂场景建议与上游 git 对照测试。
