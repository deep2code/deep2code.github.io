背景：OpenSSL 历史上出过 Heartbleed 等大漏洞，业界干脆各自维护分支——Google 的 BoringSSL 深度绑定 Chromium 生态、靠删减接口求稳；OpenBSD 的 LibreSSL 主打「砍外围、守核心」。Nginx 编译期可以用 --with-openssl=源码目录 指定这些 TLS 库；2026 年构建 HTTP/3 时官方也建议用 OpenSSL 3.5+ 或 BoringSSL（见文末安全台账）。

Nginx 1.30/1.31 新版线（2024-2026 更新）

HTTP/3 与 QUIC（1.25.0+，1.30 起生产可用）

Nginx 从 1.25.0 实验性支持 HTTP/3 和 QUIC，到 1.30.0（2026-04-14）稳定版把主线能力全吃下来：HTTP/3 基于 UDP，解决 TCP 队头阻塞，支持 0-RTT 快速连接恢复；1.27.5 起 QUIC 引入 CUBIC 拥塞控制。

# nginx.conf HTTP/3 配置
server {
    listen 443 ssl;
    listen 443 quic reuseport;  # 启用 HTTP/3
    http3 on;                    # 显式启用（1.27+）
    
    server_name example.com;
    
    ssl_certificate     /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;
    ssl_protocols       TLSv1.3;  # HTTP/3 强制要求 TLSv1.3
    
    # 启用 0-RTT
    ssl_early_data on;
    
    # QUIC 地址验证
    quic_retry on;
    
    # GSO 优化（Linux）
    quic_gso on;
    
    # 通知浏览器支持 HTTP/3
    add_header Alt-Svc 'h3=":443"; ma=86400';
    
    location / {
        proxy_pass http://backend;
    }
}

2025-2026 全新特性

  • HTTP Early Hints（1.29.0，2025-06-24）：支持 HTTP 103 预响应，服务器在最终响应前先下发资源加载指令，加速首屏渲染。
  • HTTP/2 to backend（1.29.4）：反向代理到后端可以走 HTTP/2（以前只能 HTTP/1.1），降低上游连接开销。
  • Encrypted ClientHello / ECH（1.29.4）：加密 TLS 握手里的 SNI，配合 TLSv1.3 防流量嗅探。
  • Multipath TCP（1.29.7 / 1.30.0）：多路径 TCP 支持，移动端弱网下提升可靠性。
  • upstream 粘性会话（1.29.6）：原生 sticky sessions，会话保持不再靠第三方模块。
  • HTTP 正向代理（1.31.0 主线）：内置 forward proxy 支持。
  • 默认代理升级：proxy 默认 HTTP/1.1 + keep-alive；复杂 SSL 配置的内存 / CPU 优化（1.28.0）。
  • njs 1.0.0（2026-06）：官方语言引擎转向 QuickJS 路线。

HTTP Early Hints 配置示例（1.29.0+）

# 103 Early Hints 配置
location / {
    add_before_body "Link: ; rel=preload; as=style";
    # 客户端收到 103 状态码后开始预加载
    # 随后收到 200 和实际内容
    proxy_pass http://backend;
}

版本选择建议（2026-08）

版本线特点推荐场景
1.31.x（主线）最新特性：HTTP 正向代理、ECH、HTTP/2 后端尝鲜 / 需要新能力（至 1.31.4）
1.30.x（稳定）Early Hints、HTTP/2 后端、ECH、MPTCP、sticky 全量入稳生产首选（1.30.0 @ 2026-04-14，至 1.30.4）
1.28.x（稳定维护线）2025-04 发布，仍在安全维护已上 1.28 的存量环境
1.26.x 及更早已退出 stable 维护尽快升级

安全台账（2025-2026）

  • CVE-2024-35200：HTTP/3 QUIC 模块空指针解引用 DoS，修复于 1.27.2。
  • CVE-2025-23419：SSL 会话复用漏洞，修复于 1.26.3 / 1.27.4（2025-02）。
  • CVE-2026-1642：SSL upstream 注入，修复于 1.28.2 / 1.29.5（2026-02）。
  • CVE-2026-42926 / 40460 等一批：HTTP/2 请求注入、HTTP/3 地址欺骗、rewrite 缓冲区溢出等，修复于 1.30.1 / 1.31.0（2026-05）。
  • CVE-2026-42533 / 60005 / 56434：map 正则缓冲区溢出、slice 内存泄漏、ssi use-after-free，修复于 1.30.4 / 1.31.3（2026-07）。
  • 建议紧跟 1.30.x / 1.31.x 的最新补丁；构建 HTTP/3 时用较新的 OpenSSL（3.5+）或 BoringSSL。
  • 支持通过 OSSL_STORE 加载密钥（1.29.0+）。
