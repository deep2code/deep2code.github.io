HTTP 模块更新

Nginx 1.25+ 新增 HTTP/3 和 Early Hints 支持。核心 HTTP 模块改进：

  • http3 on|off 指令（1.27+）
  • quic_retry、quic_gso、ssl_early_data 指令
  • add_before_body 支持 103 Early Hints（1.29+）
